# 43. 체인 58 사전 등록 — VIPL 5-fold in-domain: 원시 입력 PhysFormer × 고심박 가중 손실 (2026-10-23, 사용자 선택 "2안")

## 1. 왜
목표의 VIPL 칸(기존 방법 대비 향상)은 zero-shot 에서 FactorizePhys 6.88 대비 불성립으로 확정(38 §G-4). 사용자가 마지막 실험으로 "고심박 실패를 겨냥한 원시 입력 PhysFormer 또는 고심박 가중 손실, 사전 등록 후 5-fold" 를 선택. 근거: ①in-domain 5-fold 최선(VIPL 단독 증강+검증 6.21, 장치 라벨 공동학습 6.51)도 90–120 bpm 12~13·운동 후 15 로 FactorizePhys zero-shot(7.2 / 8.9)에 뒤지고 60–90 은 앞선다(4.3~4.4 vs 6.3) ②zero-shot 에서 입력만 차분→원시로 바꾸면 90–120 구간 −3.5(3시드, 42 §6) → in-domain 에서도 고심박 구간을 고치면 5-fold 전체가 6.88 아래로 내려갈 수 있다.
