- **③ 검증된 주입 설계(가상얼굴 데이터)**: 체인 53 Phase 1(단일 시드)에서 UBFC 34 출발점에 가상얼굴 42 클립을 더하면 MMPD 무효(+0.50 / +0.47 ns), VIPL zero-shot 악화(PhysFormer +1.42, FactorizePhys +2.45; Holm p<.0001), PURE 악화(FactorizePhys +4.13 p=.008), PhysFormer MCD 붕괴(14 → 36). 체인 51 의 실-only 대조(공식 코퍼스 안에서 −0.36 VIPL·−5.3 NIRP 소동작)와 방향이 반대 → 가상얼굴의 이득은 **PURE·MCD 실 클립과 함께 있을 때만** 나타나는 조건부 효과로 재서술(Phase 2 시드 후 확정). 파형 뱅크 vs 템플릿 비교(MMPD −2.01)는 영향 없음.
- **④ 직접 감독 분해(목적함수)**: UBFC 출발점에서 두 백본 모두 무효(H-U2 ns) — 분해 손실의 이득(MMPD zero-shot 5시드 −2.73, MMPD 인트라 −0.87 p=.015 2차)은 공식 코퍼스·MMPD 인트라 데이터 위에서만 관측됨 → "목적함수의 이득은 학습 풀의 실 노이즈 다양성에 의존" 으로 한계절에 명시.
- **실 얼굴 손상 사본(H-U3)**: 이 실험에서 유일하게 일관된 긍정 요인(MMPD·VIPL·플리커), 단 PhysFormer 에서 PURE·DLCN·NIRP 정지 악화 → 조건부.
- **VIPL in-domain**: 체인 50 Phase 2b(증강만 6.92)로 공동학습의 기여는 '≈0.4 bpm' 으로 줄었고, 체인 50c(증강 + 검증 선택 6.21, 10-20)로 **0 이하**가 됨 — VIPL 안에서는 외부 데이터·목적함수 없이 문헌 레시피 요소 2개가 최선(§5 VIPL 행). '기존 방법 대비 향상' 은 POS·공개 가중치 대비로는 성립(6.21 vs 7.77/13.53/16.21/6.88)하나 우리 방법의 기여로 귀속되지 않음.
- **목표(/goal) 판정 요약**: zero-shot 13축·MMPD·VIPL 에서 기존 방법(고전·공개 가중치) 대비 우리 모델의 우위는 유지되나 그 원인 귀속이 바뀜(실 클립·실 손상 사본); MMPD 인트라 5-fold 는 기존 방법 in-domain 기준선 대비 분해 모델 −1.25(p<.0001, 1차 움직임 지표는 Holm ns); VIPL in-domain 은 POS·공개 가중치 대비 유의, 정칙화된 단독 학습 대비 −0.41(p=.0097). 공정 출발점(UBFC 34)에서는 PhysFormer × MMPD 만 개선.
