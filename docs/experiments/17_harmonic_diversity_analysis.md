1. **MCD 안정 상태에서 고조파 배가가 사라졌고 MAE가 42.63(CoTN)→5.19로 내려가 POS(4.75)와 0.44 BPM 차이.** 배가율 CoTN 8/20 → CoTNH 0/20 (정확 McNemar p = .008), per-video 절대오차 Wilcoxon p < .001, 효과 크기 r = .87. 사전학습 base 대비는 MAE 29.27→5.19이지만 per-video 검정은 경계(p = .057, r = .47) — base는 이미 14/20을 맞히고 있었고 CoTNH가 새로 나빠진 영상(subject5, 9, 14, 20)이 있기 때문.

3. **다른 축의 대가는 작다**: UBFC held-out 1.43→1.10(개선), 실+플리커 0.00→1.10 / 실+clean 1.21→1.43(각 1영상 차이, 검정 불가), 합성 C3/C6/E3 0.09–0.15 → 0.15–0.19(유지).

## 4. 통계 검정

설계: 동일 영상에 대한 모델 간 대응 비교. 종속변수 = per-video HR 절대오차(BPM), 분포가 극단적 이봉(0 근처 vs 70+)이라 정규성 가정 불가 → **Wilcoxon signed-rank(정확 분포, 0-차이 쌍 제외)**. 효과 크기 = r = |z|/√n(0-차이 제외 n) 및 대응 rank-biserial r_rb(음수 = CoTNH 오차가 작음). 배가 플래그(엄격 [1.8, 2.2]) 차이 = **정확 McNemar(이항, 불일치 쌍)**. 다중비교: MCD 안정 세트의 CoTNH 대 3개 비교에 Holm 보정 병기.

### 4.5 검정력·한계

- 상태별 n = 20이면 Wilcoxon 정확 검정에서 중간 효과(r ≈ .3)를 80% 검정력으로 잡으려면 n ≈ 50 이상 필요 — 운동직후의 "유의하지 않음"은 효과 부재 증거가 아니다.
- McNemar는 불일치 쌍 수로 결정되며 한쪽이 0이면 최소 p는 0.5^k — 안정 세트 base 비교(5/0)는 p = .063으로 원리상 .05를 넘을 수 없다.
- 단일 시드·단일 체크포인트(Epoch9). 시드 반복 없이 모델 간 차이가 학습 분산보다 큰지 알 수 없다(2단계 T2L 시드 std ≤ 0.03은 합성 세트 기준일 뿐 MCD에는 미측정).
- 20명은 600명 코퍼스의 첫 20명이며 무작위 추출이 아니다.

## 5. 해석

1. **개선(안정 상태)**: 고조파 배가·150 BPM 락인이 20/20에서 사라졌고 CoTN이 틀렸던 16영상이 맞았다. 이는 "학습 파형의 고조파 다양성 부재가 배가의 원인"이라는 5단계 가설의 방향과 부합한다. 다만 §요약 4의 압축 증강 동시 도입 때문에 **파형 축 단독 효과라고 단정할 수 없다** — 특히 MCD가 mpeg4 압축 영상이라 압축 증강이 주 요인일 가능성을 배제 못 한다. CoTN + 압축(파형은 neurokit) 또는 CoTN + 고조파(압축 없음) 중 하나의 ablation이 필요하다.
2. **무개선/부분 개선(운동직후)**: 배가는 없어졌으나 반감(2/20)과 저편향이 새로 생겨 통계적으로 base와 구분되지 않는다. 학습 BPM 상한(TRAIN20H 최대 118)과 무관한 GT 65–90 구간에서도 저편향이 나타나므로 "고심박 외삽"만으로 설명되지 않는다. 6단계 계획(CoTNH-M: 고심박 클립 + MCD in-domain 정체성)은 후자를 in-domain 적응으로 다루므로 제로샷 결과와 분리 보고해야 한다.
3. **악화**: 안정 subject 5·9·14·20, 운동직후 subject 4·7·8·10 등 CoTNH가 새로 크게 틀린 영상이 있다. 방향은 모두 **저편향**(예측 < GT)이고 배가의 반대 실패(반감·서브하모닉)로 읽힌다 — 고조파 다양화가 "2f 선호"를 "f/2 허용"쪽으로 밀었을 가능성. 실+플리커 0.00→1.10, 실+clean 1.21→1.43도 각 1영상이지만 같은 방향(저편향)이다.
4. **5단계 서술 수정 필요**: (a) 배가율 6/20·10/20은 엄격 2× 기준으로는 5/20·8/20이며, 락인 기준(≥140)으로 7/20·10/20이다. (b) "neurokit의 강한 2차 고조파"는 `12_waveform_harmonics.md`에 의해 기각되었고, 결함은 다양성 0이다. (c) 배가 사례 기본파 파워는 정의에 따라 1–4%(단일 bin) 또는 6–13%(±3 BPM 창)로, 결론("피크의 소수 %")은 유지된다.
5. **실용적 결론**: 안정 상태 제로샷 MAE 5.19는 POS 4.75와 동급이나 "학습 모델이 고전 방법을 넘는다"는 주장은 아직 성립하지 않는다(운동직후 19.91 vs POS 12.17). 논문에는 "고조파 다양화(+압축 증강)가 안정 상태 교차 데이터셋 붕괴를 해소했으나 운동직후에는 부분적"으로 기술하는 것이 정직하다.

1. **안정 상태의 주요인은 파형 다양화**다(주효과 r = .80, 단독으로도 유의). 압축 증강은 **단독으로는 비유의**(p = .41; MAE 42.63→31.51은 3영상의 배가 해소에 의존)이나 두 수준 평균의 주효과로는 유의(p = .022, 중간 효과)하다.
2. **"결합 시너지"는 통계적으로 지지되지 않는다.** 상호작용 −3.03 BPM(p = .60, r = .13)은 0에 가깝고, MAE 셀 값은 거의 정확히 가산적(42.63 − 11.12 − 23.29 ≈ 8.2 vs 실제 5.19)이다. CoTNH가 CoTNW보다 좋은 것(19.34→5.19, p = .135)은 "시너지"가 아니라 "압축 효과가 파형 효과 위에 더해진 것"으로 서술해야 한다. 16 보고서 Ablation 표의 "결합 시너지" 문구는 "가산적 결합"으로 수정 권고.
3. **운동직후는 어떤 효과도 유의하지 않다**(W 주효과 p = .23, 방향은 오히려 +1.5 BPM 악화; C 주효과 p = .081, r = .42). 운동직후 MAE가 낮은 셀은 압축이 들어간 CoTNC 17.67 / CoTNH 19.91이지만 통계적으로 구분되지 않으며, 파형 다양화는 운동직후에 기여하지 않는다.
4. 합산 40영상에서는 두 주효과 모두 유의(W p = .016, C p = .004)하고 상호작용은 없다 — 다만 W 주효과의 부호검정은 비유의(14/22, p = .24)로, 개선이 소수 영상의 큰 배가 해소(순위 상위)에 집중돼 있음을 뜻한다.
5. 한계: n = 20/상태, 단일 시드. 셀당 1개 모델이라 학습 분산과 요인 효과를 분리할 수 없다. 그림: `phase6_ablation_2x2.png`.

## 6c. CoTNH2(실분포 정합 파형 TRAIN20H2) vs CoTNH

TRAIN20H2는 12 보고서의 처방(a2 0.34–0.85, φ2 실분포 범위)대로 밀도를 실 PPG에 맞춘 20클립이며, 나머지(압축 증강 포함)는 CoTNH와 동일하다.

| 세트 | CoTNH | CoTNH2 | Wilcoxon (CoTNH→CoTNH2) | 배가 McNemar |
|---|---|---|---|---|

Per-video(안정): CoTNH2가 CoTNH 대비 새로 크게 틀린 영상은 subject 10(150.3, 2.14×), 18(151.2, 2.00×), 12(150.3, 1.57× 락인), 19(60.6→99.3), 16(62.4→86.1), 11(62.4→89.7), 15(77.3→56.2) 등 7건; 반대로 CoTNH의 저편향 4건 중 subject 9·14·20은 CoTNH2에서 정확해졌다(58.0→80.9, 66.8→90.5, 76.5→93.2). 운동직후는 CoTNH의 락인 2건(subject 12, 18)과 반감 2건(4, 15)이 모두 해소됐고 새 배가·반감 없음.

**해석(가설, 검증되지 않음)**
- **12 보고서의 "밀도 반대(a2 < 0.3 클립 55%는 실존하지 않는 파형에 예산 낭비)" 주장은 결과로 지지되지 않는다.** 실분포에 밀도를 맞춘 TRAIN20H2가 안정 상태에서 유의하게 나빠졌고(p = .049) 배가가 재출현했다. 즉 저 a2(정현파에 가까운) 클립은 "낭비"가 아니라 **기본파-고조파 대비를 명시적으로 가르쳐 2f 락인을 억제하는 역할**을 했을 가능성이 있다 — 고조파가 약한 클립에서만 "1f가 정답"이라는 신호가 모호하지 않게 주어지기 때문. 이는 실분포 정합이 아니라 **분포 폭·대비**가 중요하다는 방향이고, 16 보고서의 "다양성 폭 > 실분포 밀도 정합" 해석과 일치한다. 다만 이 기전은 사후 해석이며 a2 구간별 통제 실험(예: a2 < 0.3만 제거 / 만 추가)이 있어야 확정된다.
- 운동직후·실노이즈(RTNC/RTNI 0.00)·합성에서의 개선은 TRAIN20H2의 높은 a2(≤ 0.85)가 운동직후의 강한 고조파(12 보고서: 운동직후 a2 중앙값 +0.04, BPM과 r = .50)를 커버한 결과일 수 있으나, 운동직후 차이는 비유의(p = .18)이고 RTNC/RTNI는 1영상 차이라 우연과 구분할 수 없다.
- **시드/우연 가능성을 배제 못 한다.** 합성 20클립 교체라는 작은 변화가 안정 MAE를 5.19↔18.90으로 흔드는 것 자체가 단일 시드·n = 20 체제에서 모델 간 차이가 학습 분산 수준일 수 있음을 시사한다(2단계 시드 std는 합성 세트에서만 측정). CoTNH·CoTNH2 각각 시드 3회가 있어야 "TRAIN20H가 낫다"를 주장할 수 있다.
- PURE에서 CoTNH2가 유의하게 나쁜 것(p = .003, 배가 14→18)은 저심박(GT 45–57 BPM) 구간 배가가 늘어난 것으로, 파형 밀도와 무관하게 학습 BPM 하한(52) 문제가 지배적이라는 7단계 해석과 부합한다.

## 6d. PURE 제로샷 (59 트라이얼; held-out = 피험자 07–10, id ≥ 700, n = 24; steady = 태스크 01, n = 10)
