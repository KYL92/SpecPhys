## 3. 설계 (사전 등록)

### 트랙 Z — 제로샷 평가 (학습 없음, 기존 가중치)
VIPL-HR은 어떤 학습 풀에도 없음 → 순수 zero-shot 14번째 축. 평가 모델: 기준 TW `CoTAF_TW_L` 5시드, 하이브리드 분해 `CoTAM_HYB4_L` 5시드, 소프 `CoTAM_HYB4_SOUP_L`, 고전 POS/CHROM.
- **H-Z1** (방법 편 핵심 주장의 외부 재현): 하이브리드 5시드 풀링 MAE < TW 풀링, 특히 움직임 시나리오(v2, v3, v9). 성공 기준: 영상 단위 Wilcoxon p<.05 (v2∪v9 또는 전체).
- **H-Z2**: 소프 ≈ 풀링 앙상블(29 문서 결론 재현), 정지(v1, v8)에서 이득.
- 보고: 전체·시나리오(9)·소스(3)·fold 별 MAE, 정본 GT(라벨 파형 toolbox 프로토콜) / 문헌 GT(gt_HR 평균) 병기.

### 트랙 C — 피험자 배타 5-fold 교차검증 (문헌 프로토콜)
각 fold k: fold k 피험자 = 평가, 나머지 4-fold = 학습. 셀 3종(모두 동일 레시피·시드 100):
| 셀 | 학습 데이터 | 검증 대상 |
|---|---|---|
| BASE (`VF{k}_BASE_L`) | VIPL 4-fold만 | 매칭 기준선 |
| TW (`VF{k}_TW_L`) | VIPL 4-fold + 공식 코퍼스 `COTRAIN_ALLF_TW` 203(실 161 + 가상얼굴 42) | 가상얼굴 공동학습 기여(데이터 편 주장) |
| HYB (`VF{k}_HYB_L`) | VIPL 4-fold + `COTRAIN_ALLF_HYB4`(TW + DN 24 + MMPD 1~6) + 하이브리드 손실(V4 env) | 직접 감독 분해 기여(방법 편 주장) |
- **H-C1**: TW < BASE (전체 2,378 영상 쌍대 Wilcoxon p<.05).
- **H-C2**: HYB < BASE, 그리고 움직임 시나리오(v2, v3, v9)에서 HYB < TW.
- 문헌 비교: 셀별 SD/MAE/RMSE/r(문헌 GT = gt_HR 평균, 5-fold 합산 2,378 영상) vs PhysFormer 7.74/4.97/7.79/0.78, RhythmFormer 4.51/7.98/0.78, PhysFormer++ 4.88/7.62/0.80, Dual-GAN 4.93/7.68/0.81, RhythmNet 5.30/8.14/0.76, POS 11.5/17.2/0.30, CHROM 11.4/16.9/0.28 (PhysFormer CVPR'22 Table 1, RhythmFormer Table 1). 참고선 지위.
- 시드: 1단계 = 시드 100 × 15 run. **2단계(조건부)**: 1단계에서 BASE 대비 유의 개선(p<.05)이 나온 셀이 있으면 BASE와 해당 셀에 시드 200·300 추가(fold 5 × 2 시드 × 2~3 셀)로 3시드 확증(프로토콜 ≥3시드 규칙). 1단계가 전 셀 비유의/악화면 단일 시드 부정으로 보고하고 추가 학습 없음.
- epoch: 표준 10. fold 1 BASE가 4 h 초과 시 전 셀 5 epoch로 통일(결과 전 결정, 로그에 기록).
- 누출 점검: `agg_vipl.py --cv`가 각 fold 모델의 평가 영상이 자기 fold 피험자인지 assert. DLCN/MR-NIRP 순수 zero-shot 불변(VIPL 학습 풀은 VIPL 셀에만 사용, 공식 모델 불변).

### 판정 규칙
- 트랙 Z: H-Z1 충족 → 방법 편 §5 "단일 코퍼스" 한계 완화 문구 + 표에 VIPL 축 추가. 미충족 → 정직 보고(단일 코퍼스 한계 유지, VIPL 동작 특성 분석).
- 트랙 C: H-C1·H-C2 충족 시 "가상얼굴 공동학습·분해가 대규모 벤치마크 교차검증에서도 유효"; 미충족 시 그대로 보고(기여 재표현 지침 기록). 문헌 대비 절대 수치는 레시피 차이를 명기한 참고선으로만.

### 7.2 읽기(평가) 프로토콜 불일치 — 적분(cumsum) 읽기의 저주파 편향
공식 PhysFormer 평가(`Inference_HRevaluation.m`): 미분 없는 출력 rPPG 를 대역통과·z-score 후 3등분, 구간별 pwelch(2^13) 0.7–4 Hz 피크, 3개 평균(본문: 30 s 영상을 10 s 클립 3개로 나눠 평균). 학습 손실(`TorchLossComputer.cross_entropy_power_spectrum_DLDL_softmax2`)도 출력의 DFT(40–179 bpm, Hanning)에 직접. 본 정본 프로토콜은 DiffNormalized 출력을 cumsum 적분 → detrend → 0.6–3.3 Hz → 영상 전체 periodogram: 적분은 −20 dB/decade 기울기로 대역 내 3.3 Hz 성분을 0.6 Hz 대비 진폭 5.5배(전력 30배) 불리하게 만들어 SNR 낮은 출력에서 argmax 가 대역 하단으로 쏠리고, 학습은 미분 출력 PSD 로 감독되므로 학습–평가가 불일치한다.

### 7.3 학습 레시피 차이 (공식 코드 대조)
| 항목 | 문헌 PhysFormer(공식 코드) | 본 파이프라인(툴박스) |
|---|---|---|

| 입력 | 원시 RGB (x−127.5)/128, 128+0~15 px 랜덤 크롭, 좌우 반전 | DiffNormalized(프레임 차분 정규화), 증강 없음 |

| 손실·평가 신호 | 출력 그대로 DFT 40–179 bpm / 평가도 미분 없음 Welch 3구간 | 손실은 미분 출력 PSD, 평가는 적분 후 periodogram(§7.2) |
| 얼굴 박스 | MTCNN 첫 프레임 확대 박스 고정 | Haar 첫 프레임 확대 박스 고정(동일 전략) |

결과: VIPL 단독은 본 레시피에서 암기로 붕괴(5/5 fold, in-sample r .76 / held-out .01; scratch 재현 LIT 18.66 도 붕괴) → 문헌이 in-domain 에서 고심박까지 직접 학습하는 경로가 본 파이프라인에는 없고, 작동하는 유일한 경로(정렬 코퍼스 앵커 + 전이)는 운동 후 영상의 맥박을 잡지 못한다. 공식 코퍼스에도 ≥100 bpm 클립이 32%(UBFC 중앙값 102, 최대 150) 있으나 정지·실내 영상이라 v7(거친 호흡·큰 움직임·홍조·MJPG) 과 조건이 다르다. 시간 배속 증강은 같은 얼굴에 다른 HR 을 부여해 고심박 표본을 만들고 정체성→HR 지름길을 끊는 장치로, 본 파이프라인에 없는 가장 큰 레시피 차이다.

### 7.4 차이가 아닌 것(배제)
얼굴 박스 전략 동일; 전처리 품질은 본 POS 7.8 vs 문헌 POS 11.5 로 열세 아님; GT 정의는 문헌 GT 열로 정합(장치 HR 라벨 효과 −0.14 ns); 고심박 실패가 3 소스 균일 → 25 fps 재표본 무관; 시드 분산(fold 간 4.4~6.7)은 격차를 설명 못 함.

### 7.5 남는 격차와 수단(실행은 사용자 결정 후)
문헌형 읽기 적용 후에도 6.1 vs 4.97 → 잔여 ≈1.1 은 고심박 학습 실패 몫. 후보: ①시간 배속 증강 + β 스케줄 + 무작위 클립 시작(툴박스 학습 루프 수정, 재학습 필요) ②LITS(표준화 원시 입력, 체인 49 대기) ③문헌형 읽기 병기는 사전 등록 개정 사안.

### 7.6 추가 관찰 (10-17, 체인 46b BASE epoch 곡선·REAL 셀 5-fold)
- §7.1 의 "레시피가 고심박을 전혀 학습하지 못한다"는 진단은 **10 epoch 최종 체크포인트**에 대한 것이다. BASE epoch 곡선(§6)은 VIPL 단독 셀이 epoch 1 에 held-out 5.05(정본)에 도달한 뒤 붕괴함을 보여 주므로, 붕괴의 본질은 "학습 불가"가 아니라 **위상 무상관 파형 라벨 + 주파수 손실 조합의 과적합 동역학**이다. 공식 PhysFormer 가 25 epoch scratch 로 붕괴하지 않는 이유 후보: 시간 배속 증강(HR×2/÷2)과 무작위 클립 시작으로 "클립 정체성→HR" 지름길이 막힘(§7.3), β 1→5 스케줄. 본 환경에서 문헌 레시피(LIT·LITS)가 붕괴한 사실과 정합.
- 수단 목록(§7.5)에 추가: ④ **검증 분할 기반 early-stop**(학습 fold 내부 피험자 분리 검증, test fold 비관여) — BASE 공정 기준선과 공동학습 셀의 epoch 선택 모두에 적용 가능. 실행은 사전 등록 수정 + 사용자 결정 후.
- REAL 셀 5-fold(§6): 가상얼굴 42 클립의 VIPL in-domain 순수 기여는 0/소폭 음 → 문헌 격차(≈1.1~1.7 bpm)는 가상얼굴 데이터의 유무와 무관하며, §7.3 의 학습 레시피·§7.2 의 읽기 차이로 설명되어야 한다.

### 7.7 추가 관찰 (10-17 18:30, 체인 46z4/46z4b: 공식 UBFC 가중치 3종의 VIPL zero-shot, 라벨 유형별 정정 읽기)
PhysFormer 13.53 · RhythmFormer 16.21 · **FactorizePhys 6.88**(문헌 GT). FactorizePhys 는 VIPL 전체에서 우리 zero-shot 단일 모델(TW 8.88·HYB4 8.08)보다 유의하게 낫고 소프(7.06)와 동등하며, **우리 VIPL in-domain 5-fold(HYB 6.70·TW 6.96)와도 거의 같다**(CV_HYB_L [문헌] 6.70 vs FP 6.88 Δ-0.18 p=7.5e-01; 움직임 7.08 vs 10.11 Δ-3.04 p=0.000). 우리 우위는 움직임 조건(v2+v9: 소프 −1.84 p=.016)에 한정. 해석: UBFC 42명만으로 학습한 FactorizePhys 가 VIPL 에서 이 수준이면, 본 파이프라인의 VIPL 한계(문헌 4.97 미달)는 백본(PhysFormer)의 한계가 큰 몫 — §7.3 레시피 차이와 함께 백본 요인을 한계절에 명시. FactorizePhys 의 반감 52편·r .62 는 주의. 정본 GT 로는 우리 in-domain 이 유의 우세(HYB 5.18 vs 7.27, p<10⁻⁹; TW 5.45, p<10⁻⁴)이고 움직임 v2+v9 는 두 GT 모두 우세(문헌 HYB 7.08 vs 10.11 p<.001, TW 7.72 vs 10.11 p=.013) — 즉 FactorizePhys 와의 동등은 문헌 GT·전체 평균에 한정되고 큰 움직임에서는 in-domain 학습이 분명히 낫다.
