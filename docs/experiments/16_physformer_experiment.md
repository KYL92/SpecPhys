# PhysFormer 노이즈 강건성 실험 보고서 (파일럿)

실행: 2026-08-21 · physformer-training 단계 · 설계 근거: `_workspace/01_research_design.md`

## 가설 요약

rPPG 노이즈(표정·머리 움직임, 조명, 센서)와 공간 관류 이질성을 가상얼굴에 통제 주입하고, **오염 입력 + 오염 전 GT 감독(디노이징 학습 구조)**으로 미세조정하면 PhysFormer 강건성이 향상된다 (H1 저하 → H2 회복, H4 공간 이질성).

## 데이터셋 (UBFC-rPPG 포맷, FFV1 무손실, 256², 30fps, 33.6s/영상)

- **학습**: 합성 정체성 5명(SFHQ) × BPM 2종(55~110) = 10영상. 노이즈(조명 드리프트/플리커·강체 움직임·센서)와 공간 패치(coverage 0.35~0.6)를 다양화. 8:2 train/valid.
- **평가**: held-out 정체성 4명(sfhq_04 + 디퓨전 3명) × 조건 6종 = 24영상. 시드는 학습과 분리.

| 조건 | 내용 |
|------|------|
| C1 | clean, 균일 주입 |
| C2 | 공간 패치(coverage 50%) — 관류 이질성만 |
| C3 | 조명 (드리프트 0.15 + 플리커 0.03@**1.1Hz=66 BPM**) |
| C4 | 움직임 (10px, 2°) |
| C5 | 조명+움직임+센서 |
| C6 | C5 + 공간 패치 |

## 결과 — HR MAE (BPM, 4 정체성 평균, 영상 단위 고해상 FFT)

| 조건 | POS | CHROM | **PhysFormer 사전학습** | **PhysFormer 노이즈증강 미세조정** |
|------|-----|-------|------------------------|-----------------------------------|
| C1 clean | 16.29 | 0.42 | 16.16 | 16.11 |
| C2 patches | 16.29 | 16.29 | 32.22 | 16.10 |
| C3 illum | 0.47 | 16.34 | 10.54 | **0.14** |
| C4 motion | 0.42 | 0.42 | 33.56 | **0.15** |
| C5 illum+motion | 0.42 | 16.29 | 10.54 | **0.15** |
| C6 전부 | 0.42 | 16.29 | 10.66 | **0.09** |
| **노이즈 평균(C3–C6)** | 0.43 | 12.34 | **16.32** | **0.13** |

SNR(toolbox, 청크 평균): 사전학습 +2.0dB(clean) → **−2.7dB**(C6)로 단조 붕괴. 미세조정 후 전 조건 **+6.0~+10.4dB**.

그림: `_workspace/data/results/physformer_noise_robustness.png` · 수치: `physformer_hr_comparison.json`

## 발견된 실패 모드 (기준선이 "왜" 무너지는가)

1. **플리커 락인**: 조명 플리커(1.1Hz)가 있는 C3/C5/C6에서 사전학습 PhysFormer는 **4명 전원을 ~66 BPM으로 추정** — 심박이 아니라 주변광 주기를 읽는다. 연구자가 지적한 "광학적 노이즈" 취약성의 직접 증거.
2. **고조파 배가**: subject2(GT 64)를 128(2×)로, C2 패치에서는 192(3×)로, C4에서 subject4(GT 70)를 140(2×)으로 — 파형의 배음 구조에 취약.
3. **공간 이질성 악화**: 패치 주입(C2)은 사전학습 모델의 오차를 2배로 키운다(16.2→32.2) — 관류 이질성이 실제 문제라는 H4 전제를 지지.

## 핵심 결과 (H2 지지)

노이즈 증강 미세조정(10 epoch, LR 5e-5, 사전학습 UBFC 가중치에서 시작)은 **노이즈 조건 MAE 16.32 → 0.13 BPM (99.2% 감소)**, 플리커 락인·고조파 배가·복합 노이즈를 모두 해소했다. 특히 C6(조명+움직임+센서+패치 동시)에서 0.09 BPM — 디노이징 학습 구조가 노이즈 불변 생리신호 표현을 학습했음을 시사한다.

**미해결**: C1/C2의 subject2 고조파 배가(64→128)는 미세조정 후에도 잔존(clean 조건은 학습 분포에서 과소 대표: 10영상 중 2영상만 clean). 학습 데이터에 clean 비중 확대 또는 파형 고조파 다양화로 개선 여지.

## 타당성 위협 (정직한 한계 — 설계서 V1~V4 대응)

- **V4 순환성**: 평가 노이즈가 학습과 같은 생성기 계열(파라미터·시드는 상이). 개선폭은 과대추정일 수 있음 — held-out 노이즈 유형·강도 외삽 셀은 본 실험(풀 그리드)에서 검증 필요.
- **소규모**: 학습 10영상·평가 정체성 4명(파일럿). 설계서의 정식 그리드(학습 108클립, 평가 324클립) 대비 축소판.
- **T1 대조군 미실행**: clean-only 미세조정 대조가 없어 "합성 도메인 적응"과 "노이즈 학습" 기여가 미분리. C3~C6의 회복이 C1에서 안 나타나는 패턴은 노이즈 학습 기여를 시사하지만, T1 실행으로 확정해야 함.
- **H3 sim-to-real 미검증**: 실데이터(PURE/UBFC-rPPG) 전이는 다음 단계.

## 재현

```bash
# 데이터셋: configs/{train,test_C*}.json → build_synth_dataset.py
# 기준선: yaml/base_C*.yaml (main.py only_test, UBFC_PhysFormer 사전학습)
# 미세조정: yaml/finetune.yaml (MODEL.RESUME 패치 필요 — PhysFormerTrainer.py 참조)
# 평가: yaml/ft_C*.yaml → 고해상 MAE는 saved_test_outputs pickle 후처리
```

rPPG-Toolbox 로컬 패치 3건: MODEL.RESUME 로드(PhysFormerTrainer), PhysMamba 임포트 우회, opencv 4.10 고정.

# 2단계: 귀인 분리(T1) · 외삽(E1–E3) · 반복 시드 (2026-08-21 추가)

## 실험 구성

- **T1 대조군**: 동일 정체성·BPM·시드의 **clean-only(무노이즈·균일)** 학습셋으로 미세조정 — "합성 도메인 적응"과 "노이즈 학습" 기여 분리.
- **T2L**: 학습 20영상(신규 BPM·노이즈 10 추가)으로 확장 + **학습 시드 3회(100/200/300)** 반복 (main.py RPPG_SEED 패치).
- **외삽 평가**: E1 조명 강도 외삽(drift 0.30/flicker 0.06@0.8Hz — 학습 최대 0.20/0.04), E2 움직임 강도 외삽(25px/5°/scale 0.04 — 학습 최대 15/3/0.02), E3 **유형 외삽**(주기적 끄덕임 12px@0.35Hz + 색온도 드리프트 0.12 — 학습 생성기에 없던 유형).
- UBFC-rPPG 실데이터(H3): 공개 Drive 링크 확인했으나 대용량 파일이 쿼터로 차단 — **수동 다운로드 필요**(평가 yaml `yaml2/ev_*_UBFC.yaml` 준비 완료, 데이터만 넣으면 즉시 실행).

|------|------|------|------|------|
| C1 clean | 16.16 | 16.05 | 16.11 | — |
| C2 patch | 32.22 | **0.09** | 16.10 | — |
| C3 illum | 10.54 | 10.48 | **0.14** | 0.14±0.00 |
| C4 motion | 33.56 | 0.09 | **0.15** | 0.11±0.03 |
| C5 il+mo | 10.54 | 10.60 | **0.15** | 0.15±0.00 |
| C6 all | 10.66 | 10.54 | **0.09** | 0.09±0.00 |
| E1 illum↑↑ | 16.11 | **27.57** | **0.09** | 0.11±0.03 |

고전(참고): POS/CHROM은 E1–E3에서 0.42~0.47 — 무채색 조도 변화에 대한 **설계적 불변성** 보유.

## 핵심 발견 (그림: `phase2_attribution_extrapolation.png`)

1. **귀인 분리 성공 — 조명 강건성은 노이즈 학습의 몫이다.** T1(clean-FT)은 움직임(C4, E2)·패치(C2)·신규유형(E3)은 해결하지만(합성 영상의 자연 움직임에 대한 도메인 적응), **조명 조건(C3/C5/C6)에서 base와 동일하게 실패**(~10.5, 플리커 락인 지속)하고 강한 조명(E1)에서는 base보다 **악화**(16.1→27.6). 반면 T2는 전 노이즈 조건 ≤0.15. → **조명 플리커 강건성은 도메인 적응이 아니라 노이즈 증강 학습이 만든다** (설계서가 요구한 핵심 증거).
2. **외삽 일반화 (V4 방어)**: T2는 학습 범위를 넘는 강도(E1, E2)와 학습 생성기에 없던 유형(E3)에서도 ≤0.15 BPM.
3. **시드 안정성**: T2L 3시드 표준편차 ≤0.03 BPM — 결과가 특정 시드의 우연이 아님.
4. **잔존 이상**: C1(clean)에서 전 모델이 16.1 — 특정 정체성(subject2, GT 64)의 2× 고조파 오검출이 clean-uniform 조건에서만 지속. T1은 패치(C2)에서 이를 해결하지만 T2는 미해결 — 경계선상의 고조파 모호성으로, 파형 고조파 구성의 후속 분석 필요.

## H3: UBFC-rPPG 실데이터 평가 (2026-08-22, 수동 다운로드 완료 후 실행)

DATASET_2 전체 42명, toolbox 표준 전처리(HC crop, 128², DiffNormalized, 160청크), FFT 지표.

| 모델 | MAE | RMSE | Pearson | SNR(dB) |
|------|-----|------|---------|---------|
| base (UBFC 사전학습) | **1.28** | 3.72 | 0.978 | +1.65 |
| T1 clean-FT | 5.25 | 13.93 | 0.776 | −2.43 |
| T2 noise-FT | 3.54 | 9.67 | 0.837 | −0.34 |
| **T2L 확장 noise-FT** | **1.78** | 3.92 | **0.974** | +0.14 |

**해석 (정직한 프레이밍):**
- base 체크포인트는 UBFC로 **학습된** 모델이므로 1.28은 제로샷이 아니라 in-domain 상한선이다. 반면 미세조정 모델들은 실데이터를 본 적이 없다 → 이들의 성능이 진짜 전이 측정.
- 합성 미세조정은 **망각(catastrophic forgetting)**을 유발하되 그 정도가 학습 데이터 구성에 좌우된다: T1(clean 합성) 5.25로 최다 망각 → T2(노이즈 증강) 3.54 → **T2L(확장·다양화) 1.78로 in-domain 상한 대비 +0.50 BPM까지 회복** (Pearson 0.974 유지).
- 즉 **노이즈·조건 다양성은 합성 도메인 과적합을 막는 정규화로 작동**하며, T2L은 합성 노이즈 강건성(C3–C6/E1–E3 ≤0.15)과 실데이터 성능(1.78)을 **동시에** 보유한다. H3의 우려(합성 학습이 실데이터 성능을 파괴)는 다양성 확보 시 크게 완화됨.
- 잔여 격차(+0.50)와 SNR 저하는 실데이터 재혼합(synthetic+real co-training)으로 닫을 수 있을 것 — 후속 과제.

# 3단계: Synthetic+Real Co-training + SiNC 주파수 사전 (2026-08-22)

## 구성

- **분할(명시적·물리적)**: 실데이터 UBFC 42명을 번호 정렬 후 앞 34명 → co-training, **뒤 8명(subject42–49) → held-out REALTEST**(2단계의 "전체 42명 평가"와 달리 base의 학습 범위 밖 순수 평가). 합성 TRAIN20은 subject201–220으로 개명해 COTRAIN(54영상)에 합침.
- **모델**: CoT = COTRAIN 미세조정(사전학습에서 시작, 10ep, LR 5e-5). CoTS = CoT + **SiNC-rPPG(Speth et al., CVPR 2023) 영감 주파수 사전 손실**(대역 42–240 BPM 밖 파워 벌점 + 대역 내 피크 ±6 BPM 희소성; 가중 1.0/0.5, 트레이너에 env-게이트 패치). CoTS2 = 저가중(0.1/0.05).

## 결과 1 — 실데이터 held-out (subjects 42–49)

| 모델 | MAE | Pearson | SNR(dB) |
|------|-----|---------|---------|
| base | 1.43 | 0.941 | +1.99 |
| T2L (합성만) | 1.87 | 0.897 | +0.43 |
| **CoT** | **1.43** | 0.941 | **+2.16** |
| **CoTS** | **1.43** | 0.941 | **+2.36** |

**co-training은 실데이터 격차를 완전히 닫았다** — MAE가 base와 동일해지고 SNR은 base를 상회. SiNC 사전은 실데이터 SNR을 추가로 +0.20dB 개선.

## 결과 2 — 합성 노이즈 강건성 유지 여부 (HR MAE)

| 조건 | T2L(참고) | **CoT** | CoTS2(0.1/0.05) | CoTS(1.0/0.5) |
|------|-----|-----|------|------|
| C3 illum | 0.14 | 0.14 | 0.14 | 52.77 |
| C4 motion | 0.11 | 0.15 | 0.15 | 33.50 |
| C5 il+mo | 0.15 | 0.15 | 17.54 | 56.23 |
| C6 all | 0.09 | **17.54** | 18.03 | 52.65 |
| E1 | 0.11 | 0.09 | 0.09 | 52.71 |
| E2 | 0.09 | 0.09 | 0.09 | 52.77 |
| E3 | 0.15 | 0.15 | 0.09 | 33.50 |
| 노이즈 평균(C3–C6) | 0.12 | 4.50 | 8.96 | 48.79 |

CoTS2 실데이터: MAE 1.43 / Pearson 0.941 / SNR **+2.21dB** (base +1.99, CoT +2.16, CoTS +2.36).

## 해석 (그림: `phase3_cotraining_sinc.png`)

1. **co-training이 잔여 격차를 완전히 닫았다**: CoT는 held-out 실데이터에서 base와 동일 MAE(1.43)에 도달하고 SNR은 base를 상회(+2.16 vs +1.99). 합성 강건성도 거의 유지(최난도 복합 C6만 17.5로 부분 퇴행 — 실데이터 비중 34/54가 최난도 조건 학습을 희석한 것으로 추정).
2. **SiNC 주파수 사전은 용량 의존적 트레이드오프**: 실데이터 SNR은 가중치에 비례해 개선(+1.99→+2.21→+2.36)되지만, 합성 **대역 내 주기 노이즈** 강건성은 반비례로 훼손(고가중에서 붕괴 48.8, 저가중에서 C5/C6 부분 퇴행 8.96). **메커니즘**: bandwidth+sparsity 사전은 "대역 내 희소 피크"면 무엇이든 보상 — 1.1Hz 플리커 같은 in-band 주기 교란도 사전을 완벽히 만족하므로, 사전이 강할수록 교란 락인이 정당화된다. SiNC 원 설정(실데이터·광대역 노이즈 비지도)에서는 드러나지 않는 제약으로, **"주파수 사전 ≠ 노이즈 강건성 사전"**이라는 일반적 시사점.
3. **권장 최종 모델: CoT** (실데이터 완전 회복 + 합성 강건성 최대 유지). 실데이터 SNR을 조금 더 원하면 CoTS2가 균형점.
4. 남은 퇴행(C5/C6의 ~17–18)은 co-training의 합성:실 비율/커리큘럼(합성 난도 상향 가중) 조정으로 닫을 수 있을 것 — 후속.

# 4단계: 실제 노이즈 환경 입증 (2026-08-22)

## 접근 — "실제 생리신호 + 통제 노이즈"

물리적 실측 노이즈 데이터셋(PURE=실제 머리움직임 라벨, MMPD=실제 조명·움직임 라벨)은 모두 이메일 신청제라 즉시 사용 불가(하단 신청 안내). 대신 **held-out 실데이터 8명(실제 산소포화도계 정답 포함)에 통제 노이즈를 입힌** 평가셋을 구축 — 신호는 실제, 노이즈는 통제. 조건 3종(합성 실험과 동일 파라미터, 시드 700대): 조명(드리프트+플리커 1.1Hz), 움직임(10px/2°), 복합.

## 결과 1 — 실제 얼굴에서의 플리커 락인 재현 (HR MAE / SNR dB)

| 조건 | 사전학습 base | 합성 노이즈학습 T2L | co-trained CoT | 강한 주파수사전 CoTS |
|------|------|------|------|------|
| 실+움직임 | 0.00 / +1.5 | 0.33 / −0.2 | 0.00 / +1.5 | 0.00 / +1.8 |
| **실+조명 플리커** | **30.32 / −16.9** (전원 동일 예측, 락인) | **18.35 / −2.7** (부분 방어) | 30.32 / −13.5 | 30.32 / −17.4 |
| 실+복합 | 30.32 / −18.3 | 16.92 / −3.3 | 30.32 / −14.9 | 30.32 / −18.2 |

**핵심 발견 2건:**
1. **합성에서 발견한 플리커 락인이 실제 얼굴·실제 생리신호에서 그대로 재현** — 사전학습 모델은 실데이터에서도 전원을 동일값(플리커 주파수)으로 추정. 합성 테스트베드의 실패 모드 진단이 실환경으로 전이됨을 입증.
2. **co-training의 맹점 노출**: co-trained 모델도 실+플리커에서 붕괴(30.32). 원인 — co-training의 실데이터 34명이 전부 clean이라 모델이 "실제 얼굴 도메인=조명 신뢰"라는 **도메인 조건부 지름길**을 학습. 노이즈 불변성은 합성 얼굴에서만 연습됨. 합성만으로 노이즈 학습한 T2L만 부분 전이(30.3→18.3).

2. **합성 미세조정이 배가를 악화**(base 6/20 → CoTN 10/20): 주입 파형(neurokit, 강한 2차 고조파)이 고조파 모호성을 학습시켰을 가능성 — 노이즈 분류에 **파형 형태(고조파 구조) 다양성 축이 빠져 있었다**는 taxonomy 격차. 테스트베드는 dicrotic 진폭을 파라미터로 다양화한 주입을 즉시 생성할 수 있으므로, 이것이 다음 개선 축.
3. UBFC(양호) vs MCD(붕괴)의 차이: 카메라 ISP·mpeg4 압축·피부 채도 차이가 신호의 고조파 비율을 바꾸는 것으로 추정 — 고전 방법은 견디고 학습 모델은 취약.

# 6단계: 파형 고조파 다양화 재학습 — CoTNH (2026-08-25)

5단계에서 확인된 taxonomy 격차(파형 고조파 구조 축 부재)를 메우는 재학습. 목표는 MCD에서의 고조파 배가 붕괴 해소와 HR MAE 최소화.

## 학습 데이터 확장 (COTRAIN_H, 108클립)

기존 양 도메인 노이즈 co-training 풀에 두 축을 추가:
1. **고조파 다양화 주입**: 해석적 파형 p(θ)=sin θ + a₂sin(2θ+φ₂) + a₃sin(3θ+φ₃), 2차 고조파 비율 a₂∈{0, 0.15, 0.3, 0.45, 0.6, 0.75}로 20클립 — 기본파-고조파 모호성을 데이터로 깨뜨린다.
2. **압축 증강**: 실·합성 클립의 mpeg4 q6 재인코딩 사본 20클립(정답 불변) — MCD류 소비자 카메라 압축 조건 반영. 압축 후에도 주입 맥파가 생존함을 사전 검증.

## 결과 — HR MAE (BPM)

| 평가 축 | 이전 최고(CoTN) | **CoTNH** |
|------|------|------|
| MCD 안정 20명 | 42.63 | **5.19** (Pearson 0.627, 배가 0/20) |
| MCD 운동직후 20명 | 32.65 | **19.91** (배가 2/20, 반감 2/20) |
| UBFC held-out 8명 | 1.43 | **1.10** (Pearson 0.964, SNR +1.96dB — 역대 최고) |
| 실데이터+플리커 | 0.00 | 1.10 |
| 실데이터+색온도 | 1.43 | 1.43 |
| 합성 복합노이즈·강노이즈·외삽 | 0.00 | 0.00 (유지 완벽) |

## 해석

1. **고조파 다양화가 배가를 해소**: MCD 안정 상태에서 배가 0/20 — 42.63→5.19는 파형 형태 축 하나를 채워 얻은 개선. 고전 POS(4.75)에 0.44 차이로 근접.
2. **잔여 병목은 고심박 외삽**: 운동직후 오차는 대부분 GT 102~127 BPM 구간의 반감·저편향 — 학습 BPM 상한(≈118)을 넘는 구간. 파형 문제가 아니라 주파수 범위 문제.
3. 대응(진행 중): 고심박 합성 클립(122~152 BPM, 6클립) + 평가와 겹치지 않는 MCD 정체성 21~44번 학습 풀(48클립) 추가 → **CoTNH-M** 학습. 후자는 in-domain 적응이므로 결과 보고 시 제로샷과 명확히 구분 표기한다.

## 통계 검정과 정직한 한계 (병렬 세션 분석, `_workspace/17_harmonic_diversity_analysis.md`)

- 안정 상태에서 양 도메인 co-training→고조파 다양화(CoTN→CoTNH) 개선은 Wilcoxon **p<.001, r=.87**로 유의. 그러나 **사전학습(base) 대비로는 p=.057(경계)** — 배가를 없애는 대신 4명(subjects 5·9·14·20)에서 −18~−24 BPM 저편향이 새로 생겼기 때문. 운동직후는 base 대비 비유의(p=.33).
- 배가 카운트는 기준 의존적: 엄격 2× 기준 base 5/20·CoTN 8/20, ≥140 BPM 락인 기준 7/20·10/20 (본 보고서 앞선 표기 6/20·10/20은 느슨한 기준). 정본 카운트는 17 문서를 따른다.
- **귀인 한계**: CoTN→CoTNH는 파형 다양화(합성 20클립 교체)와 압축 증강(20클립 추가)이 **동시에** 바뀌어 단독 효과를 주장할 수 없다 → ablation 2종(압축만 CoTNC / 파형만 CoTNW) 학습을 체인 2로 진행 중.
- 파형 분석(`_workspace/12_waveform_harmonics.md`): "neurokit 2차 고조파가 비정상적으로 강하다"는 5단계 추정은 **기각**(a2=0.59는 실 PPG 분포의 61~81 백분위). 진짜 결함은 **다양성 부재**(폭 0.11)와 밀도 불일치(TRAIN20H는 a2<0.3에 55% 배치, 실데이터는 2.3%). 실분포 정합 재설계 **TRAIN20H2**(a2 0.34~0.85, φ2·a3·φ3 실분포 표본) 기반 **CoTNH2**도 체인 2에 포함.

- 트레이드오프: CoTA의 UBFC held-out 2.53(CoTNH-M 0.00 대비 양보) — 풀 확장에 따른 배분 문제로, 균형 풀(clean:noisy·BPM 평탄화, 병렬 세션 COTRAIN_BAL) 실험이 후속.

## PhysFormer++ (Yu et al., IJCV 2023, arXiv:2302.03548) 와의 비교

**직접 수치 비교는 불가** — 평가 코퍼스가 전혀 겹치지 않는다(PhysFormer++: VIPL-HR/MAHNOB-HCI/MMSE-HR/OBF, 전부 접근 제한·fold 프로토콜; 본 연구: UBFC/PURE/MCD/DLCN/MR-NIRP). 공개 가중치·toolbox 구현이 없어 재실행 비교도 불가(한계로 명기). 유효한 비교는 **개선 축과 개선 폭**:

| | PhysFormer++ (아키텍처 중심) | 본 연구 (데이터 중심) |
|---|---|---|
| 개입 | 백본 교체: SlowFast 시간차 트랜스포머 + 주기/교차 어텐션 | 백본 고정(원 PhysFormer), 학습 코퍼스 설계: 합성 주입·노이즈/파형/BPM 커버리지·다중 실코퍼스 co-training |
| 필요 자원 | VIPL-HR(107명) 지도 학습 | 합성(가상얼굴 주입) + 소규모 실코퍼스(UBFC 34명 등) |
| intra-dataset 개선 | VIPL 4.97→4.88 (−1.8%), MAHNOB 3.25→3.23, OBF RMSE 0.804→0.765 | (해당 프로토콜 없음) |
| cross-dataset 개선 | VIPL→MMSE-HR: 2.84→2.71 (−4.6%) — 유사 실험실 도메인 | 동일 백본의 교차 코퍼스 실패 축을 자릿수 단위로 개선: MCD 29.27→0.48(−98%), PURE 10.67→0.39(−96%), 미학습 운전 13.41→7.49(−44%) |
| 스트레스 축 | 실험실 조건 위주 | 압축(MCD)·실차 운전(MR-NIRP)·조명 플리커·고조파/BPM 커버리지 |

**해석**: PhysFormer++의 아키텍처 개선은 동일 도메인 내 수 % 수준인 반면, 본 연구가 겨냥한 실패 모드(고조파 배가·플리커 락인·BPM 커버리지)는 아키텍처가 아니라 **학습 분포의 결함**이며 데이터 개입으로 자릿수 개선이 가능함을 보였다. 두 접근은 직교적 — 본 방법(주입 합성 + 다중 코퍼스 co-training)은 백본 불문이므로 PhysFormer++ 위에도 그대로 적용 가능하고, 공개 가중치가 나오면 본 평가 스위트(UBFC/PURE/MCD/DLCN/MR-NIRP)로의 편입이 즉시 가능하다.

### 16-8. 방법 개선 — 해부학 기반 공간 진폭 지도 A(x,y) (`scripts/anatomical_amplitude_map.py`, 빌더 `spatial: anatomy`, `run_chain20_scale300ra.sh`, yaml29, 진행 중)
