# 49. 플리커 개정판 코퍼스 실험 (체인 68, 2026-10-28, 사용자 지시 "플리커 개정판 코퍼스 실험도 이어서 진행")

사전 등록. 48 §5.5 의 결론(공식 코퍼스의 플리커 성분이 VIPL 에 ≈0.35 의 비용을 지우되, 빼면 플리커·MMPD 움직임·근적외선 소동작 강건성을 잃는다)에서 나온 후속: **플리커를 빼지 않고 바꾼다**. 목표 = "VIPL 비용 0 + 플리커 강건성 유지(학습 띠 밖 주파수 포함)".

## 1. 코퍼스 개정 사양 (`COTRAIN_ALLF_TWFR`, `scripts/make_fr_pool.py`)

공식 코퍼스 203 클립과 **클립 단위로 일치**(48 §1.3 의 짝 풀 방식: 같은 시드·같은 드리프트/움직임/센서; 움직임 전용 변형 재생성본이 원본과 프레임 동일함을 매핑 검증). 플리커가 있던 49 클립(실 잡음 사본 27·가상 16·압축 사본 6)만 다음과 같이 바꾼다.

| 항목 | 공식 코퍼스 | 개정판 |
|---|---|---|
| 플리커 주파수 | 0.9–1.3 Hz(54–78 bpm, 심박 대역 안 좁은 띠) | **0.8 / 1.0 / 1.3 / 1.6 / 1.9 / 2.2 / 2.5 Hz 순환**(클립 인덱스로 결정, 48–150 bpm 전역) |
| 플리커 진폭 | 0.02–0.04 | **0.02 고정** |
| 플리커 클립 수 | 49 | 49(동일) |
| 그 외 교란·시드 | – | 동일 |

기록: `COTRAIN_ALLF_TWFR_flicker_log.json`(클립별 주파수·진폭).

## 2. 평가 축 추가 — 띠 밖 플리커 (`scripts/make_flicker_axes.py`)

기존 RTNI/RTNC 의 플리커는 1.1 Hz(학습 띠 안)뿐이라 "띠 밖 일반화" 를 못 본다. REALTEST(UBFC held-out 8명)에 같은 생성 함수로 **RTNI17(1.7 Hz)·RTNI24(2.4 Hz)**, 드리프트 0.15·진폭 0.03(RTNI 와 동일)을 추가한다. 공식 3시드·플리커 제거 3시드·개정판 3시드를 모두 이 축에서 평가한다(`scripts/flicker_axes.py` → `results/flicker_axes.{txt,json}`, 정본 읽기 `agg_model2.hr_for`).

## 3. 셀·가설·판정 (영상 단위 쌍대 Wilcoxon, 3시드 영상별 평균 풀링, `realonly_judge.py`)

셀 `CoTAF_FR_L`(시드 100·200·300): 채택 레시피 PhysFormer(UBFC 체크포인트 이어학습, cumsum 라벨, 10 epoch) 를 개정판 코퍼스로 학습 → 13축 + MMPD + VIPL + RTNI17/24. 비교 = 공식 `CoTAF_TW_L`(3시드), 플리커 제거 `CoTAF_NOFLK_L`(3시드).

| 가설 | 비교 | 지지 기준 |
|---|---|---|
| **H-R1 VIPL 비용 제거(1차)** | 개정판 vs 공식, VIPL 문헌 GT 전체 | Δ ≤ 0 이고(개선 또는 ns), 개정판 vs 플리커 제거 Δ ≤ +0.2(비열등) |
| **H-R2 플리커 강건성 유지(1차)** | 개정판 RTNI(1.1 Hz)·RTNI17·RTNI24 | 세 축 모두 MAE < 5(lock-in 없음); 공식 모델의 띠 밖(1.7/2.4) 수치 병기 |
| H-R3 다른 강건성 비용 없음 | 개정판 vs 공식, MMPD 움직임·MR-NIRP 소동작 | Δ ≤ +0.5 또는 ns |
| H-R4(탐색) | 공식 모델의 띠 밖 플리커 lock-in 여부 | 공식 RTNI17/24 ≥ 20 이면 "공식의 플리커 강건성은 띠 한정" 확정 |

판정 규칙: H-R1·H-R2 둘 다 충족 → 개정판을 **코퍼스 v2 후보**로 채택 제안(공식 모델 교체는 사용자 결정, 전 축 재검토 필요). H-R1 만 충족(플리커 강건성 상실) → "진폭 0.02 가 너무 낮음" 으로 기록하고 진폭 0.03 변형은 후속 결정. H-R2 만 충족 → 주파수 분산으로는 VIPL 비용이 안 사라짐 → 비용의 원인은 '플리커의 존재' 자체로 귀속. 모두 미충족 → 기록 후 종료.

비용: 재생성 ≈1 h CPU(병렬 2 작업), 학습·평가 3시드 ≈ 3 × 1.5 h, 띠 밖 축 평가 9 모델 × 2 축 ≈ 20 분 → ≈ 6 h. 체인 67(NF 절제)과 GPU 병행.

**판정**
- **H-R1 기각**: 주파수 분산·진폭 하향으로는 VIPL 비용이 사라지지 않았다(공식 대비 +0.07, p=.03; 플리커 제거 대비 +0.42, p<.0001 로 비열등 기준 +0.2 초과). 사전 등록 규칙대로 VIPL 비용의 원인은 '플리커의 존재(균일 밝기 변조 사본의 학습)' 자체로 귀속한다.
- **H-R2 지지**: 개정판은 1.1 / 1.7 / 2.4 Hz 모두 MAE < 2.3 으로 **광대역 플리커 강건성**을 얻었다.
- **H-R4 확정(새 발견)**: 공식 코퍼스 모델의 플리커 강건성은 띠 한정이다 — 1.1 Hz 0.92, 1.7 Hz 4.69, **2.4 Hz 41.2(완전 lock-in)**. 논문의 플리커 주장은 "1.1 Hz 통제 플리커" 로 한정해야 하며, 광대역 주장을 하려면 개정판(또는 그 변형) 코퍼스가 필요하다.
- **H-R3 기각**: MMPD held-out 이 공식 대비 +1.05(p=.002) 나빠져 플리커 제거 수준(11.56, ns)으로 돌아갔다 → 공식 코퍼스의 MMPD 이득은 1.1 Hz·진폭 2.5–4% 의 강한 플리커 사본에서 왔다(휴대폰 영상의 저주파 밝기 변조와 맞물린 것으로 추정). 근적외선 소동작은 공식 대비 -0.37(p=0.9652).

**결론**: 플리커 성분은 세 가지를 동시에 만족시키지 못한다 — (i) VIPL 비용 0 (플리커 없음이 최선, −0.35) (ii) 광대역 플리커 강건성(개정판만) (iii) MMPD 움직임 이득(공식의 강한 1.1 Hz 플리커만). 코퍼스 설계는 용도별 선택이 된다. 후속 후보(미실행, 사용자 결정): 개정판 + 진폭 0.03(MMPD 이득 회복 여부), 또는 공식 1.1 Hz 사본 + 띠 밖 주파수 사본을 섞는 혼합판. 논문 서술: 플리커 강건성은 학습 띠 한정(공식) 또는 광대역(개정판)으로 코퍼스 판본과 함께 명시, VIPL 비용 ≈0.35 명시.
