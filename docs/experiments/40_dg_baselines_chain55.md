## 1. 왜
38 문서(근거 행렬)에 대한 탑티어 적합성 평가(10-22)에서 방법 논문의 결격 사유로 든 세 가지에 대응한다 — 사용자 지시 "권고 내용으로 추가 실험 진행".
1. **같은 학습 데이터로 최신 일반화 기법과 비교**가 없다 → 공식 코퍼스(203 클립) 위에 도메인 일반화(DG) 기준선 3종을 학습해 채택 모델과 비교한다.
2. **분해 손실을 그 기준선 위에 얹었을 때 MMPD 외의 움직임 데이터에서도 이득이 나는지** 증거가 없다 → DG 기준선 × {기본, +분해 손실} 요인 설계, 움직임 축은 MMPD 움직임·MR-NIRP 소/대동작·PURE 움직임 trial(03~06, held-out 피험자 7~10)·VIPL v2/v9 로 넓힌다.
3. **문헌 수치와 읽기 방식이 다르다** → VIPL 2,378편을 문헌형 읽기(누적합 없음·3구간 Welch)로 재집계해 정본과 병기한다(모델 재학습 없음).

최강 백본(FactorizePhys) + 우리 코퍼스/분해 손실은 체인 54·54b(39 문서 §6·§7)에서 이미 기각되었으므로 반복하지 않는다 — VIPL 9.43/8.44 vs 공개 6.88 악화, MMPD 정본 float 경로 3시드 코퍼스 10.60 vs 공개 9.79(+0.81, Holm p=.023 악화)·분해 10.66(ns). 신규 휴대폰 데이터는 없다(범위 외, §7).

## 3. DG 기준선 구현 (툴박스 패치 #35 `RPPG_DG`, `neural_methods/trainer/dg_utils.py`; 하이퍼파라미터는 문헌 기본값으로 사전 고정, test 로 조정하지 않음)
도메인 라벨은 풀의 심볼릭 링크 출처(`scripts/dg_domain_map.py` → `dg_domains_<POOL>.json`, 청크 이름 `subjectN` 키). DG 가중은 감독 항(a·NegPearson + b·(주파수 CE + KL))의 **샘플별** 값에만 적용하고 하이브리드·SiNC 항은 그대로 더한다.
- **GroupDRO**(Sagawa et al. ICLR 2020): 도메인 가중 q 를 온라인 지수 갱신 q_d ← q_d·exp(η·L_d) (η=0.01, 정규화), 손실 = Σ_{배치 내 도메인} q_d·L_d.
- **V-REx**(Krueger et al. ICML 2021): 배치 내 도메인별 위험의 평균 + β·분산(β=1.0; 도메인 1개면 0).
- **DANN**(Ganin et al. JMLR 2016): transformer3 출력 토큰 평균(64-d) 위 2층 도메인 분류기 + 기울기 반전, λ = 0.1·(2/(1+e^{−10p})−1), p = 학습 진행률; 분류기는 별도 Adam(같은 lr).
배치 4 라 한 배치에 보통 2~4 도메인이 들어간다(V-REx·GroupDRO 는 배치 단위 추정, 문헌 구현과 동일한 제약). 검증: 단위 검사(가짜 모델)·스모크(VIPL 40청크 × 3 방법 + 하이브리드+DANN) 통과(08:00); 체인은 `DG stats epoch 9: method=…` 줄과 `miss=0`(도메인 미매핑 0)을 확인하고 없으면 실패한다.
선택 근거: NEST·HSRD 등 rPPG 전용 DG 논문이 공통으로 두는 범용 DG 기준선(GroupDRO·VREx·AD/DANN)이며 공식 코드 이식 없이 손실 수준에서 정확히 재현 가능하다. NEST·HSRD 자체의 재구현은 범위 외(§7).

**해석과 원고 서술(38 §G 반영)**
1. 범용 DG 기준선은 "전 축 동시 개선" 을 주지 못했다(F1 기각). 따라서 "채택 모델 < 범용 DG" 는 아니다.
2. 그러나 GroupDRO 셀이 VIPL zero-shot 에서 채택·분해 모델을 3시드로 유의하게 이긴 사실은 그대로 적어야 한다. 그 실체는 **MCD 48 클립(휴대폰·실내, VIPL 과 조건 유사)에 사실상 단독 적합한 모델**이고, 그 대가로 PURE·통제 노이즈·MMPD 가 무너진다 — 이는 33 §6 의 귀속("공식 코퍼스 zero-shot 우위의 원천 = PURE·MCD 실 클립")을 강하게 뒷받침하며, VIPL 전이에 가장 중요한 학습 데이터가 MCD 임을 보여 준다(새 발견, 후속: MCD 비중/가중을 명시적으로 조절한 코퍼스 설계는 사후 실험).
3. 분해 손실은 세 DG 위에서 모두 휴대폰 움직임 오차를 줄였다(F2) — "플러그인 이득" 서술은 유지하되 MR-NIRP·PURE 비확장을 함께 적는다.
4. "우리 분해 모델 > DG 기준선" 주장은 할 수 없다(F3 기각). 방법 논문의 포지셔닝은 §9 의 결론대로 "분해 목적함수 = 휴대폰 움직임용 플러그인" 이며, 성능 최강 주장은 하지 않는다.
5. 운영: Phase 1 6셀 + Phase 2 4셀 = 10 run, 17:17→00:46(7.5 h, 예상 1~2 일보다 훨씬 빠름 — 풀 캐시 재사용·GPU 여유). 풀 캐시 2종 삭제 완료.
