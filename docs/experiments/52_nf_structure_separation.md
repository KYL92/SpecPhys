# 52. NF-Phys 구조 연구 — rPPG 와 교란 잡음의 신호 분리 (2026-10-30, 사용자 지시)

사용자 지시: "rank-2 교란 인수분해·시간 축 정렬 구조가 의미 있어 보인다. 이 모델을 기준으로 네트워크 구조의 기여를 더 깊게 연구하고 싶다. 핵심 쟁점은 rPPG 와 교란 잡음의 신호 분리."
배경(48 §5.4·§6.1): 평균 심박 MAE 로는 rank-2 교란 인수분해의 기여가 0(5.82 vs 5.81 vs 6.04, 전 축 ns). 그러나 심박 MAE 는 분리의 질에 둔감하다. 이 문서는 **분리 자체를 측정**하고, 분리가 결정적인 조건(교란과 맥파의 주파수·공간 중첩)에서 구조 효과를 검정하는 연구 설계다.

## Phase A — 진단: 학습된 슬롯은 무엇을 잡는가 (`scripts/nf_slot_probe.py`, 10-30, 학습 없음)

통제 교란 축의 캐시 청크(72×72 Raw, 160프레임)에 체크포인트를 돌려 슬롯 프로파일 s_p(맥파)·s_n(교란)을 추출하고, 정답 맥파(PPG)와 **알려진 교란 궤적**(gain = 1 + 드리프트 + 1.1 Hz 플리커, make_noisy_real 과 같은 시드로 재생성)의 차분과 상관(|r|, 청크 평균)을 쟀다. PURE 는 교란 없는 청정 대조.

**읽기(정직)**
1. 교란 슬롯은 교란을 잡는다(감독 셀 0.95) — 그러나 **초기값인 전역 밝기 trace 자체가 이미 0.97** 이다. 즉 균일 플리커·드리프트에서 슬롯이 해낸 분리는 "전역 평균을 빼는 것" 과 같고, 감독은 슬롯이 초기값에서 벗어나지 않게 붙잡는 역할만 했다(감독 없는 셀은 0.76–0.80 으로 흘러간다).
2. 맥파 슬롯의 질(corr 0.60–0.65)·출력 SNR(0.35–0.40)·청크 HR 오차는 rank-1 과 같다 → 맥파 슬롯만으로 만든 어텐션이 더 깨끗한 맥파를 주지 않았다. 누설(0.09 vs 0.12)은 감독 셀이 약간 낮으나 작다.
3. 청정 PURE 에서 감독 셀의 교란 슬롯이 맥파를 더 흡수한다(0.27 vs 0.20): 교란이 없으면 전역 trace 가 곧 맥파라서 생기는 예측된 부작용(48 §8 ③-i). 다만 HR 오차는 오히려 낮아(1.65 vs 1.9) 해롭지 않았다.
→ **결론**: 지금까지의 교란(공간 균일·주파수 비중첩)은 트렁크(차분 + 인스턴스 정규화 + 코퍼스 학습)만으로 이미 제거되며, rank-2 구조가 추가로 분리할 몫이 없다. 구조가 의미를 가질 수 있는 영역은 **전역 trace 로 잡히지 않는 교란**(공간 비균일 조명·국소 움직임·스펙트럼 중첩)이다. Phase B 는 그 조건을 만든다.

**Phase A+B1 종합**: 균일 조명 교란(드리프트·플리커, 주파수 중첩 포함)에서 rank-2 교란 인수분해는 전역 밝기 trace 를 다시 만드는 것 이상을 하지 않는다. 구조 연구를 계속하려면 전역 trace 로 표현되지 않는 교란(B3: 반쪽 그림자·이동 반사광·국소 움직임)을 생성기에 추가해 rank-1 과 rank-2 의 격차가 생기는지 먼저 확인해야 한다(격차가 없으면 구조 연구 종결). 다음 단계 = B3 생성기 확장(≈반나절) → 기존 체크포인트 평가 → 격차 시 C2–C5 학습.

**읽기(정직)**
- 공개 FactorizePhys(rank-1, UBFC 만)는 교란이 커질수록 단계적으로 플리커·움직임에 고정된다(그림자 20%·움직임 24 px·복합에서 4/4 편 오차 = 정확히 6 bpm). 즉 스트레스 세트는 분리를 요구하는 조건을 만드는 데 성공했다.
- **코퍼스로 학습한 세 변형은 rank·감독과 무관하게 모든 조건에서 ≤0.12 bpm** — 공간 비균일 교란, 심박 근접 주기 움직임, 복합 조건까지 rank-1 이 이미 포화 상태라 rank-2 가 보여줄 격차가 없다.
- 따라서 **H-D1 기각(전 조건)**: 전역 trace 로 표현되지 않는 교란에서도 rank-2 교란 인수분해의 구조적 기여는 측정되지 않았다. 분리 능력은 코퍼스(교란 다양성) + 스펙트럼 손실이 트렁크에 심어 주며, 명시적 인수분해 슬롯은 그 위에 더할 것이 없다.

**구조 연구 결론**: Phase A(슬롯 진단)·B1(스펙트럼 중첩)·B2(주기 움직임)·B3(공간 비균일, 진폭 스윕·복합) 모두에서 rank-2 구조의 추가 기여 0. 실 축(MMPD·MR-NIRP·VIPL)도 ns(48 §5.4). 합성 스트레스에서 코퍼스 모델을 깨뜨리는 조건을 찾지 못했으므로, 구조 변형(C2–C5) 학습은 사전 등록 규칙대로 **실행하지 않는다**(격차가 없는 곳에서 구조를 비교할 수 없음). 남는 선택지(사용자 결정): (a) 구조 연구 종결 — 논문은 "코퍼스 + 스펙트럼 손실이 분리를 담당, 명시적 인수분해는 불필요" 로 서술(부정 결과로 가치 있음) (b) 코퍼스가 약한 실 조건(VIPL 운동 후·고심박, MMPD 보행)을 분리 문제로 재정의해 교란 정답이 없는 실 클립에서의 자기 지도 분리(예: 전역 trace 자기 감독 + 어텐션 공간 정칙화)를 설계 — 이는 "인수분해 구조" 가 아니라 "학습 신호" 연구가 된다.

가설(사전 등록 초안): **H-D1** B1·B2·B3 에서 rank-2(C1) 의 HR MAE·SNR 이 rank-1(C0) 보다 좋다(쌍대 p<.05) — Phase A 조건에서 0 이었던 구조 효과가 중첩 조건에서 나타난다. **H-D2** C2/C3 가 C1 보다 분리 지표(누설↓·포착↑)와 B 축 HR 을 더 개선한다. **H-D3** B 축 이득이 B4 실 축(MMPD 보행·MR-NIRP 대동작·VIPL v7)으로 전이된다. H-D1 이 기각되면 "구조 기여 없음" 을 중첩 조건까지 포함해 확정하고 구조 연구를 종결한다.

- 10-30 Phase A 완료(위 표, `results/nf_slot_probe.json`). B1 스트레스 세트 2종(심박 주파수 플리커 / +0.5 Hz, 4클립씩) 생성 중 → 기존 3 체크포인트 평가.
- 10-30 B1 완료: 스트레스 세트 4종(STRESS_INBAND6/NEAR6/NEAR12/OFFBAND6, 각 4클립) 생성·평가. 플리커=심박 조건은 판별 불능(설계 오류 기록), 근접 주파수에서 코퍼스 학습 변형 전부 분리·공개 FP 만 고정. 구조 기여 0 유지 → B3 로 진행 여부는 사용자 결정.
- 10-30 B2·B3 완료: 생성기 확장(공간 비균일 3종), 스트레스 12 조건 × 4 모델 평가 — 코퍼스 모델 전부 ≤0.12 bpm, 공개 FP 만 단계적 고정. H-D1 전 조건 기각, C2–C5 미실행(사전 등록 규칙). 종결/전환은 사용자 결정.
