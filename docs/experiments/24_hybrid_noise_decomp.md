# 22단계 — 하이브리드 심박/노이즈 분해 (체인 39, 2026-09-03 사전 등록)

사용자 목표: "노이즈 환경(MR-NIRP·MMPD)의 정확성 — 일상 적용 가능한 rPPG". 사용자 설계:
합성은 심박·노이즈를 모두 알 수 있으니 **둘 다 맞추게 학습**(이중 감독), 뱅크 파형 × 가상얼굴 × 주행/보행
노이즈로 코퍼스 공급, 실 영상은 분리하여 **심박은 SNR↑·노이즈는 반대 방향의 비지도** — 심박 감독·심박수
오차·SNR 비지도의 하이브리드.

## 구현
1. **노이즈 GT (합성의 고유 이점)**: builder `noise_gt` — 주입 없는(alpha=0) 병렬 경로를 동일 교란
   궤적·센서 draw로 렌더해 피부 평균 trace 추출 → DiffNormalized 규약으로 사이드카 저장(청크 정렬 보장).
   video 인코딩 불필요(트레이스만) — 비용 무시 가능.
2. **모델**: PhysFormer + 노이즈 헤드(upsample×2+Conv1d 복제, RPPG_NOISE_HEAD=1 게이트 생성,
   forward_dual). UBFC init은 strict=False(헤드만 신규).
3. **손실(하이브리드)**: 기본(Neg_Pearson + 주파수 CE/KL = 심박·심박수 오차 감독)
   + HYB_W_NOISE·Neg_Pearson(노이즈 헤드, 사이드카 GT — 합성 클립만)
   + HYB_W_DECOR·corr²(심박, 노이즈) 탈상관(전 클립)
   + SINC_PRIOR(대역+희소 = SNR↑ 방향 비지도, 전 클립 — 3단계 통합분 재사용).
4. **DN 24클립**: 주행 12(실 MCD 얼굴상자 궤적 이식 + 조명 드리프트 + 플리커) / 보행 12(1.6~2.4Hz
   주기 보행 진동 + 큰 랜덤워크 + 야외 조도 변화), 뱅크 v1 nearest, BPM 45~175. 코퍼스 = OFFICIAL 203 + 24.
5. **판정(§5 관행)**: CoTAF_HYB_L vs CoTAF_TW_L, 3시드, MMPD held-out 유의 + 타 축 무손실 + 방향 일치.
   관심 부표: NIRP 3축·Walking·Skin 6·halving. 트랙 B 라우팅 상한(oracle) 분석 병행(routing_oracle.py).

## 사전 기록 주의
- 요인 번들(DN 클립 + 노이즈 헤드/탈상관 + SiNC)이 한 구성에 결합 — 사용자 설계 의도대로 배치 지향.
  양성 시 요인 분해 ablation, 음성 시 개별 기여 미상으로 기록.
- 노이즈 GT는 '관측 가능한 휘도 노이즈 trace'(모션·조명·센서의 피부 평균 반영) — 공간적 노이즈 구조는 미포함.
- 코드: builder/PhysFormer.py/PhysFormerTrainer.py 패치, scripts/run_chain39_hybrid.sh (/tmp/chain39.log)

## 트랙 B 라우팅 분석 결과 (2026-09-03 00:40~, 무학습)

**상한(oracle)은 크다**: MMPD held-out 클립별 최적 선택 시 TW 10.51 → **5.5**(3-way TW/PM/POS, 선택 비중
54/24/22%) / 7.28(2-way TW/PM). NIRP도 8.5~10.4 → 5.0~6.9. 실 라벨 CV 상한(9.26)조차 하회 — 모델 간
오류가 강하게 상보적이라는 뜻.

**그러나 단순 관측 신호로는 실현 불가(정직한 null)**:
| 정책 | MMPD MAE | vs TW |
|---|---|---|
| median(3) | 10.46 | p=.48 |
| 최근접쌍 평균 | 10.88 | p=.85 |
| TW-PM 합의(5BPM)+쌍 | 10.91 | p=.77 |
| 출력 spec-SNR argmax | 12.00 | p=.002 (악화) |
| 출력 spec-SNR 3dB 마진 | 10.69 | p=.55 |

출력 SNR의 모델선택 정답률 0.59 < 항상-TW(0.69) — 신뢰 신호가 없음. 결론: **"어느 모델이 맞는가"는
예측·출력 통계에 담기지 않으며, 라우팅 이득을 실현하려면 라우터 자체를 학습해야 한다**(oracle 라벨로
학습하는 클립 분류기 — 후속 후보). 배치 가능한 것은 축(도메인) 단위 정책뿐: MMPD→TW, NIRP large→POS,
MCD 운동후·REALTEST→PM (표는 routing_oracle.py).

## 반복 계획 (goal: 성공까지 다각 반복 — 사전 등록)

## V1 결과 + 움직임 분할 표준 도입 (2026-09-03 04:3x)

사용자 지시로 **움직임 분할 평가 표준** 도입(scripts/motion_split_cmp.py, POS NIRP 기준선 scripts/pos_nirp.py):
집계 평균이 가리던 구조가 드러남.

+ **Walking에서 POS 유의 초과(17.51 vs 20.96, p=.012)**. 비용은 정지(8.19→8.78)와 깨끗한 축(PURE 4.02 등)에 집중.

**V1 시드 200** — 불안정: 정지 붕괴(7.94→11.03, p<.001), 움직임 이득 소실(11.46→11.80). SiNC/DN 요인의

**성공 조건 재정의(움직임 분할 기준)**: 움직임 조건 유의 개선의 3시드 일관 + 조건부 배치 종합 유의
+ 정지·타 축 무손실(배치 구조상 자동). V2부터 이 기준으로 판정.

## V2 결과 → V3 설계 (2026-09-03 07:2x)

**V2(SiNC off)** — 요인 분해 확정: 깨끗한 축 회복(PURE 0.51 vs V1 4.02) = SiNC가 손상 주범 ✓,
그러나 **움직임 이득도 소멸**(s100 움직임 11.84 ns·Walking 20.65, s200 12.19) = **SiNC가 이득의 원천이기도 함**.
정지 손상(9.12~9.46, s100 p=.033)은 DN/헤드 몫으로 잔존 → V2 기각.

| 요인 | 움직임 이득 | 깨끗한 축/정지 |
|---|---|---|
| SiNC 전역 (V1) | ✓ (s100 p=.038, POS 초과 p=.012) | 손상 (PURE 4.02, 시드 불안정) |
| DN+헤드+탈상관만 (V2) | ✗ | 정지 소폭 손상 |

**V3 (체인 39c, 대기 기동)**: SiNC를 **DN 샘플에만 선택 적용**(SINC_DN_ONLY 트레이너 패치 — 노이즈 합성
도메인에서만 SNR 사전 학습, 사용자 설계 의도의 정확한 구현) + DN 24→48(이득 신호 강화·시드 안정화).
판정: 움직임 분할 표준 — 움직임 유의 개선 3시드 일관 + 조건부 배치(정지=TW) 종합 유의 + 정지·깨끗 축 무손실.

## V3 결과 (2026-09-03 12:12) — 기각 (시드 일관성 실패)

SiNC DN-only는 **손상 제거에 성공**(s100 정지 7.67 개선·PURE 0.45, V1의 정지/깨끗 축 비용 소멸)했으나
움직임 이득이 시드 취약: s100 +방향(11.75)·s200 평탄(11.48, 단 Walking 17.94로 POS 유의 초과 p=.012)·
s300 −방향(12.53). NIRP 비용 재출현(small 19.06, s100). 3시드 일관 기준 미달.

패턴 종합: DN 24~48클립의 이득 신호가 시드 분산보다 작다 — 합성만으로는 움직임 이득을 안정화하기 부족.
→ **V4(+MMPD 1~6 in-domain 120클립, CoTAM 계열)**: 실 움직임/저SNR 라벨 데이터로 신호 자체를 키우는
결합 검정 (12:12 기동). 판정 기준 동일 + in-domain 기준선 CoTAM-L(9.98) 병기.
