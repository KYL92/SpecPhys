# 주입 파형 고조파 구조 검증 보고서 — "학습 파형 분포가 실제 PPG 파형 분포를 덮는가?"

작성: pulse-injection-engineer (2026-08-25). 모델 평가는 포함하지 않음(다른 에이전트 담당). CPU 신호 분석만.

## 요약 (정직한 결론)

1. **가설 "neurokit 파형은 2차 고조파가 비정상적으로 강하다" → 기각.** neurokit 등가 a2 = 0.59 (H2/H1 = 0.356)는 실 PPG 분포의 **61~81 백분위**(MCD 안정 76.5, 운동직후 61.0, UBFC 81.0)에 위치한다. 중앙값보다 높지만 정상 범위 안이며, 실데이터의 **28%는 neurokit보다 2차 고조파가 더 강하다**(운동직후는 39%).
2. **실제 결함은 "강함"이 아니라 "다양성 0"이다.** neurokit 파형은 BPM(50–120)·시드와 무관하게 a2 ∈ [0.50, 0.61], φ2 = −0.03±0.04 rad, a3 = 0.32±0.01로 **사실상 단일 점**이다. 실데이터는 a2 IQR 0.41–0.58(p5–p95 0.33–0.84, 최대 1.36), φ2 ±0.4 rad. 즉 학습 파형은 실분포의 한 점만 가르쳤다.
3. **TRAIN20H 해석적 그리드는 범위 커버리지는 좋으나(실 a2의 89%가 [0, 0.75] 안), 배분이 잘못됐다.** 클립 55%가 a2 < 0.3인데 실데이터에서 a2 < 0.3은 **2.3%**뿐이다. φ2도 0–2.8 rad 균등 배치인데 실 φ2의 97%는 |φ2| < 1.0 rad. 예산의 절반 이상이 실존하지 않는 파형에 쓰였고, 실데이터 상위 11%(a2 > 0.75)는 여전히 미커버.
4. **주입 무결성 정상.** TRAIN20H 20편 모두 POS 투영 픽셀 신호의 지배 주파수 = 기본파(20/20, a2 = 0.75 포함). GT 위상 lock-in으로 복원한 픽셀 a2의 MAE = 0.042(최대 0.14, 주입 노이즈 때문). FFV1 무손실 보존 확인.
5. **주목할 부수 발견**: (a) MCD 접촉 PPG 자체의 **3%가 스펙트럼 피크 = 2f0**(a2 > 1) — 정답조차 배가된 케이스가 있으나 모델 배가율(30–50%)을 설명하기엔 작다. (b) MCD `.PW`/`ppg_sync`의 저장 극성이 UBFC와 **반대**(형태 기준 100% vs 0% 반전) — HR 평가엔 무관하나 Pearson 계열 손실/파형 학습에는 유의.

## 1. 지표 정의 (`scripts/analyze_waveform_harmonics.py`)

- **스펙트럼**: Welch(20 s Hann, 50% 중첩, 0.01 Hz 제로패딩). 기본파 f0 = 0.6–3.3 Hz에서 고조파 합산 P(f)+P(2f)+P(3f) 최대점(배가 오검출 방지). H_k = k·f0 ± k·0.12 Hz 파워 적분 → **H2/H1, H3/H1**. `peak_is_f0` = 단순 argmax가 f0인지.
- **시간영역 적합(등가 a2/φ2/a3)**: 기본파 대역(0.7–1.3 f0) Hilbert 위상 θ(t)로 x ≈ Σ c_k sin kθ + s_k cos kθ 최소제곱 → a_k = |(c_k,s_k)|/|(c_1,s_1)|, φ_k = 기본파를 sin θ에 정렬한 상대 위상. `make_waveform`의 파라미터화 p = sin θ + a2 sin(2θ+φ2) + a3 sin(3θ+φ3)와 동일.
- **극성 정규화**: 극성 반전은 φ2를 π만큼 이동시킨다(φ3는 불변). 비교 전 모든 신호를 PPG 형태 기준(수축기 상승 < 이완기 하강)으로 정규화하고 반전 비율을 기록.
- **교정**: 알려진 (a2, φ2, a3=0.2) 해석 파형 18개로 검증 — a2 오차 < 0.003, a3 오차 < 0.002, φ2 오차 < 0.01 rad(정규화 극성 기준). 지표는 정확하다.

데이터: MCD-rPPG 원본 100 Hz `.PW` **600명 × 2상태**(앞 90 s), MCD 30 fps `ppg_sync` 변환본(평가에 쓴 20명 × 2), UBFC-rPPG DATASET_2 42명; neurokit GT(TRAIN 10, TRAIN20 20, COTRAIN 합성 20, 직접 생성 45 = BPM 50–120 × 3시드); TRAIN20H GT 20.

관찰:
- 운동직후는 안정 대비 a2가 체계적으로 높다(짝지은 600명 중 66.5%에서 증가, 중앙값 +0.04). a2와 BPM의 상관 r = 0.50 — 고심박일수록 2차 고조파가 강하다. 즉 **운동직후 조건의 난이도 증가 일부는 파형 자체의 고조파 강화**다.
- MCD 30 fps 변환본(20명)은 100 Hz 원본 분포와 일치 → 변환·다운샘플링이 고조파 구조를 바꾸지 않았다.
- UBFC는 MCD보다 a3가 절반(0.15 vs 0.30)이고 φ2가 −0.5 rad 쪽으로 치우친다 — 센서(CMS50E vs MCD 기기)·필터링 차이로 추정. 두 코퍼스의 a2 분포는 거의 같다(0.48 vs 0.47).
- MCD 안정·운동직후 각 3%(18/600)는 접촉 PPG의 최대 스펙트럼 피크가 2f0이다(a2 > 1).

## 4. 커버리지 판정 (실 = MCD 100 Hz 양 상태 + UBFC, n = 1242)

| 학습 파형군 | a2 범위 | 실데이터 a2가 범위 안 | 아래 | 위 | 실 중앙값의 학습분포 내 백분위 |
|---|---|---|---|---|---|
| neurokit (모든 기존 학습셋) | [0.50, 0.61] | **23.0%** | 49.0% | 27.9% | 1.1% (실 중앙값이 neurokit 최하단) |
| TRAIN20H 해석 그리드 | [0.00, 0.75] | **89.2%** | 0% | 10.8% | 70% |

코퍼스별 a2가 범위 안인 비율 — neurokit: MCD 안정 19%, 운동직후 27%, UBFC 29% / TRAIN20H: 91%, 87%, 100%.

실데이터 a2 분할: < 0.15 **0.4%**, < 0.3 **2.3%**, 0.3–0.75 **87.0%**, > 0.75 10.7%, > 0.85 4.7%, p99 = 1.04. φ2(정규화 극성): |φ2| < 0.5 rad 84%, < 1.0 rad 97%, p5–p95 = [−0.61, +0.60].

**판정**
- neurokit: 실분포의 **한 점**(상위 약 30%)을 찍는다. "비정상적으로 강함"은 기각 — 위치는 정상, 문제는 폭. 배가 악화(6/20→10/20)의 원인을 파형에 돌리려면 "특정 고조파 비율(H2/H1≈0.36, φ2≈0)만 본 모델이 다른 비율에서 기본파/2차를 혼동한다"는 **다양성 부재** 가설로 재진술해야 한다. 이 보고서는 그 전제(다양성 부재)를 확인했을 뿐, 그것이 배가를 일으킨다는 인과는 모델 실험(다른 에이전트)의 몫이다.
- TRAIN20H: 범위는 덮되 밀도가 반대다. 실데이터 97.7%가 있는 a2 ≥ 0.3 구간에 클립 45%, 실데이터 2.3%가 있는 a2 < 0.3 구간에 55%. φ2는 실데이터가 거의 쓰지 않는 1.4–2.8 rad에 60%. 상위 11%(a2 > 0.75)와 3차 고조파(실 a3 중앙값 0.30, TRAIN20H는 대부분 0)는 미커버.

## 5. 주입 무결성 (TRAIN20H 20편, 픽셀 레벨)

방법: `amplitude_map.png`(주입 마스크) 내 RGB 평균 → (i) 녹색 원신호, (ii) POS 투영(무채색 플리커 상쇄), (iii) GT 위상 lock-in 최소제곱으로 픽셀 a2/φ2 복원.

| 검증 항목 | 결과 |
|---|---|
| POS 신호 지배 주파수 = 기본파 | **20/20** (a2 = 0.75인 subject6/12/18 포함; 피크비 1.00) |
| POS 픽셀 a2 vs 주입 a2 (lock-in) | MAE 0.042, 최대 0.14 (subject18: 0.85 vs 0.75, 플리커 1.1 Hz + 공간패치 0.6) |
| POS 픽셀 φ2 vs 주입 φ2 (a2 > 0) | 중앙 |오차| 0.14 rad, 최대 0.40 |
| POS 신호–GT Pearson | 중앙값 0.88 (0.65–0.96) |
| 녹색 원신호 지배 주파수 = 기본파 | 10/20 — 나머지는 **의도된 플리커**(0.95/1.1/1.3 Hz, 진폭 0.02–0.035 ≫ 맥동 0.0077) 피크 |
| 녹색 lock-in a2 | MAE 0.106 (움직임으로 고정 마스크가 배경을 포함) |

판정: 주입 파형의 고조파 구조는 FFV1 영상 픽셀에 **보존**되고, 기본파가 지배 주파수로 유지된다. 녹색 원신호에서 지배 피크가 플리커로 가는 것은 노이즈 증강 설계의 결과이지 주입 결함이 아니다(POS로 분리 가능). 즉 CoTNH 성능은 파형이 잘못 들어가서가 아니라 파형 분포 설계(4절)나 모델 측 요인으로 해석해야 한다.
