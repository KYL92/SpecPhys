| 관측 trace(맥박 포함) `HYBX_TOT_L` | +0.03 (ns) | −0.00 | −0.05 | +0.39 ns | +0.5 / −1.8 ns | +0.5 / +0.6 / +0.2 ns |

| 가설 | 판정 |
|---|---|
| H-N2 정확성 불필요(정확 ≈ 관측 trace) | **지지**: 전 축 Δ≈0. 미분 영역에서 맥박은 잡음의 7% 라 "이중 렌더의 정확한 잡음 정답" 은 "맥박이 섞인 관측 trace" 와 같은 라벨이다 → 잡음 라벨은 이중 렌더가 아니라 **교란이 지배하는 trace 자체**가 본체. 변형 E(실 클립의 자기 관측 trace를 잡음 라벨로)가 성립 가능성 있음 → 후속 후보. |
| H-N1 라벨 대응이 중요(정확 vs 대응 파괴) | **부분 지지**: VIPL 전이 +0.59(p<.0001)·MMPD 전체 +0.29(p=.022)에서 대응 파괴가 열세이나 1차 지표 MMPD 움직임은 Holm 후 ns. |
| H-N3 목적함수 기여(정확 vs 분해 없음) | **1차 기각(Holm .088)·2차 상충**: MMPD 움직임 −0.72·전체 −0.59(비보정 유의)의 이득이 있으나 **MR-NIRP 움직임에서는 분해 없음이 −3.68(p=.0005) 우세** → zero-shot 에서 분해 손실은 휴대폰 움직임 이득과 근적외선 주행 비용의 교환(34 §9 in-domain −0.85 Holm .027 과 달리 zero-shot 3시드에서는 보정 후 비유의). |

**핵심 2 서술 수정**: "합성 데이터의 정확한 잡음 정답" 은 분해 목적함수의 필요조건이 아니다(관측 trace 로 충분). 분해 목적함수의 재현되는 이득은 MMPD in-domain 움직임(3시드 Holm 유의)이며, zero-shot 에서는 보정 후 비유의하고 MR-NIRP 비용이 있다. 방법 편 주장은 "휴대폰 움직임 in-domain 플러그인" 으로 더 좁힌다. 분해 없음 셀의 VIPL 3시드 8.02 ≈ 분해 8.09(기여 0) 재확인.
