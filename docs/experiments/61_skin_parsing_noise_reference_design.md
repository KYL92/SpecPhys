# 61. 피부 영역 가중(face parser) + 비얼굴 잡음 참조(조명 DC·움직임·얼굴 내 변화) — 사전 등록 (2026-11-04)

사용자 지시(2026-11-04): ① 성능이 좋은 얼굴 랜드마크 검출기 또는 face parser 로 심박 신호가 있는 피부 영역을 더 가중해 학습, ② 얼굴이 아닌 곳에서 생기는 조명 잡음, 움직임, 얼굴 안의 변화를 써서 잡음 DC 값을 찾는 방법을 설계·실험.
동기(60 문서 §29.2·§31): 남은 약점(MMPD ≥110 bpm 34편 — 어두운 피부 26편, 운동 직후 22편, 보행 19편)은 입력에서 심박이 가장 강한 주기가 아닌 저 SNR 영상이다(학습 사전 없는 POS 도 평균 81 bpm vs 정답 122). 지금 입력은 Haar 정적 박스 1.5배 크롭 전체(배경·옷·머리카락·목 포함)라, 맥박이 없는 영역의 조명·움직임 변화가 그대로 들어간다.

## 1. 도구
- **Face parser**: SegFormer face-parsing(`jonathandinu/face-parsing`, CelebAMask-HQ 19 부위, 84.6 M; `_workspace/models/face_parsing`). 단일 GPU 프로세스에서 384 해상도, 약 180 장/s. 육안 점검: 피부·코만 정확히 분리, 눈·눈썹·입술·머리카락·목·옷·배경 제외(MMPD 크롭 예: 피부 32 %, 배경 19 %, 옷 27 %, 머리카락 10 %, 목 5 %).
- (참고) 랜드마크: LivePortrait 의 InsightFace 106점(`2d106det.onnx`)도 가능하나, 움직임 참조는 프레임 기반 Lucas–Kanade 전역 이동(기존 `NFLoss.motion_traces`)으로 충분해 이번에는 쓰지 않는다.

## 2. 사이드카(P0, `scripts/face_parse_sidecar.py`)
청크마다 8 장(균등 간격)을 분할해 64×64 부위 확률 `{cache}/{name}_parse{i}.npy` (uint8 3×64×64) — [0] 피부(skin+nose), [1] 배경, [2] 얼굴 내 비피부(눈·눈썹·안경·입·입술). 대상: 학습 풀 `cotrain_allf_hyb4_u8`(3,665), `vipl_u8`(12,934), `mmpd_all_u8`(7,260), 실 축 `fp_real_*`(10 캐시 2,325). 청크 안에서는 정적(청크 시간 평균) → 입력에 시간 불연속을 만들지 않는다.

## 3. 개입(툴박스 패치 50·51·52; 학습·평가 모두 같은 변환)
- **패치 50 `RPPG_SKINW=α`(피부 가중)**: 화소 가중 w = α + (1−α)·p_skin, α = 0.2 를 Raw 입력 프레임에 곱한다(u8 캐시·float Raw 캐시 모두). 피부 밖은 0.2 로 줄인다(0 으로 지우면 FactorizePhys 의 시간 차분·정규화가 경계에서 불안정).
- **패치 51 `RPPG_BGDC=1`(배경 기준 조명 DC 정규화)**: 안정 배경(배경 확률 ≥ 0.875, 크롭의 ≥ 3 %, 평균 밝기 ≥ 25)의 채널별 평균 b_c(t) 를 시간 평균 1 로 정규화해 프레임을 나눈다 — 얼굴과 배경이 공유하는 조명 변화(느린 DC 드리프트·플리커)를 제거. 어두운 배경은 센서 잡음이 지배해 정규화가 잡음을 더하므로 건너뛴다(CPU 점검에서 결정, 결과 보기 전).
- **패치 52 `NF_SS_REF=1`(잡음 참조 스펙트럼 배제)**: 기존 자기 지도 배제(`NF_SS_TRACE=1`, 패치 38)의 교란 마스크를 크롭 전체 밝기(피부 맥박이 섞임) 대신 **배경 R·G·B 차분 trace + 얼굴 내 비피부 차분 trace + LK 전역 이동(x, y)** 으로 만든다(심박 기본·반·배 대역 ±5 bpm 은 마스크에서 제외). 출력 스펙트럼이 이 잡음 주파수에 놓인 질량을 벌하고, 잡음 슬롯 표적도 배경 trace 스펙트럼으로 바꾼다. 로그 `[nf-ref] active`·`NF-REF stats epoch k: bg=a/n nonskin=b/n`.

## 6. 설계 수정(2026-11-04 00:3x KST, 사전 등록): 회귀형 배경 조명 제거(패치 51b)
관찰(학습 1 시드): 배경 DC 정규화 `NF_BGDC_L` 시드 100 의 MMPD 10.99(채택 셀 ≈9.3) — 악화. 진단(무작위 300 청크, 학습 없음): 피부와 배경의 1 s 고역 통과 상대 변동의 상관 중앙값이 MMPD 0.23 · 학습 풀 0.30 · VIPL 0.17 로 낮고, MMPD 배경 변동 크기(0.41 %)가 피부 변동(0.44 %, 맥박 포함)과 비슷하다(배경 밝기 중앙 47, 어둡고 압축 잡음). 배경으로 통째로 나누면 지우는 공통 조명보다 더하는 배경 잡음이 크다.
수정: **패치 51b `RPPG_BGDC=2`** — 청크마다 채널별 β = ⟨hp(피부 상대 변동), hp(배경 상대 변동)⟩ / ⟨hp(배경), hp(배경)⟩ ∈ [0, 1.5] 를 추정해 frames ÷ (1 + β·배경 상대 변동) — 피부와 실제로 공유하는 조명 성분만 제거(β=1 이면 기존 51, 공유가 없으면 β→0 으로 무해). 배경에는 맥박이 없으므로 β 추정이 맥박에 편향되지 않는다. MMPD 200 청크 점검: 적용 97 %, 평균 β 0.24.
추가 셀(각 시드 100·200·300, pro6000 체인 109): `NF_BGRG_L`(회귀형 배경 제거) · `NF_SKBGRG_L`(피부 가중 + 회귀형). 판정은 §5 와 같은 가족. 기존 `NF_BGDC_L`·`NF_SKBG_L` 은 사전 등록대로 끝까지 돌려 그대로 보고한다.

### 6.1 실행 기록(정직 보고): 회귀형 단독 셀의 첫 실행은 무효

### 7.4 해석
- **face parser 피부 가중**은 고전 POS 의 신호 품질은 올리지만(전체 13.37 → 11.06) 학습 모델에는 중립이다. FactorizePhys 의 FSAM 주의가 이미 피부 영역을 가중하는 것으로 보인다(가설).
- **비얼굴 배경으로 조명 DC 를 직접 나누는 방식은 해롭다.** 배경 변동은 피부와 공유하는 조명 성분보다 센서·압축 잡음과 배경 물체 변화가 크다(§6 진단, POS (d) 와 같은 방향). 공유 성분만 빼는 회귀형(β)은 MMPD 전체는 지키지만 고심박을 +3.9~5.0 bpm 악화시킨다. 160 프레임 청크에서 β 가 맥박과 배경 잡음의 우연 상관까지 지우는 것으로 보인다(가설, 미검증).
- **잡음 참조(배경 RGB·얼굴 내 비피부·LK 이동)를 입력 변환이 아니라 손실의 스펙트럼 배제로 쓰는 방식만** 비용 없이 고심박을 같은 방향으로 줄였다. 그러나 사전 등록 가족(Holm 4)에서는 유의하지 않다.
- POS 결과와 같이 MMPD ≥110 대역의 실패는 공간 선택·공통 잡음 제거로 닫히지 않는 저 SNR 문제가 주다(모든 셀 30 bpm 이상).

### 16.3 제로샷 표기
원고의 "zero-shot" 은 대상에 적응하지 않는다는 뜻이고, 두 수준을 구분한다. **데이터셋 수준**: VIPL-HR·MR-NIRP·DLCN(어떤 제로샷 풀에도 없음). **피험자 수준**: MMPD·PURE·UBFC-rPPG·MCD-rPPG(다른 피험자가 풀에 있음). 표 1 은 † 열을 앞으로 옮기고 DLCN 열을 추가했다(재배열만, 값 불변). 공개 FactorizePhys 대비 Holm 5(`final_config_tables` 절 G, 보충 S1-T14): VIPL·MR-NIRP 정지·소동작 우세(SpecPhys Holm ≤ .031, SpecPhys-R Holm ≤ .042), 대동작·DLCN 유의 차 없음(p ≥ .58).

### 16.4 합성 데이터 근거의 범위(정직 기록)
사용자 요청 마무리 문장("좋은 성능은 스펙트럼 학습과 합성 데이터의 영향으로 확인")을 위해 대조를 다시 확인했다(`final_config_tables` 절 H, 보충 S1-T15). **스펙트럼 손실**: 같은 풀 VIPL 8.44 → 5.82(p<.0001), MR-NIRP 소동작 10.44 → 6.12(p=.16, ns). **합성 클립**: 코퍼스 수준 PhysFormer(실 161 vs + 42) VIPL 9.36 → 9.00(p=.017)·MR-NIRP 소동작 13.99 → 8.68(p=.006), **그러나 UBFC 34 클립 출발**에서는 VIPL 악화(PhysFormer +0.81, FactorizePhys +2.01, Holm <.0001)·MR-NIRP 소동작 무효(−1.80, +0.74, ns). SpecPhys 와 같은 트렁크인 FactorizePhys 출발 실험에서는 합성 이득이 없다. 그래서 초록은 "confirm" 대신 "support", "adding synthetic clips to real clips from several datasets" 로 쓰고 본문 4.4 에 두 결과를 함께 적었다. SpecPhys 풀에서 합성 71클립만 뺀 대조는 없다(5시드 약 2시간 예상, 사용자 미지시로 돌리지 않음).
