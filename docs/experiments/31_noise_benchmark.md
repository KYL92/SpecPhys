## 2. 트랙 L — 문헌 비교 정합 (체인 47 전반 + 체인 49)
세 차이의 해소책과 판정:
| 차이 | 해소 | 셀 |
|---|---|---|
| GT: 정본(파형 스펙트럼, 장치 HR 대비 −3~4 bpm) vs 문헌(gt_HR 평균) | 학습 HR 라벨도 **gt_HR**(초당 HR → 프레임 보간 사이드카 `{idx}_hr.npy`, 청크 평균; 트레이너 `RPPG_HR_LABEL_FILE=1`, 사이드카 없는 풀 청크는 cumsum 유지) + 평가 문헌 GT. 파형 손실은 VIPL 청크 제외 유지 | `VF1_TWg_L` (fold 1 파일럿) → 문헌 GT MAE 가 `VF1_TW_L`(6.23) 이하이면 5-fold 채택(`VF{k}_TWg_L`) |
| 레시피: 문헌 = 처음부터 25 epoch·lr 1e-4·Pearson 가중 a=0.1(공식 코드)·MTCNN 첫 프레임 박스 | **문헌 레시피 셀**: VIPL 4-fold 만, 사전학습 없음(RESUME 제거), 25 epoch, lr 1e-4, `PF_LOSS_A=0.1`, gt_HR 라벨. 박스는 Haar(1.5배) 유지 — MTCNN 차이는 잔여로 명기(파일럿이 문헌 대비 1.5 bpm 이상 열세면 fold 1 에 MTCNN 재크롭 추가 검토) | `VF1_LIT_L` 파일럿(≈4 h). 규칙: 문헌 GT MAE ≤ 7 이면 fold 2~5 실행(매칭 기준선 = 문헌 레시피의 VIPL-only); > 9(붕괴)면 입력 표현 차이로 판단해 `Standardized` 입력 변형 1회(`VF1_LITS_L`, u8 캐시에서 생성) 후 종료 |
| 단일 fold·시드 | 5-fold 합산(체인 46) + **시드 200·300**: TW·HYB(+ 채택 시 TWg) 전 fold → 3시드 풀링(프로토콜 ≥3시드) | 체인 49 (≈40 h, 최후순위) |
판정: 문헌 표와 같은 지표(SD/MAE/RMSE/r, 문헌 GT, 2,378편)로 ①우리 공동학습 셀 ②문헌 레시피 VIPL-only 셀 ③문헌 보고치를 한 표에. ②가 문헌 보고치와 1 bpm 이내면 "프로토콜 정합" 선언, 아니면 잔여 차이(MTCNN·입력 표현)를 명기한 참고선 유지.

## 3. 트랙 N — 노이즈 환경 집중 (체인 47 후반 + 48)
목표 축 2개: **VIPL 휴대폰(source 2, fold 1 held-out 193편 + v8/v9)** 과 **MR-NIRP driving(정지/소동작/대동작)**. 평가 보조 축: DLCN(zero-shot 회귀 점검), MMPD 움직임 분할(체인 48 승자만).
| 셀 | 학습 데이터 | 질문 |
|---|---|---|
| `VF1_TW_L`, `VF1_HYB_L` (기존) | 공식 코퍼스 + VIPL fold 2~5 전체 | H-N1: VIPL 공동학습이 MR-NIRP driving 노이즈로 **전이**되는가(제로샷 TW/HYB4 대비 피험자 쌍대, 정지 n=19·움직임 n=38) |
| `VF1_MOB_L` / `VF1_MOBHYB_L` | 공식 코퍼스(+HYB4 풀) + VIPL fold 2~5 **source 2 만**(≈770편) | H-N2: 휴대폰 집중 데이터가 전체 VIPL 보다 휴대폰 축·NIRP 에 유리한가 |
| `NF{k}_TWN_L` (k=1..5) | 공식 코퍼스 + VIPL fold 2~5 전체 + **MR-NIRP 학습 fold 피험자**의 전 trial(driving·garage × 975·940, 전장) | H-N3: MR-NIRP in-domain 피험자 배타 5-fold 가 driving 움직임을 최선 zero-shot 보다 개선하는가 |
| `NF{k}_HYBN_L` | 위 + HYB4 풀 + 하이브리드 손실 | H-N4: 하이브리드 분해가 in-domain 위에서 움직임 조건에 추가 기여하는가 |
- MR-NIRP fold: 피험자 1~19 를 5-fold(4/4/4/4/3)로 고정(`_workspace/data/physformer/nirp_folds.json`, 시드 0 셔플). 평가는 held-out 피험자의 driving 975 앞 60 s(기존 축 영상과 동일) → 기존 zero-shot 축 결과와 피험자 단위 쌍대 가능.
- **불변식**: 공식 모델(CoTAF_TW_L·CoTAM_HYB4_L)과 공식 풀은 불변, DLCN 은 어떤 셀에도 학습 사용 금지. MR-NIRP 를 학습에 쓰는 셀은 `NF*` 접두 + 풀 `COTRAIN_NIRPTR*`(피험자 코드 3SSCT: 30000+S×100+조건×10+세션)로 격리하고 결과는 항상 "in-domain" 라벨. zero-shot 표에는 절대 섞지 않음.
- 판정: 피험자(NIRP)·영상(VIPL) 단위 Wilcoxon, 단일 시드 1차 → 유의 셀만 시드 200·300 추가(체인 49 에 편입).
