# 36. UBFC 기반 통제 요인 실험 — 같은 학습 데이터 출발점에서 "합성 데이터 · 분해 손실 · 실 노이즈 증강" 의 기여, 두 백본(PhysFormer·FactorizePhys) (체인 53, 사전 등록, 2026-10-18)

사용자 지시(10-18): ① FactorizePhys + 우리 코퍼스 + 분해 손실을 체인 53 설계서로 ② 기존 공개 가중치(UBFC 만 학습)와 우리 모델(UBFC 일부 + PURE + MCD + 가상얼굴)을 비교한 것은 학습 데이터가 달라 공정하지 않다 — **UBFC 데이터셋을 기반으로 우리의 합성·분해 방식을 적용했을 때의 개선**을 보고 싶다.

## 1. 설계 원칙 — 비교하려는 것만 다르게
- **출발점을 통일**: 모든 셀은 UBFC-rPPG 학습 피험자 34명(공식 코퍼스에 있는 1~41 중 34명 원본 클립)에서 출발하고, 같은 백본의 UBFC 공개 가중치에서 미세조정한다(PhysFormer: 툴박스 UBFC 배포 가중치, FactorizePhys: 툴박스 UBFC FSAM_Res 배포 가중치). PURE·MCD·MMPD 실데이터는 **넣지 않는다**(기존 코퍼스와 달리). 따라서 PURE·MCD 도 이 실험에서는 순수 제로샷 축이 된다.
- **요인을 한 번에 하나씩 추가**: 가상얼굴(합성 데이터) → 분해 손실(목적함수) → 실 얼굴 노이즈 증강(우리 손상 연산자). 각 단계의 차이가 곧 그 요인의 기여다.
- **평가는 전 셀 동일**: UBFC held-out 피험자 42~49(데이터 내), 제로샷 — PURE 59편, MCD 안정/운동후 40편, DLCN 20편, MR-NIRP 주행 3조건 57편, 통제 노이즈(플리커·압축) 16편, MMPD 평가 피험자 7~33 540편, VIPL 2,378편, 합성 C3/C6/E3. 읽기는 라벨 유형별 툴박스 규칙(정정판).
- **백본 요인**: 같은 4셀을 PhysFormer 와 FactorizePhys 양쪽에 두어 "같은 데이터에서 백본 차이" 와 "같은 백본에서 우리 방식의 기여" 를 분리한다. 공개 가중치(UBFC 42명 전체 학습)는 참고 행으로만(피험자 수 42 vs 34, 학습 레시피 상이).

## 2. 셀 (백본 B ∈ {PhysFormer, FactorizePhys})
| 셀 | 학습 데이터 | 손실 | 답하는 질문 |
|---|---|---|---|
| `U0_B` | UBFC 34명 원본 34클립 | 기본(백본 고유 손실 + cumsum HR 라벨) | 우리 레시피로 UBFC 만 다시 학습한 공정 기준선 |
| `U1_B` | U0 + 가상얼굴 42클립(실측 맥파 주입, 압축 사본 10 포함) | 기본 | **합성 데이터의 기여** (H-U1) |
| `U2_B` | U1 + 이중 렌더 잡음 클립 48(가상얼굴의 맥박 없는 렌더) | 기본 + 심박·잡음 분해 4항(잡음 헤드) | **분해 목적함수의 기여** (H-U2) |
| `U3_B` | U2 + 실 얼굴 노이즈 증강 사본 34 + 압축 사본 10 | 분해 4항 | **실 얼굴 손상 연산자의 기여** (H-U3) = UBFC 기반 "우리 전체 레시피" |
| 참고 `PUB_B` | 공개 가중치(UBFC 42명) | – | 기존 방법 그대로 |

가설과 1차 비교(백본별, Holm 3건): H-U1 U0→U1, H-U2 U1→U2, H-U3 U2→U3. 1차 축: MMPD held-out 움직임 조건(324편)과 VIPL 전체(장치 기준값, 2,378편). 2차: 나머지 축 전부 + 백본 간 U3_PF vs U3_FP(같은 데이터·같은 손실에서 백본 효과) + U3_B vs PUB_B.
지지 기준: Δ<0, Holm p<.05, 어느 2차 축에서도 유의 악화 없음(악화가 있으면 "조건부 기여"로 기록).

## 3. 구현
- 풀: `COTRAIN_U0`(UBFC 34), `COTRAIN_U1`(+201~236, 601~610), `COTRAIN_U2`(+261~307 잡음 도메인 48; 잡음 GT 사이드카 `noise_gt_hyb2` 48개 존재), `COTRAIN_U3`(+301~341 노이즈 증강 사본 34, 501~510 압축 사본 10) — 모두 `COTRAIN_ALLF_HYB4` 의 심볼릭 링크 재사용(`make_pool`).
- PhysFormer 셀: 기존 경로 그대로(`gen_yaml` → 13축 + MMPD yaml, `train_eval`; U2/U3 는 HYB 환경 `RPPG_NOISE_HEAD=1 RPPG_HYBRID=1 SINC_PRIOR=1 SINC_DN_ONLY=1 HYB_W_NOISE=1.0 HYB_W_DECOR=0.25`). 10 epoch·lr 5e-5·batch 4·cumsum 라벨, UBFC 체크포인트 RESUME.
- FactorizePhys 셀: ①학습 yaml 틀 신설(툴박스 FactorizePhys 학습 설정: Raw 입력 72×72·Standardized 라벨·청크 160, FSAM_Res 배포 가중치 RESUME) ②**잡음 헤드 이식(패치 #34)**: `FactorizePhys.forward_dual(x)` — 같은 voxel 임베딩에 두 번째 `BVP_Head`(FSAM 없음)를 붙여 (rPPG, noise) 반환, 가중치 로드는 strict=False(잡음 헤드는 rPPG 헤드 복사로 초기화) ③`FactorizePhysTrainer` 에 PhysMamba 이식과 같은 4항 손실(잡음 Pearson vs 사이드카·탈상관·SiNC DN-only) 추가, 환경변수 기본 off ④학습률: FactorizePhys 는 Phase 0 에서 U0 로 3값(1e-4·5e-5·2e-5) 탐색 — 선택 기준은 **학습 피험자 중 4명(31·32·33·34)을 뗀 검증 손실**(평가 축 비관여), 선택 후 34명 전체로 재학습.
- 집계·판정: `agg_model2.py`(라벨 유형별 읽기)·`agg_mmpd.py`·`agg_vipl.py` 그대로; 판정 `scripts/ubfc_judge.py`(백본별 U0→U1→U2→U3 쌍대 + 축별 표 + Holm + 백본 간 비교) → `results/ubfc_judge.json`.
- 스모크: FactorizePhys 학습 경로(RESUME·Raw·72×72)와 `forward_dual` 단위 검사, 1 epoch 소규모 학습으로 손실 4항 출력 확인 후 기동.

## 4. 비용·순서
- 학습은 작다(풀 34~168클립, 2~10 분/epoch). 비용은 평가: 모델당 13축 ≈30 분 + MMPD 6배치(캐시 공유) + VIPL ≈10 분 ≈ 1~1.3 h.
- Phase 0: FactorizePhys 학습률 탐색 3 run(≈1 h). Phase 1: 8 셀 시드 100(학습 ≈2 h + 평가 ≈10 h). Phase 2: 시드 200·300 전 셀(16 모델, ≈22 h) — 1차 비교가 하나라도 유의하거나 효과 ≥0.3 bpm 이면 실행(사전 규칙). 총 ≈1.5 일.
- GPU: 체인 50 완료(`/tmp/chain50.done`) 후 체인 52 와 병행(게이트 12 GB). 마커 `/tmp/chain53_{p0,p1,p2}.done`, `/tmp/chain53.done`, 로그 `/tmp/chain53.log`.

## 5. 기존 비교의 해석 정정 (33 문서 §5 에도 반영)
공개 가중치(UBFC 42명)와 우리 채택 모델(UBFC 34 + PURE + MCD + 가상얼굴)의 제로샷 비교는 "학습 데이터가 다른 두 모델의 비교" 이며, 아키텍처나 우리 방식의 기여를 분리하지 못한다. 같은 백본 비교(PhysFormer 공개 vs 채택)는 "데이터·레시피 전체" 의 효과이고, 본 체인이 그 효과를 요인별로 분해한다. 원고에서는 공개 가중치 행을 "참고선" 으로 강등하고, 본 체인의 U0→U3 표를 기여의 1차 근거로 쓴다.

**해석(사용자 질문 "UBFC 기반으로 합성·분해 방식을 적용했을 때 개선이 있는가")**
1. 단일 시드 기준, UBFC 34명 출발점에 우리 가상얼굴 42 클립을 더하는 것은 MMPD 에 이득이 없고 VIPL zero-shot 을 두 백본 모두에서 유의하게 악화시킨다. 분해 목적함수는 두 백본 모두 무효. 유일한 긍정 요인은 실 얼굴 노이즈·압축 사본(H-U3)이며, 그 이득은 MMPD(정지 중심)·VIPL·플리커에 한정되고 PhysFormer 에서는 PURE·DLCN·MR-NIRP 정지를 해친다.
2. 따라서 공식 코퍼스 모델이 공개 가중치보다 zero-shot 에서 앞섰던 것(33 §5)은 UBFC 기반 요인들이 아니라 **코퍼스의 PURE·MCD 실 클립**(이 실험에서 의도적으로 제외)에서 온 것으로 귀속된다 — 체인 51(실-only 대조군)·체인 50(증강)·체인 46b(REAL 셀) 결과와 일관.
3. 목표 근거표(33 §5) 의 "공정 기준선" 열: PhysFormer 는 같은 출발점에서 MMPD 만 유의 개선(공개 가중치 −2.81), VIPL 은 ns; FactorizePhys 는 개선 없음(VIPL 악화). 기존 방법 대비 '정확도 향상' 주장은 **PhysFormer × MMPD(실 노이즈 사본 기여) 로 한정**되고 가상얼굴·분해 손실로는 성립하지 않는다.
4. 규칙에 따라 1차 유의(H-U1 역방향·H-U3)가 있어 Phase 2 시드 200·300(16 run ≈ 22 h)이 자동 진행 중 — 시드 풀링에서 H-U1 악화·H-U3 개선이 유지되는지, PhysFormer 의 MCD 붕괴가 시드 특이인지 확인 후 최종 판정(§8).
