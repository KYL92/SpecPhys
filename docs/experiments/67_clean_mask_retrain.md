# 67. 합성 학습 클립의 맥파 마스크를 고쳐 최종 모델 재학습 (체인 126, 사전 등록 11-08)

## 1. 왜 하는가
사용자 지시(11-08): "1,2번 진행해주세요." 1번은 합성 학습 클립을 고친 마스크로 다시 만들고 최종 모델을 다시 학습해, 누출이 실제 성능에 미친 영향을 재는 것이다. 2번은 원고 반영이다(§6).

배경(66 §6.3·§8): 생성기의 YCrCb 피부색 마스크가 따뜻한 색 배경에도 맥파를 주입했다. 최종 풀의 생성 얼굴 주입 클립 80개 중 38개에서 화면 가장자리 띠의 0.3 이상이 맥파 마스크 안이다. 정체성별로는 sfhq_01 0.79, sfhq_06 0.63 이다. 실제 영상의 배경에는 맥박이 없으므로, 합성 클립이 실제와 다른 단서를 가르쳤을 수 있다. 64 §5 에서 합성 클립을 빼면 MMPD 가 좋아진 결과(9.07 → 8.13)와 관련이 있을 수 있다(미검증).

## 2. 데이터 (`scripts/make_clean_train_configs.py`, `scripts/prep_chain126.sh`)
- **결정성 점검:** 세트마다 첫 피험자를 원래 설정으로 다시 렌더하면 원래 vid.avi 와 프레임이 비트 단위로 같다(TRAIN20H_TW·TRAIN6HI_TW·TRAIN6LO_TW 각 1클립; TRAIN24DN·DN2 는 65 §2 에서 48/48 확인). 따라서 깨끗한 판은 맥파 마스크만 다르고, 시드·파형·잡음·움직임은 같다.
- **깨끗한 판:** 원래 설정 + `skin_mask_parser`(YCrCb ∧ 얼굴 부위 분할 피부+코)로 80클립을 다시 만든다(폴더 끝 `_C`). 코덱 사본 10개는 원래와 같은 규칙으로 다시 만든다(TRAIN20H_TW_C 홀수 1~19, mpeg4 q 6 → `CMP_SYN_TW_C` 601~610).
- **풀:** `COTRAIN_ALLF_HYB4C` 는 실제 클립 링크를 그대로 두고 생성 얼굴 90개만 `_C` 로 바꾼다. 생성 얼굴 90개만 새 u8 캐시(`hyb4c_syn_u8`)와 부위 분할 사이드카를 만들고, 풀 목록(`cotrain_allf_hyb4c_u8_pool.csv`)은 3,665 청크로 원래와 같은 크기다. 1차원 잡음 정답은 깨끗한 판의 이중 렌더 48클립에서 다시 뽑는다(`noise_gt_hyb2c`). 피부 영역이 바뀌어 trace 도 조금 달라진다.
- **점검 결과(11-08 01:57, 결과 전):** 결정성 3/3 비트 일치. 화면 가장자리 띠의 0.3 이상이 맥파 마스크인 클립이 TRAIN20H_TW 10/20 → 0/20, TRAIN6HI_TW 3/6 → 0/6, TRAIN6LO_TW 3/6 → 0/6, TRAIN24DN 11/24 → 0/24, TRAIN24DN2 11/24 → 0/24 로 줄었다(평균 0.35~0.45 → 0.00~0.01). 풀 목록 3,665 청크 중 생성 얼굴 540 청크를 바꿨고, 부위 분할 사이드카 3,665/3,665, 1차원 잡음 정답 48 이다.

## 3. 셀 (체인 126, pro6000)
| 셀 | 이름 | 비고 |
|---|---|---|
| 깨끗한 마스크 풀의 최종 모델 | `NF_NSP2C_L` | 새로 학습, 시드 2100·2200·2300·2400·2500 |
| 현재 최종 모델 | `NF_NSP2_L` | 체인 121, 같은 시드 |
| 합성 클립을 뺀 최종 모델 | `NF_NSP2NS_L` | 체인 123, 같은 시드 |

레시피는 현재 최종 모델과 같다: `RPPG_NF=1 RPPG_SKINW=0.2 NF_SS_TRACE=1 NF_SS_REF=1 NF_ARCH=nsp NF_NSP_LAM=0.01`, 1차원 잡음 정답(`noise_gt_hyb2c`), 배가 억제 0.5, ×2 증강 0.25, lr 1e-4, 10에폭, 공개 FactorizePhys 가중치에서 시작.
사용자에게 '새 시드 5개'로 제안했지만, 같은 시드를 쓰기로 했다. 같은 시드에서는 초기값과 데이터 순서가 같아 마스크만 다른 짝이 되고, 두 기존 셀과도 바로 짝지을 수 있기 때문이다. 이 시드의 시험 결과는 이미 본 것이다(체인 121·123).

## 4. 판정 규칙 (결과 전 확정, `scripts/cleanmask_judge.py`)
- **가족 C1 (누출을 고친 효과, Holm 5):** 깨끗한 마스크 vs 현재 최종. VIPL-HR 전체, MMPD 7~33 전체(공통 정답), 풀 저심박, 풀 고심박, MR-NIRP 소동작. 영상별 오차의 5시드 평균, 부호 뒤집기 순열(양측), Wilcoxon 병기. 양방향 모두 보고한다. Δ < 0 이고 Holm p < .05 면 '고친 쪽이 나음', Δ > 0 이고 Holm p < .05 면 '고친 쪽이 나쁨', 그 밖은 '측정되지 않음'.
- **가족 C2 (깨끗한 합성 클립의 몫, Holm 5):** 깨끗한 마스크 vs 합성 클립을 뺀 셀, 같은 5지표. 64 §5 의 '합성 클립이 MMPD 를 나쁘게 함'(9.07 vs 8.13)이 누출 때문이었다면 이 비교에서 MMPD 차이가 줄거나 사라져야 한다.
- **가드(C1):** VIPL <60, VIPL ≥120, MMPD <110, MMPD ≥110, DLCN, RTNI, PURE. Δ > +0.3 bpm 이고 보정 없는 p < .05 면 위반이다.
- **서술:** 깨끗한 분리 시험(`sepevalc_u8`)의 심박 판독과 지연 보정 r, 세 셀 비교.
- **결과를 쓰는 방법:** C1 에서 고친 쪽이 낫고 가드를 지키면 최종 설정 교체 후보로 사용자에게 올린다(자동 교체 안 함). 어떤 결과든 원고 한계 절에 누출과 이 재학습 결과를 함께 적는다(사용자 지시 2번).

**서술: 깨끗한 분리 시험(심박 판독).** 현재 최종과 깨끗한 마스크 모델은 비슷하다(전역 플리커 근접 0.11 vs 0.13, 플리커 +30 0.89 vs 0.85). 합성 클립을 뺀 모델은 합성 시험에서 크게 낮다(0.06, 0.53).

**읽기.**
- 누출을 고쳐도 실제 정확도는 유의하게 달라지지 않았다. 방향은 VIPL-HR·MMPD·저심박이 조금 낫고 고심박이 나쁜, 이전에 여러 번 본 심박 사전 트레이드오프 모양이며 MMPD ≥110 가드를 어겼다. 최종 설정 교체 후보가 아니다.
- 합성 클립이 MMPD 를 나쁘게 하는 효과는 누출 때문이 아니다. 누출을 고쳐도 +0.75 bpm(Holm .004)으로 남는다. 반대로 VIPL-HR 이득은 깨끗한 클립에서 보정 후에도 유의해졌다(−0.32, Holm .001).
- 따라서 원고의 최종 모델과 그 수준값은 그대로 두고, 누출과 이 민감도 분석을 함께 밝힌다(§6).
