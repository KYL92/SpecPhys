# 24단계 — 노이즈 세기 감독 + 학습된 신뢰도 (체인 41, 2026-09-04 사전 등록)

논의 승인 ①: 하이브리드 고도화 — "분해 네트워크가 자기 노이즈 수준을 알고, 그것으로 배치를 스스로 결정".

## 구현
1. **세기 보존 사이드카**(builder): noise_gt.npz = {noise_dn, total_dn} — 차분 정규화만 하고 표준화 없음.
   노이즈 비율 GT = std(noise_dn 청크)/std(total_dn 청크) ∈ [0,1] — 입력이 클립 표준화되므로 절대 세기 대신
   **비율**(스케일 불변)을 감독. DN 48클립 재빌드.
2. **신뢰도 헤드**(모델): transformer3 풀링 → 2층 MLP → sigmoid, 청크 노이즈 비율 예측. 손실 SmoothL1(DN 샘플).
3. **적응형 SNR 사전**(트레이너 SINC_ADAPTIVE): SiNC band/sparse를 per-sample로 계산, **예측 conf(detach)로
   가중** — "노이즈가 심하다고 스스로 판단할수록 사전 강화". V3의 이산(DN-only) → 연속·실 데이터 적용 일반화.
4. **추론 신뢰도 덤프**(RPPG_CONF_DUMP): 평가 시 클립별 conf 저장 → **학습된-신뢰도 라우팅**
   (conf>τ → HYB5, else TW)을 GT-모션 라우팅(9.59, p=.0017)과 비교(conf_routing.py).
   τ는 MMPD 1~6 보정(HYB5가 1~6 학습 → 과발화 편향 가능성 명시, held-out τ 스윕 병기).

## 판정
- 주: MMPD held-out 움직임 분할(표준) + 학습된 라우팅 composite가 GT-모션 라우팅에 근접하는가
  (근접 시 "모션 라벨 없이 배치 가능" — 방법론 완결). conf의 정지/움직임 분리도도 보고.
- 코퍼스 = V4와 동일(OFFICIAL+DN48+MMPD 1~6), CoTAM_HYB5_L 3시드. V4(HYB4) 풀링과도 비교.
코드: builder/모델/트레이너 패치(위), scripts/{conf_routing.py,run_chain41_conf.sh}, /tmp/chain41.log
