# 연구 설계서 — 통제 노이즈 주입 가상얼굴을 이용한 rPPG 강건성 학습

작성: 2026-08-21 · research-designer · 프로젝트: Virtual-Face

---

## 연구 개요

- **연구 제목 (가제)**: *Controlled Noise Injection on Synthetic Faces: Learning Noise-Invariant rPPG Representations with a Known Ground-Truth Pulse*
  (국문 가제: 정답을 아는 합성 얼굴에 대한 통제 노이즈 주입 — PhysFormer의 노이즈 불변 rPPG 표현 학습)
- **연구 분야**: 컴퓨터 비전 / 원격 생체신호 계측(camera-based physiological sensing) / 합성 데이터 학습
- **연구 유형**: **계산 실험(computational experiment)** — 요인설계(factorial design) 기반 통제 시뮬레이션 + 딥러닝 모델 학습·평가. 인간 피험자 없음.
- **학술적 기여**
  - **이론적**: rPPG 성능 저하를 "노이즈 유형 × 강도"의 함수로 **분해 측정**할 수 있는 실험장(testbed)을 제시한다. 실제 데이터셋에서는 노이즈와 정답이 뒤섞여 있어 불가능한 인과적 분해다.
  - **방법론적**: 디퓨전 모델의 학습 원리(정답 신호 → 통제 노이즈 오염 → 오염 입력으로부터 정답 복원)를 **rPPG 영상 도메인에 이식**한 학습 구조를 조작적으로 정의하고 검증한다.
  - **실무적**: 사전학습 PhysFormer의 노이즈 취약 지점을 조건별로 문서화하고, 합성 데이터 미세조정만으로 개선 가능한 범위/불가능한 범위를 실증한다.
  - **신규(관류 이질성)**: 피부 픽셀의 **공간적 맥동 이질성**(코·지방 부위의 약한 관류)을 진폭 맵으로 모사하여, ROI 선택 난제를 "학습으로 흡수 가능한가"라는 검증 가능한 질문으로 전환한다.

## 연구 배경 및 선행연구

### 이론적 배경

- **핵심 이론 1 — 피부 광학 반사 모델(Dichromatic / Shafer model)**: 피부 화소의 시간 변화는 정반사(specular)·확산반사(diffuse)·강도(intensity) 성분의 합이며, 혈류 맥동은 확산반사 성분의 **혈액량 맥파 벡터 Pbv 방향**으로 나타난다. CHROM(de Haan & Jeanne, 2013)과 POS(Wang et al., 2017)는 이 모델의 서로 다른 사영(projection) 해법이다. 본 연구의 **주입(forward) 모델은 이 반사 모델의 역방향 사용**이다.
- **핵심 이론 2 — 시공간 어텐션 기반 생리신호 표현**: PhysFormer(Yu et al., CVPR 2022)는 temporal difference guided global attention으로 준주기적(quasi-periodic) rPPG 특징을 강화하고 국소 시공간 표현을 정제한다. 즉 **노이즈 억제를 아키텍처로 내재화**한 대표 모델이며, 본 연구의 주 검증 대상이다.
- **핵심 이론 3 — 디노이징 학습(denoising objective)**: 오염된 관측으로부터 오염 전 신호를 복원하도록 감독하면, 모델은 **노이즈에 불변인 잠재 표현**을 학습하도록 강제된다(denoising autoencoder / DDPM 계열의 공통 원리). 본 연구는 이 원리를 **픽셀 노이즈 → PPG 파형 감독**이라는 크로스모달 형태로 적용한다.

### 연구 공백 (Research Gap)

1. **노이즈 기여의 인과적 분해 부재**: 실제 rPPG 데이터셋은 노이즈와 생리신호가 분리 불가능하게 얽혀 있어, "성능 저하의 몇 %가 조명 때문인가"라는 질문에 답할 수 없다. 조건 라벨(MMPD)은 범주적일 뿐 **연속 강도 통제**가 불가능하다.
2. **합성 데이터 연구에서 노이즈의 위상**: 선행 합성 데이터 연구(SCAMPS, Ou et al. 2023)는 노이즈를 도메인 갭을 메우는 *증강 기법*으로 다룬다. 노이즈 유형·강도를 **설계된 요인**으로 두고 성능 저하 곡선과 회복 곡선을 동시에 그린 연구는 없다.
3. **디노이징 원리의 적용 층위 불일치**: 확산모델 계열 rPPG 연구는 신호(1D/MSTmap) 단계에 가우시안 노이즈를 주입한다. **영상 픽셀 단계의 물리적 노이즈(조명 드리프트, 강체 지터, 표정)** 로부터 정답 PPG를 복원하도록 감독하는 구조는 검증되지 않았다.
4. **관류 이질성의 통제 불가**: 얼굴 영역별 rPPG 연구는 코·저관류 부위의 신호가 약함을 *관찰*하지만, 관류 분포 자체를 조작한 실험은 불가능했다. 이질성이 **ROI 선택으로 회피해야 할 문제인지, 학습으로 흡수 가능한 문제인지** 미해결이다.

## 연구 질문

- **RQ1**: 사전학습 PhysFormer의 HR 추정 정확도는 조명 변화·강체 움직임·센서 노이즈·표정 움직임 각각의 **강도가 증가함에 따라 어떤 형태로 저하**되며, 어떤 노이즈원이 지배적인가? 이 저하 양상은 고전 방법(POS/CHROM)과 어떻게 다른가?
- **RQ2**: 통제 노이즈로 오염된 합성 영상을 입력으로, **오염 전 정답 PPG를 감독 신호로** 미세조정하면 노이즈 조건에서의 정확도가 유의하게 개선되는가? 개선은 학습 시 본 노이즈에 국한되는가, 미관측 노이즈 유형으로도 일반화되는가?
- **RQ3 (탐색)**: 합성 데이터로 획득한 노이즈 강건성이 **실제 데이터셋(PURE / UBFC-rPPG)** 으로 전이되는가? sim-to-real 갭의 크기와 성격은 무엇인가?
- **RQ4 (신규)**: 맥동 진폭이 **공간적으로 이질적인**(패치별로 강/약/무맥동) 합성 데이터로 학습한 모델은, 이질적 관류를 갖는 평가 데이터에서 균일 주입 학습 모델보다 강건한가?

## 가설

- **H1 (문제 입증 — 저하)**: 사전학습 PhysFormer의 HR MAE는 노이즈 강도에 대해 **단조 증가**하며, 복합 노이즈 조건에서 clean 대비 통계적으로 유의하게 악화된다.
  - **H1a**: 저하 크기의 순위는 `복합 > 강체 움직임 ≈ 표정 움직임 > 조명 변화 > 센서 노이즈`이다. (모션이 주파수 대역에서 심박과 겹치므로)
  - **H1b**: 강도가 높아질수록 PhysFormer와 POS/CHROM의 격차가 **축소**된다 — 즉 학습 기반 모델의 우위는 분포 내(in-distribution) 조건에 국한된다.
- **H2 (핵심 — 회복)**: 노이즈 증강 합성 데이터로 디노이징 목적 하에 미세조정한 PhysFormer는 **noisy 조건 MAE가 사전학습 대비 유의하게 감소**하며(단측 검정), **clean 조건 성능은 비열등(non-inferior)** 하다(비열등 마진 Δ = 1.0 BPM).
  - **H2a (일반화)**: 학습 시 **제외한 노이즈 유형**(held-out noise)에 대해서도 개선이 관측되나, 그 효과크기는 학습된 유형 대비 작다.
- **H3 (탐색 — 전이 한계)**: 합성 데이터 미세조정 모델을 PURE / UBFC-rPPG에 zero-shot 적용하면, 합성 평가셋에서 관측된 개선폭이 **부분적으로만 재현**된다(Δ_real < Δ_synth). 즉 노이즈 증강은 도메인 갭을 좁히지만 소거하지 못한다.
- **H4 (신규 — 관류 이질성)**: 공간 이질(가우시안 패치) 진폭 맵으로 학습한 모델은, **이질적 관류 평가 조건에서 균일 주입 학습 모델보다 낮은 MAE**를 보인다. 특히 커버리지가 낮을수록(30%) 두 모델의 격차가 커진다(학습 조건 × 커버리지 **상호작용** 예측).
  - **H4a**: 균일 주입 학습 모델은 커버리지 감소에 따라 급격히 저하되나, 이질 학습 모델은 완만한 저하를 보인다.

> **가설 사전등록**: 위 가설·분석 계획은 본 실행 전에 확정하며, 설계서 커밋 해시를 사전등록 기록으로 삼는다. 사후 발견은 **탐색적(exploratory)** 으로 명시 구분한다.

## 연구 방법론

### 연구 설계

- **접근법**: 양적 · 계산 실험
- **설계 유형**: **요인설계(factorial) + 정체성 단위 분할 교차검증**
  - 평가: 노이즈 유형(6) × 강도(3) × BPM(3) × 진폭맵(2) 의 완전 교차 그리드, held-out 정체성 2명에 대해 반복
  - 학습: 학습 조건(4수준: 사전학습 / 균일 증강 미세조정 / 이질 증강 미세조정 / 노이즈 없는 합성 미세조정[대조]) × 시드(3)
- **핵심 비교 축**
  - **(a) 문제 입증**: 사전학습 PhysFormer의 clean → noisy 성능 저하 곡선
  - **(b) 가설 검증**: 노이즈 증강 미세조정 모델의 동일 그리드 성능
  - **(c) 기준선**: POS / CHROM (학습 불가, 노이즈에 대한 "무학습 하한선")
  - **(d) 대조**: 노이즈 없는 합성 데이터로만 미세조정 → 개선이 "합성 도메인 적응" 때문인지 "노이즈 학습" 때문인지 분리

### 디노이징 학습 구조의 조작적 정의

> **입력** = 노이즈 오염 영상 `V_noisy = N_θ(V_inject)`
> **감독 신호** = **오염 이전**의 정답 PPG 파형 `p(t)` 및 달성 BPM `achieved_bpm`
> **손실** = PhysFormer 표준 손실 (시간영역 negative Pearson + 주파수영역 label distribution / CE)
> → 모델은 `V_noisy`에서 `N_θ`에 **불변**인 성분만으로 `p(t)`를 재구성해야 하므로, 노이즈 불변 생리신호 표현이 강제된다.

- 디퓨전과의 대응: 디퓨전이 `x_0 → x_t` 순방향 오염 후 `x_0` 복원을 학습하듯, 본 구조는 `V_inject → V_noisy` 순방향 오염 후 `p(t)` 복원을 학습한다. **차이점**: 노이즈가 등방 가우시안이 아니라 **물리적으로 구조화된 노이즈**(조명·모션)이며, 복원 대상이 영상이 아니라 **잠재 생리신호**다. 반복적 역과정(reverse process)은 사용하지 않는 **단발(single-step) 디노이징 감독**이다 — 이 축약을 논문에서 명시한다.

### 일반화된 주입 모델

기존 예비실험의 균일 주입을 **공간 진폭 맵**으로 일반화한다:

```
I_c(x, y, t)  ←  I_c(x, y, t) · ( 1 + α · A(x, y) · p(t) · Pbv_c )
```

| 기호 | 의미 | 값/범위 |
|------|------|---------|
| `c` | RGB 채널 | {R, G, B} |
| `Pbv_c` | 혈액량 맥파 벡터 (정규화) | [0.33, 0.77, 0.53] |
| `α` | 전역 변조 깊이 | 기본 0.01 (실제 피부 맥동 상단), 스윕 시 {0.002, 0.005, 0.01, 0.02} |
| `p(t)` | 정답 PPG 파형 (평균 0, 단위 분산), HRV는 `--hrv_std`로만 명시 부여 | neurokit2, 통제 성분 0 고정 |
| **`A(x, y)`** | **공간 진폭 맵** (피부 마스크 내 0 이상) | 아래 3수준 |

**A(x,y) 수준 정의**

| 수준 | 이름 | 생성 규칙 | 의미 |
|------|------|----------|------|
| A0 | **균일(uniform)** | 피부 마스크 내부 `A ≡ 1` | 기존 예비실험. 이상화된 등질 관류 |
| A1 | **가우시안 패치 (커버리지 60%)** | 얼굴을 16×16 패치로 분할 → 가우시안 랜덤필드(공간 상관길이 ℓ ≈ 3패치)를 샘플링 → 상위 60% 패치에 `A ~ N(1, 0.3²)` 절단(≥0), 하위 40%는 `A = 0` | 코·지방 부위 등 저관류 영역 혼재를 모사 |
| A2 | **가우시안 패치 (커버리지 30%)** | 동일 절차, 상위 30%만 pulsatile | 극단적 이질 관류 (스트레스 조건) |

- **커버리지 100%(=A0), 60%(=A1), 30%(=A2)** 를 독립변수 수준으로 사용한다.
- **해부학적 사전지식 변형(A1-anat, 탐색)**: 랜덤필드 대신 이마·볼에 높은 가중, 코·턱에 낮은 가중을 주는 고정 맵. 랜덤 이질 학습이 해부학적 이질에도 전이되는지 확인 (H4의 외적 타당성 점검).
- **정답 불변성 보장**: `A(x,y)`가 무엇이든 시간 성분 `p(t)`는 동일하므로 **정답 PPG/BPM은 A와 독립**이다. 즉 A는 순수한 *공간 신호 강도 분포* 조작이며, 라벨 오염이 없다.
- **검증 절차**: 주입 후 각 패치의 복원 진폭을 실측하여 `A(x,y)`와의 상관을 확인(주입 무결성 QA). 예비실험의 "달성 BPM 실측" 관행을 진폭 맵으로 확장한다.

### 노이즈 모델 정의 (독립변수 IV1)

| 코드 | 노이즈원 | 구현 | 강도 파라미터 (L1 / L2 / L3) |
|------|---------|------|---------------------------|
| **L** | 조명 드리프트 + 플리커 | 전역 게인 `g(t) = 1 + a_d·sin(2π·0.05t + φ) + a_f·sin(2π·f_f t)`, 채널별 미세 색온도 변화 | `a_d` = 0.02 / 0.05 / 0.10, `a_f` = 0.005 / 0.015 / 0.03 (`f_f` ∈ {5, 7.5} Hz) |
| **G** | 공간 불균일 조명 | 이동하는 저주파 밝기 그라디언트(2D 코사인 램프, 0.1 Hz 이동) | 대비 0.03 / 0.08 / 0.15 |
| **M** | 강체 머리 움직임 지터 | 프레임별 affine (평행이동 + 회전 + 스케일), 1/f 노이즈 궤적 | 평행이동 σ = 1 / 3 / 6 px, 회전 σ = 0.5 / 1.5 / 3.0°, 스케일 σ = 0.2 / 0.5 / 1.0 % |
| **S** | 센서/코덱 노이즈 | 가우시안 리드 노이즈 + 포아송 샷 노이즈 + (L3에서) H.264 CRF 압축 | σ = 1 / 3 / 6 (0–255), CRF = – / – / 28 |
| **E** | 자연 표정 움직임 | LivePortrait 구동 영상 교체 (저모션 = 눈 깜빡임 위주 → 고모션 = 말하기/웃음, 예비실험 `d6`) | 저 / 중 / 고 (구동 클립 3종) |
| **X** | 복합 | L2 + M2 + S2 (X1), L3 + M3 + S3 + E3 (X2) | 2수준 |

- **적용 순서 (물리적 인과 순서 준수)**: `주입(A·p·Pbv)` → `표정 E(생성 단계에서 결정)` → `조명 L, G` → `강체 모션 M` → `센서/코덱 S`. 순서를 고정하고 로그에 기록한다.
- **파라미터 현실성 캘리브레이션**: `M`의 궤적 통계는 PURE/UBFC 실제 영상에서 랜드마크 추적으로 추정한 평행이동/회전 분포에 맞춘다. `L`은 MMPD의 조명 조건별 프레임 평균 휘도 분산에 맞춘다. **캘리브레이션 근거를 표로 문서화**한다(타당성 위협 완화의 핵심).

### 표본 = 합성 데이터셋 구성 (인간 피험자 대체)

> 계산 실험이므로 "표본 크기"는 **데이터셋 구성 규모 + 통계 검정력**으로 치환한다.

**학습 세트 (identity-disjoint)**

| 축 | 수준 | 개수 |
|----|------|------|
| 정체성 | SFHQ 4 + SDXL-Turbo 2 | 6 |
| 목표 BPM | 54, 66, 78, 90, 102, 126 | 6 |
| 노이즈 실현(realization) | 유형 조합을 랜덤 샘플링, 시드 고정 | 3 |
| 진폭 맵 | T2 = A0만 / T3 = {A0, A1, A2} 균등 혼합 | 1 또는 3 |

→ T2: 6 × 6 × 3 × 1 = **108 클립**, T3: 6 × 6 × 3 × 3 = **324 클립** (T3 과다 시 BPM 축을 4수준으로 축소해 216으로 맞춤 — **학습량을 T2와 동수로 맞추는 것이 H4 검정의 공정성 요건**).
클립당 1008프레임 → 160프레임 청크 6개 ⇒ T2 기준 **약 648 학습 윈도우 / 60분 분량**. (참고: UBFC-rPPG 실제 학습셋은 42분 분량 — 동급 규모)

**검증 세트**: 학습 정체성 중 1명을 홀드아웃하여 early stopping에만 사용(성능 보고에서 제외).

**평가 세트 (held-out identity)**

| 축 | 수준 | 개수 |
|----|------|------|
| 정체성 | 학습에 미사용 SFHQ 1 + SDXL 1 | 2 |
| 노이즈 조건 | clean(1) + L1–L3(3) + G1–G3(3) + M1–M3(3) + S1–S3(3) + E1–E3(3) + X1–X2(2) | **18** |
| 목표 BPM | 60, 78, 96 | 3 |
| 진폭 맵 | A0, A1, A2 | 3 |

→ 2 × 18 × 3 × 3 = **324 평가 클립 = 1,944 평가 윈도우**. 각 셀(조건×맵)당 2 정체성 × 3 BPM × 6 청크 = **36 윈도우**.

**검정력 근거 (표본 = 윈도우)**
- 주 검정: 조건별 paired 비교(T0 vs T2/T3), 셀당 n = 36 쌍.
- 양측 α = 0.05, power = 0.80, paired t 기준 검출 가능 최소 효과크기 **d ≈ 0.48**. 예비실험 기준 MAE 표준편차 ≈ 2 BPM ⇒ **약 1.0 BPM의 MAE 차이**를 검출 가능.
- 18개 조건에 Holm 보정 적용 시 실질 α ≈ 0.003 ⇒ 검출 가능 d ≈ 0.65 (**≈ 1.3 BPM**). H2가 주장하는 개선폭(선행연구 기준 수 BPM 규모)보다 충분히 작으므로 **검정력 확보**.
- 윈도우 간 독립성 위반(같은 클립 내 청크는 상관)을 고려하여 **주 분석은 혼합효과모형 + 클립 단위 클러스터 부트스트랩**으로 수행하고, paired t는 보조로만 보고한다.

**반복 / 시드**
- 데이터 생성 시드 3개 × 학습 시드 3개 중, **주 실험은 데이터 시드 고정 + 학습 시드 3개**(모델 학습 변동 추정). 데이터 시드 민감도는 부속 실험으로 1회 확인.
- 모든 결과는 **3 시드 평균 ± 표준편차**로 보고하며, 단일 시드 최고값 보고를 금지한다.

**계산 자원 / 저장 관리**
- 무손실 PNG 전량 저장은 수 TB 규모가 되므로, **노이즈 오염 `N_θ`는 데이터로더에서 온더플라이(on-the-fly) 적용**한다. 디스크에는 주입 완료 clean 클립(A별)만 저장하고, 노이즈 파라미터는 시드로 재현한다. 평가셋만 **완전 물질화(materialize)** 하여 모든 모델이 비트 단위로 동일한 입력을 보도록 고정한다 — 공정 비교의 필수 조건.
- 학습 1회 ≈ RTX 5090 32GB에서 수 시간 규모 추정. T1/T2/T3 × 3 시드 = 9회 학습.

## 분석 계획

**주 분석 (사전등록)**

1. **저하 곡선 (H1)**: `MAE ~ 노이즈유형 × 강도수준 + (1 | 정체성) + (1 | 클립)` 선형혼합모형. 유형별 강도 기울기의 부호·크기를 검정하고, 유형 간 기울기 대비(contrast)로 H1a의 순위를 검정한다.
2. **방법 간 격차 (H1b)**: `MAE ~ 방법(PhysFormer/POS/CHROM) × 강도` 의 **상호작용항**이 유의한지 검정. 상호작용 계수가 음(=격차 축소)이면 H1b 지지.
3. **회복 효과 (H2)**: 조건별 paired 비교(동일 평가 윈도우에 T0 vs T2). 정규성 위반 대비 **Wilcoxon signed-rank** 를 주 검정으로, 효과크기는 **Cliff's δ** 및 **ΔMAE의 클러스터 부트스트랩 95% CI**(BCa, 2,000 resample, 클립 단위 재표집)로 보고. 18조건에 **Holm–Bonferroni** 보정.
4. **clean 비열등 (H2)**: clean 조건에서 `MAE(T2) − MAE(T0)` 의 95% CI 상한 < **Δ = 1.0 BPM** 이면 비열등 지지 (단측).
5. **노이즈 학습 vs 도메인 적응 분리**: T1(clean 합성 미세조정) 대비 T2의 추가 개선분 = **노이즈 학습의 순효과**. 이 대조가 본 연구 주장의 핵심 증거다.
6. **일반화 (H2a)**: held-out 노이즈 유형(학습 시 **G와 S를 제외**하고 학습한 T2-ho 모델을 G/S 조건에서 평가)에서의 ΔMAE를, 학습된 유형(L/M/E)에서의 ΔMAE와 비교. 두 개선폭의 비율을 **일반화 지수**로 보고.
7. **관류 이질성 (H4)**: `MAE ~ 학습조건(T2 균일 vs T3 이질) × 커버리지(100/60/30) + (1|정체성)` 혼합모형의 **상호작용항**을 주 검정으로 한다. H4a는 커버리지에 대한 단순기울기(simple slope) 비교로 검정.
8. **sim-to-real (H3, 탐색)**: PURE / UBFC-rPPG에 zero-shot 평가. `Δ_real / Δ_synth` 비율과 절대 MAE를 rPPG-Toolbox 공개 벤치마크 수치와 병기. **탐색적으로 명시**하고 다중비교 보정 대상에서 분리 표기.

**보조 분석**
- 노이즈 불변성 지표(중간층 임베딩 코사인 유사도)와 ΔMAE의 상관 → H2의 기전 근거.
- 피부톤 3분위 × 노이즈 강도 상호작용 (탐색, SCAMPS의 피부톤 발견과 대조).
- 실패 사례 정성 분석: 스펙트럼에서 모션 하모닉이 심박 피크를 압도하는 윈도우를 시각화.

**보고 원칙**
- 모든 조건의 결과를 **완전 보고**(유의하지 않은 셀 포함). 조건 선별 보고 금지.
- 표는 `MAE / RMSE / r / SNR` 4지표를 항상 함께 제시 — MAE만 개선되고 SNR이 악화되는 경우를 은폐하지 않는다.
- 그림: (a) 노이즈 유형별 강도–MAE 저하 곡선(모델별 겹쳐 그림), (b) 조건별 ΔMAE 포레스트 플롯(95% CI), (c) 커버리지 × 학습조건 상호작용 플롯, (d) 대표 스펙트럼 비교.

## 윤리적 고려사항

- **IRB 필요 여부**: **불필요.** 인간 피험자·인체 유래물·개인정보를 수집하지 않는 순수 계산 실험이다. 모든 얼굴은 실존하지 않는 합성 정체성이다.
- **동의서 요건**: 해당 없음(합성 데이터). 단 **H3의 외부 검증에 사용하는 PURE / UBFC-rPPG는 실제 인체 데이터**이므로, 각 데이터셋의 **이용약관(EULA)·연구목적 한정 조항을 준수**하고, 원 영상 프레임을 논문에 게재하지 않는다(수치·파형만 보고).
- **데이터 익명화**: 합성 얼굴에 대해 "실존 인물과 우연히 유사할 가능성"을 고지하며, 논문 게재 이미지는 SFHQ(MIT) 라이선스 범위 내에서 사용한다. SDXL-Turbo 생성물은 Stability AI 라이선스 조건을 확인·표기한다.
- **이중용도(dual-use) 고려**: 본 연구의 파이프라인은 **영상에 인공 심박을 심는 기술**을 포함하므로, 딥페이크의 rPPG 기반 탐지를 **회피**하는 데 전용될 수 있다. 논문에 다음을 명시한다 — ① 연구 목적은 rPPG 강건성 향상과 **탐지기 평가용 하드 네거티브 생성**이며, ② 주입 코드는 연구 목적 라이선스로 공개하고, ③ 생성물에는 합성 표식(메타데이터)을 부착한다.
- **재현성**: 모든 시드·설정·달성 BPM·체크섬을 로그로 공개하고, 코드·설정 파일을 저장소에 함께 배포한다.

## 한계 및 후속 연구

**한계**
1. 결론의 일차적 유효 범위는 **합성 실험장 내부**다. "PhysFormer가 실제 환경에서 이만큼 개선된다"로 확장 해석할 수 없다.
2. 노이즈 목록은 완결적이지 않다 — 부분 가림(occlusion), 안경/화장, 극단적 저조도, 다중 광원 색온도 혼재, 다양한 카메라 ISP 파이프라인은 이번 범위 밖이다.
3. 정체성 8명(학습 6 + 평가 2)은 소규모이며, 피부톤·연령 분포가 SFHQ 샤드 표본에 의존한다. SCAMPS가 보고한 "아바타 수에 따른 성능 증가" 곡선의 저점 구간에 위치할 가능성이 있다.
4. 관류 이질성 모델(가우시안 랜덤필드 패치)은 **해부학적 근거가 아닌 통계적 근사**다. 실제 관류 분포와의 일치도는 검증되지 않았다.
5. 디노이징 구조는 단발 감독이며, 완전한 반복적 확산 역과정을 구현하지 않는다.

**후속 연구**
1. **실제 데이터 벤치마크 검증(최우선)**: PURE / UBFC-rPPG, 나아가 MMPD(조명·모션 다요인) 및 UBFC-Phys에서 rPPG-Toolbox 표준 프로토콜로 미세조정 모델을 평가하여 H3를 본격 검정한다. 여기서 개선이 재현되지 않으면 본 연구의 실무적 기여는 제한된다 — **이 검증 없이는 저널 투고 불가**로 간주한다.
2. **정체성 규모 확장**: SFHQ 전체 샤드 활용으로 30–100 정체성 규모의 학습셋을 구성하고, "정체성 수 vs 강건성" 스케일링 곡선을 그린다.
3. **모델 일반화**: TS-CAN, PhysNet, RhythmFormer, PhysMamba, FactorizePhys에 동일 프로토콜 적용 → 결론이 아키텍처 특이적인지 확인.
4. **완전 확산 구조**: 반복적 역과정 기반 rPPG 복원(DiffPhys 계열)과 본 단발 감독 구조의 정면 비교.
5. **해부학적 관류 맵**: 실제 데이터에서 추정한 영역별 pulsatile 강도 맵으로 A(x,y)를 대체하고, 학습된 모델이 **ROI 선택 없이도** 최적 ROI 기반 방법에 필적하는지 검정.
6. **α 스윕 검출 한계 곡선**: 노이즈 조건별로 α를 낮춰가며 각 방법의 최소 검출 변조 깊이를 측정 — "노이즈가 검출 한계를 얼마나 밀어올리는가"의 정량화.

### 통계분석가(statistical-analyst)에게
- 주 검정 = **선형혼합모형**(고정: 노이즈유형 × 강도 × 학습조건 × 커버리지 / 랜덤: 정체성, 클립) + **클립 단위 클러스터 부트스트랩 95% CI**. 청크 간 상관 때문에 단순 t 검정을 주 근거로 삼지 말 것.
- 핵심 검정 3개: ① 강도 기울기(H1), ② 조건별 paired ΔMAE + Holm 보정(H2), ③ **학습조건 × 커버리지 상호작용**(H4).
- **비열등 검정**(clean 조건, Δ = 1.0 BPM, 단측)을 별도로 수행할 것.
- T1(clean 미세조정) 대비 T2의 **추가 개선분** 대비가 논문의 핵심 주장 — 이 수치를 독립 표/그림으로 분리 제시.
- 효과크기는 Cliff's δ(비모수)와 ΔMAE 절대값을 병기. 3 학습시드의 평균 ± sd 보고 필수, 최고 시드 단독 보고 금지.
- 지표 4종(MAE/RMSE/r/SNR) 완전 보고. 유의하지 않은 셀 포함 전조건 보고.

### 논문작성자(paper-writer)에게
- **포지셔닝 문장**: "선행 합성 데이터 연구는 노이즈를 도메인 갭을 메우는 *증강 기법*으로 사용했다. 본 연구는 노이즈를 *독립변수*로 승격시켜, 정답을 아는 실험장에서 rPPG 성능 저하와 회복을 유형·강도별로 분해한다."
- Related Work 3축 구성: ① 고전 신호처리(CHROM/POS) ② 딥러닝 rPPG(PhysFormer 계열) + 강건성 벤치마크(rPPG-Toolbox, MMPD) ③ 합성 데이터·디노이징(SCAMPS, Ou et al. 2023, DiffPhys 계열).
