# 65. 학습된 잡음 빼기 + 이중 렌더 픽셀·색 정답 (체인 124, 사전 등록 11-07)

## 1. 왜 하는가
사용자 지시(11-07): "두 가지 묶어서 시험해주세요". 두 가지는 다음과 같다.
1. 학습된 잡음 추정을 주 경로에서 실제로 빼는 구조
2. 이중 렌더 정답을 프레임당 숫자 하나가 아니라 픽셀·색 단위(저해상도 RGB 영상)로 주는 것

배경은 다음과 같다.
- 64 §5·§8: 1차원 잡음 정답은 효과가 측정되지 않았다. 라벨이 들어가는 잡음 칸에는 출력에서 잡음을 빼는 경로가 없고, 학습 클립의 잡음은 참조 신호에 이미 보인다(스펙트럼 코사인 중앙값 0.99).
- 64 §6, 58 §S6d: 심박과 잡음이 4 bpm 안이면 출력이 심박의 약 2배로 간다. 투영 층이 있어도 없어도 같다.
- 시간축 투영은 참조와 같은 주파수의 성분을 통째로 지운다. 160프레임 청크의 주파수 간격은 11.25 bpm 이라 이보다 가까운 잡음과 맥파는 시간 정보로 가를 수 없다. 남은 단서는 위치(맥파는 피부에만)와 색(맥파는 정해진 색 방향)이다.
- 이중 렌더의 둘째 벌은 같은 장면을 맥파 없이 만든 영상이다. 같은 가중치로 두 영상의 특징을 구하면, 맥파가 만든 특징 변화 v − v_N 을 정확히 알 수 있다. 실제 영상에서는 얻을 수 없는 정답이다.

**데이터.**
- 기존 이중 렌더 48클립(피험자 261~308)을 `noise_video` 로 다시 렌더했다. 1차원 정답 48/48 이 기존과 같고, 영상은 캐시의 입력 청크와 비트 단위로 같다(아래 사이드카 검증).
- 새 이중 렌더 학습 48클립 `TRAIN48DR`(피험자 2001~2048, `scripts/make_dr_configs.py`): 풀의 합성 정체성 5개(SFHQ 01·02·03·05·06), 실 PPG 뱅크 파형, 진폭 0.008, 심박 48~170 bpm. 잡음 4종 × 12클립:

  - B 피부 국소 플리커(피부의 35 % 블롭, 진폭 8 %), 심박에서 0~4 bpm
  - C 피부 국소 플리커, 심박에서 8~40 bpm
  - D 주기 머리 움직임(6 px), 심박에서 0~4 bpm
  - 공통: 조명 드리프트 0.15, 무작위 이동 6 px, 회전 1.5°, 센서 잡음 2
- 잡음 영상 사이드카 `{cache}/{name}_noisevid{i}.npy`(`scripts/noisevid_sidecar.py`): 툴박스와 같은 얼굴 상자(첫 프레임 Haar, 큰 상자 1.5)를 두 영상에 똑같이 적용했다. 입력 청크와 비트 단위로 같은지 확인한 뒤에만 저장했고, 96/96 클립(576 청크)이 통과했다. 트레이너의 잡음 영상 변환을 입력 사이드카에 적용하면 로더가 만든 학습 입력과 최대 차 0 이다(`scripts/lsub_smoke.py`).
- 학습 풀: 기존 366클립 + 새 48클립 = 414클립, 3,953 청크(`cotrain_allf_hyb4_dr_u8_pool.csv`). 1차원 잡음 정답은 96클립(`noise_gt_dr`).

**모델 (`NF_LSUB=1`).** 학습된 잡음 빼기 모듈 `LearnedNoiseSub` 를 conv_block 출력 v(16채널 × 160프레임 × 7×7)와 기존 투영 사이에 넣었다.
- 입력: v(표본·채널별 표준화)와 잡음 참조 8개(측면 띠 R·G·B, 화면 전체 R·G·B, LK 이동 vx·vy). 참조에는 투영 층과 같은 진폭 게이트를 건다.
- 3D 합성곱 두 층(시간 5 × 공간 3×3, 은닉 16채널)이 잡음 성분 s(시간 평균 0)를 예측하고, v − s 를 기존 투영과 두 슬롯에 넘긴다. 공간과 채널 관계를 보므로 같은 주파수의 잡음도 위치와 색으로 가를 수 있다.
- 파라미터 28,832개(모델 52,169 → 81,001). 마지막 층을 0 으로 초기화해 시작 시 출력이 현재 최종 모델과 같다(CPU 확인, 최대 차 0). 학습과 평가에 모두 적용된다.

**분리 감독 (`NF_LSUB_SUP=1`).** 잡음 영상 사이드카가 있고 배속 증강이 걸리지 않은 청크마다 다음을 계산한다.
- 같은 가중치로 잡음 영상의 특징 v_N 을 구한다(기울기 없음).
- L_sep = log(‖s − (v_N − v̄_N)‖² / ‖(v − v_N) − 시간 평균‖² + 10⁻³)
- s = 0 이면 L_sep = r0(특징 수준의 잡음 대 맥파 에너지 비의 로그)이다. 모든 시간 변화를 지우면 0, 맥파 특징을 남기고 잡음만 지우면 음수가 된다.
- 기울기는 빼기 모듈로만 간다. 트렁크는 기존 출력 손실로만 학습한다. 가중 `NF_LSUB_W` = **8**(§2.1).

나머지 레시피는 현재 최종 모델과 같다: 피부 가중 0.2, 참조 기반 배제, 두 슬롯, 투영 λ = 0.01, 배가 억제 0.5, ×2 증강 0.25, 1차원 잡음 정답 L_nuis, lr 1e-4, 10에폭, 공개 FactorizePhys 가중치에서 시작.

## 5. 판정 규칙 (결과 전 확정, `scripts/lsub_judge.py`)
- **가족 M (기전, Holm 2), 학습된 빼기 + 정답 vs 기준:** M1 전역 플리커 근접 12클립, M2 피부 국소 플리커 근접 12클립. 클립별 r 의 5시드 평균을 쌍대 비교하고, 정확 부호 뒤집기 순열(양측)로 검정한다. 지지: Δr > 0, Holm p < .05.
- **가족 P (실제 정확도, Holm 5), 같은 비교:** VIPL-HR 전체, MMPD 7~33 전체, 풀 저심박, 풀 고심박, MR-NIRP 소동작. 영상별 오차의 5시드 평균, 부호 뒤집기 순열(양측), Wilcoxon 병기. 지지: Δ < 0, Holm p < .05.
- **가족 L (정답의 몫, Holm 7):** 학습된 빼기 정답 있음 vs 없음, M1·M2·P 5개.
- **가드 (학습된 빼기 + 정답 vs 기준):** VIPL <60, VIPL ≥120, MMPD <110, MMPD ≥110, DLCN, RTNI, PURE. Δ > +0.3 bpm 이고 보정 없는 p < .05 면 위반이다.
- **해석:** M 지지는 위치·색으로 같은 주파수 분리가 된다는 뜻이다(합성 영상). P 지지와 가드 유지는 실제 정확도로 이어진다는 뜻이다. L 지지는 이중 렌더 정답이 필요하다는 뜻이다. 아무것도 지지되지 않으면 '측정되지 않음', 반대 방향 유의는 '역효과'로 쓴다.
- **결과를 쓰는 방법:** P 지지와 가드 유지면 최종 설정 교체 후보로 사용자에게 올린다(자동 교체 안 함). M 만 지지면 합성 영상 수준의 기전 근거로만 쓰고, 원고 반영은 사용자가 정한다. 지지가 없으면 그대로 보고하고, 이중 렌더 정답의 이득은 측정되지 않은 것으로 둔다.
- **사전 기록 주의:** 새 풀은 합성 클립이 48개 늘었다(64 §5 에서 합성 클립은 MMPD 를 나쁘게 했다). 기준(새 풀)과 현재 최종 모델의 비교는 시드와 풀이 달라 서술만 한다. 실제 시험 영상은 이전 실험과 같고, 분리 시험 24클립만 새로 만들었다. 공학 점검 학습(§2.1)은 판정에 쓰지 않는다.

| 기존 플리커 먼 거리 (4클립) | 0.696 | 0.743 | +0.047 | 0.740 |

보정 뒤 남은 이득은 잡음이 심박과 먼 클립의 이득과 크기가 같다. 같은 주파수 잡음을 가른 근거가 아니라, 파형 전반이 조금 나아진 것으로 읽는 것이 맞다. 심박 판독도 그대로다. 전역 플리커가 심박 4 bpm 안이면 모든 갈래가 청크의 0~42 % 만 맞힌다(거리별 평균: 기준 0~33 %, 빼기 + 정답 8~33 %, 빼기만 10~42 %, 현재 최종 0~30 %). 피부 국소 플리커는 판독이 약간 오르지만(예: −2 bpm 거리 0.87 → 1.00) 검정한 지표가 아니다. 정답 없는 갈래가 지연 보정 후에도 같거나 낫다(전역 근접에서 정답 있는 쪽 −0.020, p = .008).

### 6.2 학습 중 분리 손실
다섯 시드 모두 마지막 에폭 sep 가 0.21~0.23 으로 양수다(r0 1.22~1.33). 이중 렌더 정답이 있는 학습 청크에서도, 모듈은 '모든 시간 변화를 지움'보다 맥파 특징을 잘 남기지 못했다. 모듈은 모든 청크에서 특징 시간 변화의 약 75 % 크기를 뺀다(srel 0.74~0.76). 정답 없는 갈래도 65~79 % 를 뺀다(마지막 에폭, 시드별).

### 6.5 결론
- 사용자의 원래 구상(심박과 잡음을 함께 렌더해 둘의 분리를 학습)을, 이번에는 위치·색을 볼 수 있는 학습된 빼기 모듈과 픽셀·색 단위 정답으로 다시 쟀다. 이중 렌더 정답의 몫은 이번에도 측정되지 않았다. 정답이 없는 같은 모듈이 같거나 낫다.
- 같은 주파수 잡음을 가른다는 근거도 나오지 않았다. 사전 등록 지표는 지지됐지만, 탐색 점검에서 대부분 출력 위상 차이로 설명된다.
- 모듈 자체는 실제 영상에서 뚜렷한 트레이드오프를 만든다(보통 심박·움직임 영상 개선, 110 bpm 이상 악화). 최종 설정 교체 후보가 아니다.
- 원고는 바꾸지 않았다. 반영 여부는 사용자가 정한다.
