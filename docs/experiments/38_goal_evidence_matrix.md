- **기여 귀속(36 §9 3시드 공정 비교 + 34 §8 MMPD 인트라 3시드)**: 위 우위 가운데 우리 방법에 귀속되는 부분은 ① MMPD in-domain 의 코퍼스 데이터 기여(7.26 → 6.65, Holm p=.015)와 분해 손실의 움직임 기여(8.14 → 7.29, Holm p=.027; 3시드로 사전 등록 1차 3건 모두 지지, 10-22), ② UBFC 출발점에서 PhysFormer 의 MMPD 움직임 분해 손실 이득(−1.50, Holm p=.010)과 실 얼굴 손상 사본이며, 가상얼굴은 역방향, VIPL in-domain 은 기여 0. 보강 실험(45 문서, §G-7~§G-9, 10-26~27)의 보정: 분해 목적함수는 정확한 잡음 라벨을 요구하지 않고(관측 trace 라벨 Δ≈0) zero-shot 이득은 비유의·MR-NIRP 주행 비용이 있어 "휴대폰 움직임 in-domain 한정" 으로 좁힌다; 공식 코퍼스 체크포인트에서 출발하는 2단계 미세조정은 MMPD 5-fold 6.10(시드 1; 공개 출발 7.10 대비 −1.00, 3시드 분해 셀 5.91 과 동등)으로 코퍼스의 사전학습 자원 가치를 보이지만 VIPL 은 +0.27 열세로 기여 0 유지; 가상얼굴 42 클립은 같은 수의 MMPD 실 클립 42 보다 MR-NIRP 소동작·PURE 에서 우세하므로 "역방향" 은 UBFC 출발점 요인 실험의 VIPL 결과에 한정해 읽는다.
- **결론**: 고전 방법과 PhysFormer·RhythmFormer 공개 가중치에 대해서는 세 축 모두 정확도 향상이 성립한다. FactorizePhys 공개 가중치에 대해서는 MMPD in-domain 에서만 확정되고 zero-shot·VIPL in-domain 에서는 동등 또는 열세이므로, 원고는 "FactorizePhys 를 포함한 모든 기존 방법을 모든 축에서 이긴다" 고 쓰지 않는다. 수치 출처: `results/agg_{POS,CHROM,PFbase,RFbase,FPbase}_VIPL.json`, `agg_{POS,CHROM,base,RhythmFormer,FactorizePhys}_MMPD.json`, `agg_CoTAF_TW_L*`, `agg_CoTAM_HYB4_L*`, `agg_CoTAM_HYB4_SOUP_L*`, `agg_CV_{TWg,HYB,BASEAV}_L_VIPL.json`, `agg_MCV5_{BASE,TW,HYB}_L_MMPD.json`.
- **범용 도메인 일반화 기준선과의 관계(§G-2, 10-23 체인 55 3시드)**: 위 표의 "기존 방법"(고전·공개 가중치 3종)에는 포함되지 않지만, 같은 공식 코퍼스로 학습한 GroupDRO 셀이 VIPL zero-shot 에서 채택 모델(9.00 → 7.53)과 분해 모델(8.09 → 7.53)을 유의하게 이긴다(다만 MMPD held-out·PURE·통제 노이즈·MR-NIRP 움직임에서 붕괴, 도메인 가중이 MCD 단독 수렴). 따라서 원고의 zero-shot 서술은 "고전·공개 가중치 대비 향상" 으로 한정하고, 범용 DG 에 대해서는 "전 축 동시 우세는 없음 + 분해 손실은 DG 위에서도 휴대폰 움직임 오차를 줄이는 플러그인" 까지만 쓴다(40 §10). 이 결론 문단의 판정(성립 3건·부분 성립 1건)은 바뀌지 않는다. §G-3(체인 56, MCD 가중 코퍼스, 10-23)도 같은 방향이다: 강건성 가드를 통과한 MCD ×4 셀(VIPL 8.27)조차 FactorizePhys 공개 가중치 6.88 을 넘지 못하므로, 위 표 FactorizePhys 행의 "VIPL zero-shot 열세" 는 시험한 모든 변형(공식 코퍼스·분해·소프·범용 DG·MCD 가중·FactorizePhys 백본 결합, 그리고 §G-4 체인 57 의 원시 입력 PhysFormer 7.99 — PhysFormer 계열 최선이나 +1.11 열세)에서 확정이다.
- **VIPL in-domain 칸 최종(§G-5 → §G-6, 체인 58·59, 10-24)**: 고심박(≥90 bpm) 손실 가중 셀은 시드 100 에서 6.10 으로 FactorizePhys 공개 가중치 zero-shot 6.88 을 유의하게 넘었으나, 시드 200·300(6.54/6.36)을 더한 3시드 풀링 6.34 는 앵커 6.51 대비 −0.17(Holm p=.30)·FactorizePhys 대비 −0.55(Holm p=.34) 모두 비유의 → 단일 시드 결과로 철회하고 위 표의 "동등(유의차 없음)" 을 유지한다. 사전 등록 게이트 불통과로 후속(zero-shot 가중·VIPL 단독+가중·앵커 시드)은 미실행. VIPL in-domain 에서 최강 기존 방법 대비 향상은 어떤 변형으로도 확정되지 않았다.

## E. 추가 검정 결과 (10-21, 체인 54 — 39 문서 §6)

FactorizePhys 를 공식 코퍼스(203) / 하이브리드 풀(366 + 분해 손실)로 미세조정한 셀(3시드)은 공개 FactorizePhys 체크포인트 대비 **VIPL zero-shot 악화**(9.43 / 8.44 vs 6.88, Holm p<.0001), **MMPD zero-shot 악화 또는 동등**(정본 float 경로 10-22 확정: 코퍼스 셀 10.60 vs 9.79 +0.81 Holm p=.023 악화, 분해 셀 10.66 +0.88 ns; 39 §7). 따라서 §D 의 FactorizePhys 열은 변하지 않는다: 기존 방법 중 FactorizePhys 공개 가중치에 대한 우위는 MMPD in-domain 에서만 성립하고, zero-shot 에서는 백본을 바꿔도(코퍼스를 FactorizePhys 에 주어도) 성립하지 않는다. 최종 문장: **"기존 방법 대비 정확도 향상" 은 고전 방법·PhysFormer·RhythmFormer 공개 가중치에 대해 세 축 모두 성립하며, FactorizePhys 공개 가중치에 대해서는 MMPD in-domain 에서만 성립한다.**

결론: "최신 일반화 기법과 같은 데이터로 비교" 요구에 대한 답은 **범용 DG 기준선 3종은 채택·분해 모델을 넘지 못했고, 분해 손실은 세 기법 위에서 모두 휴대폰 움직임 오차를 줄였다** 이다. 단일 시드 결과이며, 게이트를 통과한 GroupDRO 만 시드 200·300 을 추가 중(Phase 2, 10-23 새벽). NEST·HSRD 등 rPPG 전용 DG/TTA 기법과의 비교는 미실시(40 §7). VIPL 문헌형 읽기 병기 결과(40 §6·§8): in-domain 5-fold 셀만 0.2~0.8 유리, zero-shot PhysFormer 계열은 악화 → §A 수치는 정본 읽기 유지.

**G-2. 3시드 최종(10-23 00:46, 40 §10)**: 게이트를 통과한 GroupDRO 두 셀을 시드 100·200·300 으로 반복(앵커도 3시드). 공식 코퍼스 + GroupDRO VIPL **7.53** vs 채택 모델 9.00(−1.47 Holm p<.0001)·분해 모델 8.09(−0.56 p<.0001) — **VIPL 에서는 범용 DG 셀이 우리 두 모델을 유의하게 이긴다**; 그러나 같은 셀이 MMPD held-out 13.55(+3.24 악화), PURE held-out 14.1(앵커 0.44), 통제 노이즈 30.3(플리커 lock-in), MR-NIRP 움직임 +2.2 로 무너지며, 세 시드 모두 도메인 가중이 MCD 로 수렴(≥0.997)했다 → 실체는 "MCD 48 클립 단독 적합" 이고, 이는 §D 의 귀속(zero-shot 우위의 원천 = PURE·MCD 실 클립)을 뒷받침한다. 분해 풀·손실을 GroupDRO 위에 얹으면 MMPD 움직임 −3.91(Holm p<.0001, H-G2 3시드 지지). 최종: **H-G1 기각(전 축 동시 개선 없음)·H-G2 지지(휴대폰 움직임 한정)·H-G3 기각(우리 분해 모델이 최선 DG 셀보다 우세하지 않음 — VIPL 열세, MMPD 동등~열세)**. 원고에서는 "범용 DG 가 우리를 전 축에서 넘지 못함 + 분해 손실은 플러그인" 까지만 주장하고, "우리 방법 > DG" 는 쓰지 않는다.
