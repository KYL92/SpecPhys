# 42. 체인 57 사전 등록 — 원시(Standardized) 입력 PhysFormer: 고심박(운동 후) 실패의 원인이 입력 표현인가 (2026-10-23, 사후 실험 명시)

## 1. 왜
목표의 VIPL 칸(최강 기존 방법 FactorizePhys 6.88 대비 향상)은 체인 46z4·54·55·56 모든 변형에서 불성립. 10-23 진단으로 격차의 소재가 좁혀졌다: **60–90 bpm 에서는 우리 모델이 FactorizePhys 보다 낫고(in-domain 4.40 vs 6.30), 90–120 bpm(11.8 vs 7.2)·≥120(37~44 vs 20.5)·운동 후 v7(14.8 vs 8.9)에서만 진다.** 코퍼스의 심박 분포는 고심박을 충분히 담고(90–120 구간 43%, UBFC 중앙값 102) in-domain VIPL 학습·시간 배속 증강·MCD 가중·GroupDRO 어느 것도 90 bpm 이상 구간을 고치지 못했다(모두 10.4~13.8). 따라서 남은 가설은 **입력 표현**: PhysFormer 의 프레임 차분(DiffNormalized) 입력이 운동 후 영상(거친 호흡·상체 흔들림)에서 빠른 맥파를 저주파 교란에 묻히게 한다. FactorizePhys 는 원시 프레임 표준화 입력을 쓴다.

## 2. 셀 (공식 코퍼스 203 u8 풀, 입력 `DATA_TYPE: [Standardized]`(툴박스 패치 29, 풀 캐시는 청크 통계 폴백), 라벨·읽기는 정본 그대로)

평가: **VIPL 2,378편 zero-shot 만**(13축·MMPD 는 Standardized 캐시가 없어 Phase 1 생략 — 게이트 통과 시 Phase 2 에서 시드 추가 후 주요 축 캐시 생성 검토). 앵커 `CoTAF_TW_L`(차분 입력, 같은 풀), 기준 `FPbase`.

## 3. 가설·판정 (`scripts/raw_judge.py`, 영상 단위 쌍대 Wilcoxon, Holm 2 × 셀)
| 가설 | 비교 | 기준 |

| H-R1 입력 표현이 원인 | 셀 vs 앵커, **90–120 bpm 구간(387편) 문헌 GT MAE** | Δ<0 Holm p<.05; 가드: 60–90 구간 악화 ≤1.0 |
| H-R2 최강 기존 방법 초과 | 셀 vs FactorizePhys 6.88, VIPL 전체 문헌 GT | Δ<0 Holm p<.05 |

**함의**
1. 원시 입력 PhysFormer(`RAW_TW_L`)는 우리 PhysFormer 계열 중 VIPL zero-shot 최선(7.99; 채택 9.00·분해 8.09·MCD ×4 8.27·GroupDRO 7.53 은 붕괴 동반)이며 60–90 bpm 도 같이 좋아진다. 다만 **13축·MMPD 는 Standardized 캐시가 없어 미평가** — 통제 노이즈·움직임 강건성이 유지되는지 모르므로 채택 모델 교체 주장은 할 수 없다(후속: 13축 Standardized 캐시 생성 후 재평가, 사용자 결정).
2. 목표의 VIPL 칸 최종: **FactorizePhys 대비 향상은 어떤 변형으로도 성립하지 않는다**(체인 46z4·54·55·56·57 누적). 차분 입력이라는 설계 선택이 고심박 손실의 일부를 설명한다는 점은 원고의 한계·후속 연구 절에 들어간다.
