# 23단계 — 주입 진폭 혼입 ablation (체인 40, 2026-09-03 사전 등록)

## 사용자 발견 (코드 검증 완료)
- 해석적 파형: `make_waveform`에서 **std=1** 정규화 (inject_pulse.py L50)
- TW 뱅크 파형: builder에서 **max|x|=1** 정규화 → 실측 RMS = **0.414** (뱅크 131세그 평균; p10/50/90 = .336/.418/.487)
- 주입은 `g = 1 + α·ppg·Pbv` 이므로 **해석적이 ~2.4배 강한 픽셀 변조** — TW의 개선(12.33→10.31, p=.0011)이
  waveform morphology가 아니라 "약한 주입(=저SNR·현실적 학습 신호)"에서 왔을 가능성. 라벨은 DiffNormalized
  표준화로 스케일 불변이라 학습 라벨엔 영향 없음 — 영향 경로는 순수하게 **영상 픽셀 변조 크기**.

## 판정 (사전 등록)
- AL ≈ TW & TWH ≈ CoTAF_L → **진폭이 원인** (morphology 주장 철회, T7·논문 §수정 필요 — 대신 "주입 진폭 = 유효 SNR 제어"라는 새 발견)
- AL ≈ CoTAF_L & TWH ≈ TW → **morphology가 원인** (기존 주장 생존, 진폭 무관 확인을 각주로)
- 중간(둘 다 부분 기여) → 기여 분해 수치로 정직 기록
기준선: CoTAF_L 12.19/12.33±0.29, CoTAF_TW_L 10.51/10.31±0.19. 로그 /tmp/chain40.log, 6 학습 ≈ 9h.

**판정: 사전 등록 시나리오 ③(양 요인 기여)** — 총 격차 2.02 BPM 중

- 상호작용 ≈ 0 (근사 가산적), 어느 단독도 TW 미달(둘 다 TW 대비 유의 열세).

**논문 수정 지침(T7·§16-17)**: "waveform morphology가 주효과" 주장은 **생존**하나 다음을 병기 —
① max-abs 정규화가 만든 약한 주입(RMS 0.41)이 유의한 보조 기여(현실적 신호 세기 = 유효 SNR 정합 효과),
② TW의 온전한 효과는 두 요인의 결합. 사용자 코드 검토가 발견한 혼입으로, ablation 없이는 morphology에
과대 귀속될 뻔한 부분(0.68 BPM)을 분리해냄. AL의 시드 분산(0.57)이 TW(0.19)보다 큰 점은 해석적 파형의
한계가 진폭 저감으로 해소되지 않음을 시사.
