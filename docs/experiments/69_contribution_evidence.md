사용자 지시(/goal): "마지막으로 논문에 기여점과 장점을 강조하기 위한 실험을 추가해주시고 본문 및 supplement에 넣을 실험 추려주세요."

## 1. 무엇을 보강하려는가

논문의 기여는 세 가지다: (1) PPG 주입 합성 영상과 그것을 쓰는 학습 풀, (2) 스펙트럼 유도 학습(스펙트럼 손실·배가 벌점·잡음 참조 배제), (3) 두 슬롯 + 잡음 부분공간 투영 구조. 지금까지 유의한 근거는 (2)·(3) 과 기존 방법 대비 비교에 몰려 있고, (1) 은 실제 평균 정확도에서 약하다(64·67 문서: MMPD 비용, VIPL-HR 이득은 깨끗한 클립에서만 유의). 68 문서는 합성 클립의 역할이 약한 맥파에서 심박 범위 전체의 주파수 읽기를 넓히는 것임을 보였다. 이번 실험은 이 역할과 최종 모델의 장점을 기존 방법과 같은 자리에서 재고, 실제 학습 영상이 적을 때 합성 클립이 얼마나 대신하는지 잰다.

네 실험 모두 결과를 보기 전에 아래 규칙을 고정한다. 판정은 Holm 조정 p < .05 이고 예측한 방향일 때만 "지지"다.

- **D3 (합성만으로 미세조정 vs 시작점, Holm 5): VIPL-HR 에서 유의하게 나빠짐**(6.88 → 7.85, Holm p < .0001). 나머지 넷은 n.s.(MMPD +0.90, 풀 저심박 −1.54, 풀 고심박 −2.52, MR-NIRP 소동작 −7.26).
- 기전(서술): 어려운 통제 시험 오차는 합성 클립이 있을 때마다 크게 낮다 — 실제 1/4 에서 14.50 → 1.37(클립 순열 p = .003), 합성만 vs 시작점 11.10 → 1.28(p = .002). 약한 맥파의 생성 얼굴에서 넓은 심박 범위를 읽는 능력은 합성 클립만으로 생기지만, 실제 영상의 평균 오차로는 옮겨지지 않았다.
- 결론(사전 등록 규칙): D 는 본문에 한 문장, 보충 자료에 표로 적는다. "실제 학습 영상이 적을수록 합성 클립이 더 중요하다"는 주장은 이 자료로 할 수 없다.
