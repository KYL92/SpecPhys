# 47. 새 백본 설계 — 잡음 인수분해 PhysNet(NF-Phys): VIPL 고심박(운동 후) 실패를 구조적으로 푸는 모델 (2026-10-27, 사용자 지시 "백본 변경", 사전 등록 초안)

## 1. 풀어야 할 문제 (진단 요약, 42·43·45·46 문서)
| 관찰 | 근거 |
|---|---|
| 우리 PhysFormer 계열은 90 bpm 이상·운동 후(VIPL v7)에서만 FactorizePhys 공개 가중치에 진다 (90–120: 11.8 vs 7.2, v7: 14.8 vs 8.9); 60–90 bpm 은 우리가 우세(4.4 vs 6.3) | 42 §1 구간 표 |
| 라벨 분포 탓이 아니다: 코퍼스의 43% 가 90–120 bpm, in-domain VIPL 학습·시간 배속 증강·MCD 가중·고심박 가중 전부 그 구간을 10~13 에 남김(고심박 가중은 −2.2 개선하나 저심박 비용·시드 비강건) | 42 §1, 43 §6, 44 §6 |
| 입력 표현이 원인의 약 1/3: 프레임 차분(DiffNormalized) → 원시 표준화 입력으로 바꾸면 90–120 −3.5(3시드)이나 FactorizePhys 와 2.85 격차 잔존 | 42 §6 |
| 읽기 편향: 적분(cumsum) 읽기는 저주파로 기울어 고심박에 불리(문헌형 읽기는 in-domain 셀만 0.5 개선) | 30 §7.2, 40 §6 |
| FactorizePhys 의 강점은 원시 입력 + 비음수 행렬 인수분해(FSAM, rank 1)로 "지배 주기 성분" 을 샘플마다 뽑는 구조; 약점은 지배 성분이 교란일 때(플리커 30 lock-in, 근적외선 주행 13.7/14.0) | T18, 45 §1 |
| FactorizePhys 에 우리 코퍼스/분해 손실을 그대로 얹으면 악화(VIPL 6.88→9.43, MMPD +0.81) — **정정(10-27)**: 원인은 교란 사본이 아니라 **가상(합성) 클립**: 공정 출발점 UBFC-34 7.72 → +가상 42 **9.72** → +잡음 클립 48+분해 10.09 → +실 손상 사본 44 **9.12(회복)**; PhysFormer 에서는 가상 42 가 VIPL 중립(체인 64)이므로 FactorizePhys 고유 → rank-1 NMF 가 합성 클립에서 <1% 맥파 대신 지배 교란을 지배 성분으로 학습한다는 가설(미측정, Phase 0 (d)) | 39 §6·§7, 36 §9, §8 |
| 분해 목적함수에는 이중 렌더 정확 라벨이 불필요 — 교란 지배 관측 trace 로 충분(상관 .998) → 실 영상에도 같은 종류의 라벨(프레임 평균 조명·움직임 trace)을 만들 수 있다 | 45 §2-결과 H-N2 |

**설계 원칙**: (P1) 입력은 원시 표준화 프레임(고심박 맥파 보존) (P2) 맥파는 "지배 주기 성분" 이 아니라 **"교란 성분을 명시적으로 뺀 뒤의 주기 성분"** 으로 뽑는다 — rank-1 인수분해를 **rank-2(맥파 + 교란)** 로 확장하고 교란 성분을 우리 데이터의 교란 trace 로 감독 (P3) 심박 판독은 적분 없이 파형·스펙트럼 헤드에서 직접, 반감(halving) 억제 항 포함 (P4) 학습 레시피는 "코퍼스 사전학습 → 대상 적응" 2단계(45 §3-결과 ①: MMPD −1.00).

## 2. 모델 구성 (NF-Phys = FactorizePhys 트렁크 + 잡음 인수분해 FSAM + 스펙트럼 헤드)
```
입력 x: [B, 3, T=160, 72, 72]  원시 프레임, 영상 단위 표준화 (u8 캐시 Standardized 경로 / fp_* float 캐시)
① 트렁크: FactorizePhys rPPG_FeatureExtractor (3D ConvBlock ×, 공개 가중치 재사용 가능)  → voxel 임베딩 E [B, C, T', H', W']
② NF-FSAM (rank-2 비음수 인수분해):  E ≈ W·[s_p ; s_n]  — 시간 기저 2개: s_p(맥파 후보), s_n(교란 후보), 공간·채널 가중 W 2열
   · 기존 FSAM 의 NMF 반복(MD_STEPS)을 rank 2 로 두고, 두 기저의 역할을 손실로 고정:
     - s_n 감독: 합성 클립 = 관측 교란 trace(45 §2 의 total_dn, 표준화) / 실 클립 = 프레임 평균 조명 trace + 얼굴 상자 이동 trace 의 표준화 합성(약지도, 라벨 없는 영상에서 계산 가능)
     - s_p 감독: 파형 라벨(Standardized PPG) 과의 Neg-Pearson
     - 탈상관: corr(s_p, s_n)² 벌점 (patch 22 HYB_W_DECOR 재사용)
   · 어텐션 마스크 = 맥파 기저 W_p 만으로 구성(교란 기저는 마스크에서 제외) → 트렁크 특징을 "맥파 성분이 있는 voxel" 로 재가중
③ 맥파 헤드: BVP_Head(기존) → 파형 y [B, T]  (라벨 Standardized, cumsum 읽기 없음)
④ 스펙트럼 헤드: y 의 DFT 파워(30–200 bpm, Hann) 에 선형층 → 심박 분포 로짓 p(f); 손실 = CE(라벨 분포, σ=1 bpm Gaussian) + KL  (PhysFormer TorchLossComputer 재사용, 구간을 40–180 → 30–200 으로 확장)
   · 반감 억제: 라벨 f 에 대해 P(f/2)/P(f) 비율 벌점(PF_HARM_* 패치의 역방향 — 기존 패치는 2f 배가 억제, 여기에 f/2 항 추가)
⑤ 판독(평가): 파형 y 에 0.6–3.3 Hz 대역통과 → periodogram 피크(정본과 같은 periodogram, 단 적분 없음 = Standardized 라벨 모델의 정본 읽기 `toolbox_hr_nodiff`) — 공개 FactorizePhys 와 동일 읽기라 직접 비교 가능
손실 = a·NegPearson(y, ppg) + b·(CE+KL)(p(f), HR) + w_n·NegPearson(s_n, nuisance_trace) + w_d·corr²(s_p, s_n) + w_h·halving
```
학습 데이터·레시피: 공식 코퍼스 203(+ 실 클립 교란 trace 사이드카 신규 생성) 으로 FactorizePhys 공개 가중치에서 미세조정(lr 1e-4, 10 ep, 3시드) = zero-shot 모델; VIPL in-domain 은 그 체크포인트에서 VIPL 단독 증강+검증 레시피로 2단계 적응(5-fold).
왜 이것이 고심박을 고치는가: (i) 원시 입력으로 2–3 Hz 맥파 진폭이 차분 잡음에 묻히지 않음(42 §6 로 1/3 확인) (ii) 운동 후 영상의 거친 호흡·상체 흔들림은 s_n 으로 흡수되어 s_p 의 피크가 호흡·움직임 저주파로 끌리지 않음(FactorizePhys 가 운동 후 8.9 를 내는 메커니즘 = 지배 성분 추출을 유지하면서, 교란이 지배할 때의 lock-in 을 rank-2 로 방지) (iii) 적분 없는 판독으로 저주파 편향 제거 (iv) f/2 억제로 고심박 반감 방지.

|---|---|---|

## 5. 리스크·대안
- rank-2 NMF 가 두 기저의 역할을 바꿔 잡을 위험(label switching) → 교란 감독 항의 가중을 초기 epoch 에 크게 두고 탈상관 항으로 고정; 실패 시 교란 기저를 고정 trace(학습 안 함)로 두는 변형.
- 실 클립 교란 trace(약지도)가 맥파를 포함할 수 있음 → 합성 클립 결과(45 §2-결과)처럼 맥박 혼입은 7% 수준이면 무해하나, 정지 실 영상은 교란 진폭이 작아 trace 가 맥파 지배일 수 있음 → 교란 진폭 하한 이하 클립은 감독 제외.
- 공개 FactorizePhys 체크포인트 재사용 시 rank-2 로 바뀐 FSAM 과의 불일치 → 트렁크만 적재(strict=False), FSAM 은 파라미터 없음(NMF 반복)이라 적재 무관.
- 이것이 실패해도 얻는 것: "고심박 격차는 입력 표현(1/3) + 교란 인수분해(?) + 잔여" 로 귀속되는 정량 분해.

## 8. 잡음 코퍼스와의 연계 평가 (2026-10-27, 사용자 질문 "rank-2 교란 인수분해가 내 잡음 코퍼스와 연계돼 좋은 영향이 생길까", 실행 없음)

**결론**: 구조화된 교란 축(플리커·압축·근적외선 주행·휴대폰 움직임)에서는 시너지의 측정 근거가 있고, VIPL 에서는 근거가 없다(가설 단계). 지금까지 FactorizePhys 에 우리 코퍼스를 결합한 모든 셀이 VIPL 을 악화시켰으며, rank-2 는 그 악화를 없애기 위한 가설이지 증거가 아니다.

근거 표 — FactorizePhys 계열(VIPL 은 문헌 GT·u8 경로 공통이라 경로 내 비교만 유효, 36 §9; 나머지 축은 float 정본):

| 셀 | VIPL | 플리커 RTNI / RTNC | MR-NIRP 소동작 | MCD_A | PURE | 출처 |
|---|---|---|---|---|---|---|
| 공개 가중치(UBFC 42) | 6.88 | 30.3 / 30.3 | 14.0 | 4.35 | 0.74 | T18, 46z4b |
| 공정 출발 UBFC-34 (U0, 3시드) | 7.72 | 29.3 / 29.3 | 14.3 | 5.68 | 3.79 | 36 §9 |
| + 가상얼굴 42 (U1) | 9.72 | 23.2 / 20.3 | 15.1 | 5.29 | 6.50 | 36 §9 |
| + 잡음 클립 48 + 분해 손실 (U2) | 10.09 | 30.3 / 30.3 | 17.2 | 6.20 | 5.79 | 36 §9 |
| + 실 손상 사본 44 (U3) | 9.12 | 1.7 / 3.3 | 13.7 | 7.56 | 4.82 | 36 §9 |
| 공개 가중치 + 공식 코퍼스 203 (FP_OFF_TW, 3시드) | 9.43 | 2.6 / 2.7 | 6.7 | 0.40 | 0.51 | 39 §6·§7 |

① **시너지가 기대되는 축(측정됨)**: 코퍼스는 rank-1 인수분해 그대로도 FactorizePhys 의 교란 실패를 고친다(플리커 30→2.6, 근적외선 소동작 14.0→6.7, MCD 4.35→0.40, PURE 0.74→0.51). 교란 trace 라벨은 정보를 담고 있다(체인 61: 정확 라벨 ≈ 관측 trace, 상관 .998·Δ≈0; 섞은 라벨은 VIPL +0.59 p<.0001·MMPD +0.29 악화). 분해 손실의 휴대폰 움직임 이득은 백본·학습 방식에 걸쳐 재현된다(체인 52 Phase 3 움직임 −0.85 Holm .027, 체인 55 DG 3종 모두 MMPD 움직임 개선). 즉 교란 슬롯이 배울 신호와, 그 신호가 효과를 내는 축이 모두 확인되어 있다.

② **시너지가 없는 축: VIPL(역방향)**. 공정 출발점 분해(36 §9): 공개 6.88 → UBFC-34 출발 7.72(+0.84, 피험자 8명 감소·레시피), **+가상 클립 42 → 9.72(+2.0)**, +잡음 클립·분해 → 10.09(+0.37), **+실 손상 사본 → 9.12(−0.97 회복)**. 따라서 §1 에 적었던 "교란 사본이 rank-1 지배 성분을 오염" 가설은 기각이고, VIPL 을 깎는 것은 가상(합성) 클립이다. PhysFormer 에서는 가상 42 가 VIPL 중립(체인 64 교체 코퍼스 동등)이므로 FactorizePhys 고유 현상이다. 남는 기계적 가설: rank-1 NMF 가 합성 클립에서 <1% 주입 맥파 대신 지배 교란(또는 피부 전면 균일 주입 패턴)을 지배 성분으로 배우고, 그 습관이 휴대폰 영상(VIPL)에서 교란 lock-in 으로 나타난다. rank-2 는 정확히 이 가설에 대한 해법이지만, 지배 성분이 실제로 무엇인지 측정한 적이 없다 → Phase 0 (d).

③ **위험(측정된 비용)**: (i) 교란 감독의 근적외선 비용 — 분해 손실을 켜면 FactorizePhys 근적외선 소동작 6.7→10.4, PhysFormer 도 분해 없음이 −3.68(p=.0005) 우세(45 §2-결과). RGB 조명·움직임 trace 로 배운 교란 슬롯이 근적외선에서 맥파를 흡수할 수 있다 → 강제 배정 없이 탈상관만, 교란 감독 가중 작게, H-B3 의 MR-NIRP 게이트 유지. (ii) 운동 후(v7)·주기적 움직임에서는 교란 trace 가 맥파와 상관 → 탈상관 항이 맥파를 깎는 기저 전환(label switching) → 운동 시나리오 별도 감시. (iii) 고심박 실패는 코퍼스 탓이 아니다(코퍼스 90–120 bpm 43%, 46 문서) → VIPL 에서 6.88 을 넘는 몫은 원시 입력·스펙트럼 헤드가 맡고, 코퍼스 연계의 VIPL 쪽 과제는 "+1.5~2.5 의 비용을 0 으로" 이지 이득이 아니다.

④ **정직한 기대값**: rank-2 + 코퍼스가 공개 FactorizePhys 를 zero-shot 교란 축에서 이기는 것은 rank-1 결과로 이미 거의 확보(단 근적외선은 분해 가중 조정 필요); VIPL 6.88 이하는 성공 확률 50% 미만의 가설. H-B4 절제(rank-1 vs rank-2 vs 교란 감독 없음)가 "코퍼스 × 인수분해 시너지" 주장의 유일한 검증이며, Phase 0 (a)·(d) 가 그 전제를 6 h 안에 확인한다. 기동은 사용자 결정 대기.
