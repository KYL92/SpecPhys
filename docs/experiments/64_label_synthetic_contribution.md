# 64. 스펙트럼 라벨과 합성 클립의 기여: 최종 모델에서 직접 재기 (사전 등록)

사용자 지시(2026-11-07): "두 개 다 해주세요. 1. 잡음 라벨만 뺀 최종 모델 2. 학습 풀에서 합성 클립을 뺀 최종 모델." 이 문서의 §1~§4 는 결과를 보기 전에 썼다.

## 1. 왜 재는가
슬라이드 5(63 §3)는 합성 데이터의 심박·잡음 스펙트럼 라벨로 학습한다는 점을 강조한다. 지금까지의 근거는 간접적이다.
- 잡음 슬롯 감독 제거는 기준 레시피에서 차이가 없었다(표 4, 1시드, VIPL 5.82 → 5.86). 최종 모델에서는 재지 않았다.
- 합성 클립의 기여는 다른 모델의 이전 대조에서만 쟀다(보충 S1-T15). SpecPhys 풀 안에서는 미측정이다(원고 4.4).

## 3. 판정 규칙
가족마다(잡음 라벨, 합성 클립) 1차 5개, Holm 5, 영상 단위 부호 뒤집기 순열 검정(MAE 차이, 양측, 시드 평균), Wilcoxon 함께 보고. Δ = 최종 모델 − 뺀 셀.
1차: VIPL-HR 전체, MMPD 7~33 전체, 풀 저심박, 풀 고심박, MR-NIRP 소동작.
- 기여 확인: Δ<0 이 Holm p<.05 로 하나 이상, Δ>0 유의 없음.
- 역효과: Δ>0 이 Holm p<.05 로 하나 이상, Δ<0 유의 없음.
- 혼재: 둘 다 있음.
- 측정되지 않음: 유의한 항목 없음. "기여 없음" 의 증명은 아니다.

서술(보정 없음): VIPL <60, ≥120, v2, v7, v9, MMPD <110, ≥110, 보행, 회전, MR-NIRP 정지·대동작, DLCN, PURE, RTNI, RTNC, MCD-A·B, UBFC. 풀 밖 합성 20클립의 틈별 심박 판독 비율과 기저 정점(63 §2 와 같은 진단, 같은 5시드).

## 8. 잡음 라벨이 효과가 없던 이유 진단 (11-07, 사용자 질문, 학습 없음; `scripts/noise_label_redundancy.py`, `results/noise_label_redundancy.{txt,json}`)
**이중 렌더란(코드 확인, `build_synth_dataset.py`).** 합성 클립을 만들 때 프레임마다 두 갈래를 함께 계산한다. 저장하는 갈래는 피부 화소 맥파 주입 → 움직임(아핀) → 조명 이득 → 센서 잡음 순서다. 저장하지 않는 갈래는 주입 진폭 0 이고 같은 아핀 행렬, 같은 조명 이득, 같은 센서 잡음 난수를 쓴다. 두 갈래의 차이는 맥파뿐이다. 저장하지 않는 갈래에서 고정 피부 영역의 초록 채널 평균을 프레임마다 구해 차분 정규화한 1차원 trace 가 정답 n(t) 다. 프레임당 숫자 하나이며 공간 정보는 없다. 학습 풀에서는 48클립(TRAIN24DN·TRAIN24DN2, 피험자 261~308)에만 있다. 이 48클립의 잡음은 조명 드리프트, 플리커, 무작위 이동, 회전, 센서 잡음이다. 절반은 MCD 실제 얼굴 궤적, 절반은 주기 움직임을 쓴다. 반쪽 그림자, 국소 플리커, 반사 패치처럼 공간적으로 고르지 않은 잡음(52 문서 B3 옵션)은 쓰지 않았다.

**최종 모델에서 라벨이 들어가는 곳(코드 확인, `FactorizePhysTrainer.py`).** 교란 슬롯 보조 손실 L_nuis 의 표적, 그리고 그 청크의 L_decor 적용 여부뿐이다(288/3,665 청크, 7.9 %). 라벨을 끄면 그 청크 가운데 g_std > 1 회색 단계인 120개는 크롭 전체 밝기 차분 g_diff 가 L_nuis 표적이 된다. 288개 모두 사이드카 없는 청크용 L_nu2(배경 밝기 trace, 심박 대역 제거, g_std 소프트 가중)를 받는다. 출력 배제 L_excl 의 마스크(배경 R·G·B, 얼굴 내 비피부, LK 이동)와 투영 층의 참조(측면 띠 R·G·B, 전역 R·G·B, LK 이동)는 원래부터 라벨을 쓰지 않는다. 학습 로그(시드 2100, 마지막 에폭): 최종 gate=805/3665 ngt_hit=288, 라벨 끈 셀 gate=643/3665 ngt_hit=0.

**정답과 클립 자신의 참조 비교.** 288 청크를 학습과 같은 로더(u8 캐시, 피부 가중 0.2, 배속 증강 없음)와 같은 NFLoss 함수로 계산했다. 대조는 다른 클립의 참조와 짝지은 값(셔플 20회)이다.
| 지표 | 실제 평균 (중앙값) | 셔플 대조 평균 |
|---|---|---|
| L_nuis 표적: 정답 vs 크롭 밝기 스펙트럼 코사인 | 0.920 (0.990) | 0.279 |
| 심박 대역을 지운 표적: 정답 vs 배경 참조 코사인 | 0.859 (0.972) | 0.279 |
| 정답 잡음 전력 중 참조 마스크 ≥0.5 구간의 몫 | 0.567 (0.607) | 0.139 |
| 정답의 최대 잡음 정점(±3 bpm)이 마스크 ≥0.5 에 드는 비율 | 0.951 | 0.238 |

**해석.**
1. 이 합성 잡음은 화면 전체에 걸린 조명 변화와 머리 이동이라 클립 자신의 밝기·배경·움직임 trace 에 그대로 보인다. 정답의 잡음 스펙트럼은 클립 자신의 밝기 스펙트럼과 거의 같고, 가장 큰 잡음 정점은 95 % 청크에서 참조 마스크가 이미 잡는다. 정답이 새로 주는 정보가 적다.
2. 라벨이 들어가는 교란 슬롯 손실 묶음 자체가 출력에 측정 가능한 영향을 주지 않았다(58 본문 표 4: 교란 슬롯 감독과 탈상관 제거 VIPL-HR 5.86 vs 5.82, p ≥ .43, 1시드). 어텐션은 맥파 슬롯에서만 만들어 주 경로에 잔차로 더하고, NMF 기저에는 기울기가 없다(62 문서).
3. 시험 때는 정답이 없다. 참조는 학습과 시험 모두에서 쓸 수 있다.
4. 이 라벨을 처음 도입한 PhysFormer 실험(24 문서 V2)에서도 잡음 헤드와 탈상관만으로는 움직임 이득이 없었다.

**정답 라벨이 이득을 낼 수 있는 조건(제안, 시험하지 않음).** 참조에 보이지 않는 잡음, 즉 피부에만 생기는 그림자, 국소 플리커, 반사 패치다. 생성기에 옵션은 있지만 이중 렌더 학습 클립에는 쓰지 않았다.
