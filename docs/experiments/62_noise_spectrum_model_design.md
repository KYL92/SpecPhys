# 62. 모델 구조의 이점: 잡음 스펙트럼으로 안내하는 구조 실험 (체인 116~, 사전 등록, 2026-11-05)

사용자 지시(/goal, 11-05): "프레임워크 뿐만 아니라 모델에 대한 장점도 있으면 좋겠습니다. 노이즈 스펙트럼을 가이드할 수 있는 방법 찾아서 모델 구조도 실험해주세요."

## 1. 왜 지금 구조는 기여가 없는가 (코드 근거)
- **시간 수용 영역이 25프레임(0.83 s)이다.** 트렁크 6층 + `conv_block` 3층 + `final_layer` 3층이 모두 시간 커널 3, stride 1 → RF = 1 + 12×2 = 25. 72 bpm 이하에서는 한 주기보다 짧다. 모델은 국소 필터이므로 주기 잡음과 맥박을 주기성으로 가를 수 없다.
- **전역 경로는 FSAM 하나인데 잔차 곁가지다.** `fe = v + InstanceNorm(att·v)` 라서 주 경로 `v` 의 잡음은 그대로 `final_layer` 로 간다. NMF 기저는 no-grad 곱셈 갱신이라 학습 신호도 닿지 않는다(53 문서, 58 표 4 아블레이션과 일치).
- **입력 쪽 보정은 해롭고(61 §7), 손실 쪽 배제는 작게 돕는다(61 §8).** 입력 나눗셈은 맥박까지 왜곡한다. 손실은 학습 시에만 작동하므로 추론 시 그 클립의 실제 잡음을 볼 수 없다.
→ 아직 시험하지 않은 자리: **추론 때도 그 클립의 잡음 스펙트럼을 보고, 주 경로의 특징을 주파수 영역에서 전역으로 조절하는 층.**

## 2. 문헌에서 가져온 방법
- 음성 향상의 지도 NMF: 잡음 사전을 고정하고 신호 기저만 추정한 뒤 Wiener 마스크를 쓴다 (Mohammadiha, Smaragdis, Leijon, IEEE TASLP 2013; arXiv:1709.05362).
- rPPG 의 주파수 영역 층: RhythmMamba 의 frequency-domain linear layer(arXiv:2404.06483), FreqPhys 의 스펙트럼 변조(본문 [35]). 둘 다 그 클립의 잡음 참조를 입력으로 쓰지는 않는다.
- 맥파·잡음 동시 모델링: Dual-GAN (Lu et al., CVPR 2021). 잡음을 생성 모델로 다루며, 스펙트럼 게이트는 아니다.
- 우리 데이터의 사전 근거: POS 에서 잡음 참조 최소제곱 제거가 보행을 19.71 → 17.20 으로 낮춤(p=.019, 61 §8 학습 없는 점검). 추론 시 수작업 노치는 정지 영상에서 참 맥박이 LK 이동과 결맞아(0.6~0.7) 기각(61 §8.4) → 진폭 게이트 또는 학습된 게이트가 필요하다.

## 3. 잡음 참조 (파서 없이 프레임에서 계산, 추론 때도 가용)
- 측면 띠 R·G·B 차분 정규화 trace: 크롭 좌우 바깥 1/9. 부위 분할 사이드카 집계로 확인한 측면 띠의 피부 확률은 0.4~2.3 %, 배경 72~87 %(VIPL·MMPD·풀 각 300 청크, 11-05).
- 전역 R·G·B 차분 정규화 trace(맥박 포함; 측면과의 차이가 맥박/조명을 가르는 단서).
- Lucas–Kanade 전역 평행이동 속도 vx, vy (`NFLoss.motion_traces`).

### 4.1 학습 전 점검(판정 아님, 11-05 00:3x)
기존 가중치에 파라미터 없는 층을 추론 때만 끼운 점검이다. 공개 체크포인트와 SpecPhys-L 시드 600, 근사 readout, 소규모 축만 썼다. 첫 구현은 NMF 사전이 넓어 게이트 평균 0.02(신호까지 소거)였고 투영은 축 배치 오류로 효과가 없었다. 수정 뒤 투영은 플리커 대역 에너지 몫을 0.78 → 0.02(λ=0.01) 로 줄였지만, 공개 가중치의 RTNI 는 λ=0.1 에서 29.6 → 26.4, λ=0.01 에서 65.0 으로 나빠졌다(플리커를 지워도 그 가중치의 특징에는 맥박이 거의 남아 있지 않다). SpecPhys-L 에서는 λ=0.1 에서 MR-NIRP 대동작 13.0 → 11.4, 소동작 5.3 → 7.1 로 축마다 방향이 달랐다. 추론만으로는 판단할 수 없어 함께 학습해 시험한다. 이 점검 뒤 λ 는 0.1 로 고정한다.

**두 슬롯 구조와 투영의 몫(체인 122, 2×2, 시드 2100~2500).** 지금까지 "원본 어텐션 대비" 는 두 슬롯과 투영이 함께 바뀐 비교다. `NF_NSP2O_L`(원본 어텐션 + 투영, 패치 55c)을 더해 나눈다. 1차(Holm 2, 순열 검정): 원본 어텐션에서 투영의 효과 C1 풀 고심박, C2 풀 저심박 Δ<0. 서술: 두 슬롯의 효과(투영 있을 때·없을 때). 최종 설정은 이 결과와 무관하게 사용자 결정대로 두되, 원본 어텐션 + 투영이 같거나 낫다면 "두 슬롯은 필요 없다" 로 보고한다.
**MMPD in-domain 축(체인 122, 시드 600~800).** 체인 115 와 같은 방법(피험자 배타 5-fold 2단계, lr 5e-5, 10 에폭, `NF_HR_TB=1`). 1차(Holm 2, 체인 115 와 같게 Wilcoxon): zero-shot 같은 시드 대비 I1 MMPD ≥110, I2 MMPD 전체 Δ<0. 판정은 피험자 7~33 만. zero-shot 과 같은 열에 두지 않는다. 판정 `scripts/nsp_abl_judge.py`.
