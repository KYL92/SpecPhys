## 1. 개입: 시간 배속 증강(패치 30 + **패치 44**)으로 학습 심박 분포를 양쪽으로 넓힌다
새 데이터 없이, 학습 로더가 표본마다 확률 0.5 로 청크를 2배속(심박 ×2, 다음 청크와 이어 붙임)·1/2배속(심박 ÷2, 프레임 보간)으로 재표본한다(기준 88 bpm: 그 위면 ÷2, 아래면 ×2) → 학습 심박 범위가 대략 18~400 bpm 으로 펼쳐지고 저·고심박 표본 비중이 크게 는다. 스펙트럼 항의 심박 라벨은 재표본된 파형에서 다시 계산되므로 정합. **패치 44**: 증강이 차분 정규화 입력(PhysMamba)에만 있던 것을 Standardized(RhythmFormer)·Raw(FactorizePhys) 입력으로 확장(프레임 재표본 → 입력 변환), 증강 라벨에도 표준화 복원(패치 40a) 적용, 세 트레이너가 `TAUG stats epoch k: {x2, x0.5, skip, none}` 출력(체인 실패 조건: x2 없음). CPU 스모크(풀 캐시 실제 청크): 세 입력 타입 모두 라벨 심박이 정확히 ÷2(95.6→43.6, 104.1→49.2), 표준화 라벨 std 1.0.

### 5.2 해석(정직 보고)
- **고심박**: 세 갈래 모두 ≥120 에서 −3.1~−3.7, 운동 후 −0.5~−0.7 로 방향 일치 — 학습 심박 분포를 위로 넓히면 고심박이 개선된다는 것은 재현되나, n=37/302 과 시드 분산 탓에 어느 갈래도 Holm 유의에 못 미침.
- **저심박**: 어느 갈래도 VIPL <60·MR-NIRP <65 를 개선하지 못함(HRX 는 오히려 악화 방향). 저심박 합성 클립(40~59 bpm)을 10% 추가해도 효과가 없고, **배가 건수가 6 → 10~13 으로 증가** — 저심박 실패의 기제는 '커버리지 부족' 이 아니라 **2배 오판(저심박 영상을 2×HR 로 읽음)** 쪽.
- **비용**: 배속 증강은 강도(0.5→0.25)와 무관하게 MMPD +0.85~0.96 으로 가드를 위반하고 중간 대역(60~90)을 0.4 나쁘게 함 → 인공물 비용이 본질적. HRX 는 가드를 모두 지키고 MMPD 가 공개 FP 대비 −0.81(p=.019) 로 '대부분 데이터셋' 요건에 가장 가까움(RTNI 2.09·MR-NIRP 대동작 +1.1 은 비용).
- 결론: "고심박 보장 + 대부분 데이터셋" 은 HRX 풀이 가장 근접하고, 남은 구멍은 저심박의 배가 오판 → §7 의 배가 억제 항으로 공략.

### 11.3 해석(정직 보고) — 증강과 배가 항은 RhythmFormer 에서 **가산적이지 않고 간섭한다**
1. 배속 증강(×2 재생)은 학습 라벨의 절반을 2배 심박으로 만들어 모델이 2배 주파수를 정답으로 보는 빈도를 늘린다(VIPL 배가 건수 2.3 → 11.0). 배가 항은 바로 그 2배 질량을 벌하는 항이므로 두 신호가 같은 스펙트럼 위치에서 반대 방향으로 작용한다: 결합 셀의 배가 건수(8.0)는 둘 사이에 멈추고, 저심박 이득은 사라지며(8.04 → 9.45), MMPD 에서는 둘 중 어느 단독 셀에도 없던 비용(+0.5~0.6)이 나타난다.
2. 따라서 RhythmFormer 에서 "저·고심박 동시 보장 + 가드 유지" 단일 셀은 **얻지 못했다**. 얻은 것은 서로 배타적인 두 레시피다: **저심박·전체·MMPD 최저 = 스펙트럼 + 배가 항**(VIPL 5.78·<60 8.04·MMPD 7.70, 비용 없음), **고심박 = 스펙트럼 + 배속 증강**(≥120 25.99, VIPL·MMPD 비열등). 배포 목적에 따라 하나를 고르는 구조이며, 이는 사용자 전제("둘 다 챙길 수는 없다")와 일치한다.
3. SpecFP(FactorizePhys)에서도 같은 결론(§10): 배가 항이 저심박을 닫고, 고심박은 어떤 개입으로도 가드 안에서 유의하게 닫히지 않았다.

## 31. 질문 점검(2026-11-03 19시, 학습 없음): '모델 파라미터나 고주파 레이어를 늘리면 고심박이 풀리는가'
1) **2~3 Hz 는 모델에게 고주파가 아니다**: 입력 30 fps → 표현 가능 주파수 15 Hz 까지, 120 bpm = 2 Hz. 움직임이 적은 운동 직후 웹캠 영상(MCD_A)에서 0.05 M 파라미터 채택 셀은 127.4 → 127.4, 115.1 → 115.1 bpm 으로 정확히 읽는다.
