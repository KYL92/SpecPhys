## 1. Phase 0 — 실패 분류 진단 (학습 없음, Alpha, `scripts/selfsup_phase0_diag.py`)

"분리 문제" 재정의가 데이터에 맞는지 먼저 측정한다. 표적 영상(VIPL v7 + ≥90 bpm 전체, MMPD held-out 회전·대화·보행·운동 후, MR-NIRP 대동작)마다 클립 자신의 **교란 프록시** 스펙트럼 피크를 구한다:
- 전역 밝기 trace g(t): 얼굴 crop 의 공간 평균 밝기(VIPL 은 u8 캐시 청크에서 복원, MMPD 는 원본 .mat + 첫 프레임 Haar 박스, MR-NIRP 는 vid.avi).
- 전역 이동 속도 vx, vy(t): Lucas–Kanade 1차 전역 평행이동 해(**부호 있음**). 프레임 차분 절대 평균은 정류 신호라 주기 움직임을 2배 주파수에 놓으므로 쓰지 않는다(합성 끄덕임 1.6 Hz 검증: 부호 추정 96 bpm, 정류 192 bpm).
- 스펙트럼: 1 s 이동평균 제거 → 해닝 → 8× 영패딩 FFT, 0.5–3.5 Hz; 피크 = 최대의 30% 이상 국소 극대(4 bpm 병합).

모델별 예측 HR 분류(영상 × 시드): `ok`(|오차| ≤ 5) / `half_double`(≈ GT/2, 2·GT) / **`lockin`**(예측이 교란 피크 ±3 bpm, 그 피크는 GT 와 >5 bpm) / `prior`(예측 55–95 bpm 이고 GT ≥ 100, 교란 피크 무관 — 코퍼스 전형 대역으로의 끌림) / `other`. 부가: `nuis@HR` = 교란 지배 피크가 GT ±5 bpm 인 영상 비율(스펙트럼으로는 분리 불가한 구간).

사전 해석 규칙(10-31 원안): 표적 구간 실패 중 lock-in 비율 ≥ 30% → 분리 재정의 지지; 15% 미만이고 prior 우세 → 기대 효과 제한. **11-01 수정(학습 전)**: 원안 기준은 우연 수준을 고려하지 않아 무의미함이 드러났다(교란 프록시 피크 창이 대역의 31–43% 를 덮고, 예측을 다른 영상 것으로 바꿔도 '실패 중 lock-in' 이 44–85% 나온다). 따라서 기준을 **실패 조건부 셔플 대조 대비 초과분**으로 바꾼다: 초과 ≥ +5 pt 이고 z ≥ 2 → 그 구간의 분리 재정의 지지; 아니면 미지지. nuis@HR 이 높은 구간은 어떤 스펙트럼 분리 신호로도 닫히지 않음을 명시한다(단 교란이 약한 클립에서는 전역 trace 가 곧 맥파라 nuis@HR 이 '프록시 = 맥파' 를 뜻할 수 있음). 결과는 §5.0.

## 2. 학습 신호 (툴박스 패치 38; `RPPG_NF=1` 위에 추가, 손실만 바뀌고 추론은 불변)

두 신호 모두 **라벨 심박은 "맥파가 있을 수 있는 대역을 마스크에서 보호" 하는 데만** 쓰고, 교란 쪽 정보는 전부 클립 자신에서 얻는다(교란 정답 불필요).

공통: 교란 마스크 M(f) = max{ P̂(g′), P̂(vx), P̂(vy) } × (1 − 심박 대역), 30–200 bpm 1 bpm 격자, 샘플별 최대 1. g′ = 전역 밝기 차분 trace(모델 내부 `g_diff`), vx·vy = `NFLoss.motion_traces`(Lucas–Kanade), 심박 대역 = 라벨 HR 의 기본·반·배 주파수 ±5 bpm(`NF_SS_WIDTH`).

**A. 전역 trace 자기 감독 `NF_SS_TRACE=1`**
1. 출력 스펙트럼 배제 L_excl = Σ_f P̂_out(f)·M(f) (`NF_SS_W_EXCL` 1.0) — 출력 파형이 클립 자신의 교란 주파수에 전력을 두지 못하게. 기존 스펙트럼 NLL(심박 대역 질량)과 달리 교란 피크를 직접 겨냥한다.
2. 교란 슬롯 스펙트럼 표적 L_nuis2 = 1 − cos(P̂(s_n), P̂(g′)·(1 − 심박 대역)) (`NF_SS_W_NUIS` 1.0) — 사이드카 없는(실) 청크에, 소프트 게이트 w = min(1, g_std / `NF_SS_SOFT` 1.0 그레이). 기존 하드 게이트(g_std > 1.0, 1,114/3,665)는 그대로 두고 그 아래 청크에도 약하게 적용. 시간 영역 노치는 쓰지 않는다(160 프레임 창에서 최소제곱 노치가 24 bpm 떨어진 교란 전력의 70% 를 함께 제거 — 10-31 확인).

**B. 어텐션 공간 정칙화 `NF_SS_ATT=1`** — NF-FSAM 의 맥파 슬롯 공간 적재 p_att(h,w) = Σ_채널 coef[:, :, 0] (7×7 격자, 합 1; 패치 38 이 `nf_aux["coef"]` 로 노출, 미분 가능), 교란 슬롯 적재 n_att 동일.
1. 피부 사전 L_skin = Σ p_att·(1 − S) (`NF_SS_W_SKIN` 0.5) — S = 시간 평균 프레임의 YCrCb 피부 규칙(Cr 133–173, Cb 77–127) 격자 비율; 피부 비율 < 10% 샘플은 제외.
2. 교란 영역 억제 L_nreg = Σ p_att·r (`NF_SS_W_NREG` 0.5) — r(h,w) = 셀 밝기 차분 trace 의 정규화 전력이 M 위에 놓인 질량(샘플별 최대 1): 교란이 센 셀에서 어텐션을 뺀다.
3. 슬롯 공간 분리 L_dis = cos(p_att, n_att) (`NF_SS_W_DIS` 0.25) — 맥파 슬롯과 교란 슬롯이 같은 자리에 앉지 않게.

가중치는 사전 고정(튜닝 없음; 기존 NF 손실 가중과 같은 규모). 기존 NF 손실(스펙트럼 NLL 1.0·반감 0.5·맥파 슬롯 0.5·사이드카 교란 감독 1.0·탈상관 0.25)은 불변. 트레이너는 `[nf-ss] active …` 와 매 epoch `NF-SS stats epoch k: trace= att= excl= nuis2= soft_gate= skin= nreg= dis= skin_frac= valid=a/n n=` 을 찍는다 — 체인은 이 줄이 없거나 trace 셀에서 `excl=0`, att 셀에서 `valid=0` 이면 실패.

스모크(10-31, Alpha, 7 클립 1 epoch, `results/chain72_smoke_nfss_1031.log`): 두 통계 줄 출력, 손실 유한, `excl=0.312 nuis2=0.464 soft_gate=0.48 skin=0.507 nreg=0.684 dis=0.915 skin_frac=0.49 valid=66/66`, UBFC held-out 1.10 bpm. 초기 슬롯 공간 코사인 0.92 — 두 슬롯이 거의 같은 자리에 앉아 있음(L_dis 의 출발점).

## 4. 가설·판정 (`selfsup_judge.py`; 영상 단위 쌍대 Wilcoxon, 3시드 영상별 평균 풀링)

1차 가족(결합 셀 vs 기준, Holm 3; 지지 = Δ < 0 & Holm p < .05):
- **H-L1** VIPL 운동 후 v7 (n=302)
- **H-L2** MMPD held-out 보행 motion 4 (n=108)
- **H-L3** MR-NIRP 대동작 (n=19)

2차(비보정 병기): VIPL ≥90·≥120·v7&≥90, MMPD 운동 후·움직임 합산, 단일 신호 셀(A, B)의 같은 표적(귀속), 결합 vs 단일(간섭).

가드(비열등: Δ ≤ +0.3 이고 기준 우세 p ≥ .05): VIPL 전체(5.82), MMPD 전체(8.83), PURE·MCD_A·REALTEST, MR-NIRP 소동작(6.12); RTNI 절대값 < 5(플리커 lock-in 재발 없음).

**H-L4 기제**: 표적 영상에서 Phase 0 규칙의 lock-in 분류 비율(같은 피크 캐시 `selfsup_nuis_peaks.json`)이 결합 셀에서 기준보다 감소(영상별 시드 평균 지표의 쌍대 Wilcoxon + 부호 검정). HR 이 좋아져도 lock-in 이 줄지 않으면 "분리 기제" 주장은 하지 않는다(사전/분포 효과로 서술).

판정: 1차 3개 중 ≥ 1 지지 + 가드 통과 → "자기 지도 분리 신호 유효(표적 명시)", 방법 서술에 추가(단일 신호 귀속 병기). 0 지지 → 기각(정직 보고; A/B 단독이 결합보다 나으면 간섭 보고). 가중치·게이트 조정은 사후 탐색으로 별도 표기(사전 등록 외).

MR-NIRP 대동작(+11.8, n=19)은 판단 불가. 보행에서 lock-in 은 움직임 프록시(m 86) 쪽이 전역 밝기(g 58)보다 많다 → 마스크에 이동 속도 trace 를 넣은 설계와 부합.
3. 크기 감각: v7 에서 우연 초과 lock-in 은 실패의 ≈16% ≈ 영상·시드의 ≈9%, 그 실패의 오차가 ≈15 bpm 이면 완전 제거 시 MAE 개선 상한 ≈ 1.3 bpm(공개 FactorizePhys 와의 격차 0.76 보다 큼). **그러나 실패의 대부분(≈84%)은 전역·움직임 프록시의 lock-in 으로 설명되지 않는다**(other 18–37%: 특정 교란 피크 없는 저 SNR, 국소 교란, VIPL 라벨 품질). 따라서 "분리 문제 재정의" 는 **부분 지지**: 자기 지도 분리 신호의 효과는 v7·고심박·보행에 국한되고 크기도 제한적일 것으로 예상한다.
4. prior 붕괴는 드물다(≤ 8%) — 고심박 실패는 "코퍼스 전형 대역으로의 끌림" 이 아니라 특정 주파수(교란 피크 또는 기타)로의 이동이다.
5. nuis@HR: 대화 46%·운동 후 27% 는 교란이 약한 클립(g_std 0.2–0.3, 이동 0.15 px/frame)이라 전역 trace 가 곧 맥파인 경우 — 분리 불가의 증거가 아니라 프록시의 한계. 학습 손실은 라벨 심박 대역을 마스크에서 제외하므로 영향 없음.

**사전 해석(수정 기준 적용)**: 분리 재정의 지지 = VIPL 운동 후·≥120(명확), VIPL ≥90·MMPD 보행(경계); 미지지 = MMPD 회전·운동 후; 판단 불가 = MR-NIRP 대동작. 체인 72 의 기대: 효과가 있다면 H-L1(v7)에서 가장 크고 H-L2(보행)는 작으며 H-L3(MR-NIRP)는 불확실. H-L4 는 두 모델이 같은 피크 창을 쓰므로 우연 성분이 상쇄되는 쌍대 차이로 평가한다(판정 스크립트 그대로). 가설·가중치는 바꾸지 않는다.
