# 32. 시간 배속 증강 + 검증 early-stop 실험 설계 (체인 50, 사전 등록, 2026-10-17)

사용자 지시(10-17): "시간 배속 증강과 검증 early-stop 실험 설계해주세요". 실행은 체인 49 완료(`/tmp/chain49.done`) 후, 사용자 승인 뒤 기동. 본 문서 작성 시점에 GPU 실험·코드 변경 없음.

## 1. 배경과 질문

근거(30 문서 §6·§7):
- **BASE epoch 곡선**(fold 1, VIPL 단독): held-out 정본 MAE 가 epoch 1 에 5.05(공동학습 TW 4.56·HYB 5.07 수준)까지 내려간 뒤 epoch 2 부터 단조 붕괴(최종 12.91, 반감 72편). VIPL 단독 셀의 실패는 "학습 불가"가 아니라 과적합(청크 암기) 동역학이다.
- **문헌 레시피 대조**(§7.3): 공식 PhysFormer 는 25 epoch scratch 로도 붕괴하지 않는다. 본 파이프라인에 없는 요소 중 암기 지름길("청크 정체성→HR")을 직접 막는 것이 **시간 배속 증강**(50% 확률로 2배속·HR×2 / 1/2배속·HR÷2)이며, 이는 동시에 본 모델의 최대 오차원인 **≥100 bpm 구간**(총 오차 47%, §7.1)에 학습 표본을 공급한다.
- **epoch 선택**: 지금은 10 epoch 최종 체크포인트 고정(검증 없음). test fold 를 본 사후 선택은 금지이므로, 학습 fold 내부 피험자 분리 **검증 집합**으로 epoch 을 고르는 것이 공정한 유일한 방법이다.

질문 세 가지:
- Q1 시간 배속 증강이 공동학습 셀(정합 앵커 TWg, fold 1 문헌 GT 6.09 / 3시드 6.05)의 VIPL 오차, 특히 고심박 구간을 줄이는가.
- Q2 시간 배속 증강이 VIPL 단독 셀의 붕괴를 막는가(문헌과 같은 "VIPL 만으로 학습" 경로가 본 파이프라인에서 열리는가).
- Q3 검증 기반 epoch 선택이 VIPL 단독 셀을 구제하고, 공동학습 셀에는 무해(또는 유익)한가.

## 2. 가설 (사전 등록)

| 가설 | 내용 | 1차 비교 | 지지 기준 |
|---|---|---|---|
| H-T1 | 시간 배속 증강이 공동학습 셀의 VIPL held-out 오차를 줄인다 | `VF1_TWgA_L` vs `VF1_TWg_L`(같은 학습 피험자 86명, 최종 epoch) | 문헌 GT MAE 영상 단위 쌍대 Wilcoxon p<.05(Holm, 가족 3) & Δ<0; 기전 확인: GT≥100 구간 MAE 감소 |
| H-T2 | 시간 배속 증강이 VIPL 단독 셀의 붕괴를 막는다 | `VF1_BASEA_L` 최종 epoch vs BASE 15.80 / r .02 | 최종 epoch 문헌 GT MAE < 8 & r > .5 & 반감 < 20편(붕괴 기준의 역) |
| H-E1 | 검증 epoch 선택이 VIPL 단독 셀을 구제한다 | `VF1_BASEV_L` 검증 최적 epoch vs 같은 run 최종 epoch | 쌍대 p<.05 & 검증 최적 읽기 문헌 GT MAE < 8 |
| H-E2 | 검증 epoch 선택이 공동학습 셀에 무해하다 | `VF1_TWgV_L` 검증 최적 vs 같은 run 최종 epoch | 악화 방향 유의(p<.05)가 아니면 무해; 개선 유의면 유익 |
| H-TE | 두 수단은 상보적이다(증강 + 선택 ≥ 각 단독) | `VF1_TWgAV_L`·`VF1_BASEAV_L` 검증 최적 vs 단독 셀 | 기술 통계 + 쌍대 검정, 채택 판단은 §6 |

귀무 결과도 그대로 기록한다(정직 보고). "붕괴" 정의: 문헌 GT MAE ≥ 10 또는 r < .3 (30 문서 BASE 5 fold 전부 해당).

## 3. 요인 설계와 셀 (fold 1 파일럿, 시드 100)

학습 피험자 집합: fold 1 test 21명 제외 86명. 검증 셀(V)은 그중 **12명(학습 4 fold 에서 3명씩, `random.Random(0)` 고정, `vipl_valid_subjects.json`)** 을 검증으로 떼고 74명으로 학습(VIPL 청크 ≈ −14%). 풀(공식 코퍼스 203 클립, 장치 HR 사이드카 없음)은 전부 학습에 둔다.

| 셀 | 학습 데이터 | 시간 배속 증강 | 검증 선택 | 읽기(결과 이름) | 답하는 가설 |
|---|---|---|---|---|---|
| `VF1_TWgA_L` (공동학습 + 증강) | VIPL 86명 + 공식 코퍼스, 장치 HR 라벨 | O | X (최종 epoch) | `VF1_TWgA_L` | H-T1 (vs TWg 6.09) |
| `VF1_TWgV_L` (공동학습 + 검증) | VIPL 74명 + 공식 코퍼스 | X | O | 검증 최적 = 자체 테스트 / 최종 = epoch 곡선 E9 | H-E2; 최종 읽기 vs TWg = 피험자 12명 감소 비용 |
| `VF1_TWgAV_L` (공동학습 + 증강 + 검증) | VIPL 74명 + 공식 코퍼스 | O | O | 최종 / `_bv` | H-TE |
| `VF1_BASEA_L` (VIPL 단독 + 증강) | VIPL 86명 만 | O | X (최종 epoch) | `VF1_BASEA_L` + epoch 곡선 | H-T2 (vs BASE 15.80) — 문헌 레시피에 가장 가까운 셀 |

| `VF1_BASEAV_L` (VIPL 단독 + 증강 + 검증) | VIPL 74명 만 | O | O | 최종 / `_bv` | H-TE(VIPL 단독 측) |

모든 셀 공통: 정합 프로토콜(31 문서 §4 — 장치 HR 사이드카 라벨 `RPPG_HR_LABEL_FILE=1`, VIPL 청크 파형 손실 제외 `RPPG_PEARSON_SKIP_RE`, uint8 캐시, DiffNormalized, UBFC 체크포인트 미세조정 10 epoch, lr 5e-5, batch 4, `PF_LOSS_A` 기본 1.0), 모든 epoch 체크포인트 보존(`epochs_keep/`) → **test fold epoch 곡선은 전 셀 진단용**(선택에 사용 금지). 평가 축: VIPL fold 1 held-out 471편(문헌 GT 주·정본 부) + MR-NIRP driving 3축 + DLCN(zero-shot 회귀 게이트, 공동학습 셀만).

제외 요인(교란 통제): β 1→5 스케줄·원시 RGB 입력·무작위 크롭/반전은 넣지 않는다(§7.3 의 다른 차이는 별도 단계). 하이브리드(HYB) 변형은 증강 채택 후에만(§6 Phase 3).

## 4. 시간 배속 증강 명세 (툴박스 패치 #30, 로더 `BaseLoader.__getitem__` uint8 경로, 학습 로더에서만)

공식 PhysFormer 의미(30 §7.3)를 청크 캐시에 맞게 옮긴다. 환경변수 `RPPG_TAUG=1`(기본 0 = 상류 동작), `RPPG_TAUG_P`(기본 0.5), `RPPG_TAUG_HR_SPLIT`(기본 88).
- 표본마다 확률 p 로 증강 여부를 뽑고, 방향은 **청크 HR 라벨**로 정한다: HR > 88 → 1/2배속(HR÷2), HR ≤ 88 → 2배속(HR×2). HR 은 장치 HR 사이드카(VIPL)가 있으면 그 구간 평균, 없으면(풀 청크) 파형 라벨 누적합의 0.6–3.3 Hz FFT 최댓값. 난수는 torch RNG(워커 시드가 `RPPG_SEED` 에서 파생) → 시드 재현 가능.
- **2배속**: 청크 i 의 161 프레임 중 앞 160 + 다음 청크 i+1 의 161 프레임(경계 중첩 프레임 공유) = 321 프레임에서 짝수 인덱스 161 프레임 → DiffNormalized 160. 파형 라벨: 두 청크 라벨 320 샘플을 인접 쌍 합산(`l[0::2]+l[1::2]`, 부표본 파형의 정확한 차분) → 160. 다음 청크가 없으면(VIPL 18.5%·풀 9.6%) **증강 생략**(원본 유지, 편향 방지) 하고 생략 수를 센다.
- **1/2배속**: 앞 81 프레임을 선형 보간(원 프레임과 인접 평균을 교대)으로 161 프레임 → 160. 파형 라벨: 앞 80 샘플을 각각 둘로 나눠 반복(`repeat(l[:80],2)/2`, 정확).
- **진폭 보존**: 재표본 후 DiffNormalized 청크의 표준편차를 원 청크와 같게 재조정(2배속은 차분 진폭 ≈2배, 1/2배속은 ≈1/2 이 되는 것을 상쇄; 손실 두 항 모두 스케일 불변이므로 입력 분포 유지 목적).
- **HR 라벨 전달**: 로더가 돌려주는 청크 이름에 `|x2` / `|x0.5` 를 붙이고, 트레이너가 배치 시작에서 이름을 분리해 사이드카 HR 에 배수를 곱한다(풀 청크의 cumsum 라벨은 재표본된 파형에서 자동으로 바뀜). 파형 손실 제외 정규식·하이브리드 노이즈 GT 조회는 분리된 원이름으로 동작.
- 로그: epoch 0 배치 200 에서 `TAUG stats fast=a slow=b skip=c none=d`(사이드카 적중과 같은 자리). 기대값(p=0.5): 2배속 ≈39%, 1/2배속 ≈11%, 생략 ≈4%.
- 평가·검증 로더는 증강하지 않는다(환경변수는 학습 run 에만, 로더 이름 `train` 일 때만).

학습 라벨 분포 효과: VIPL 영상의 22.5%(fold 1 학습 fold 는 21~28%)만 HR > 88, ≥100 은 6.4% → 증강 후 매 epoch 표본의 ≈39% 가 HR 76~176 로 올라가 고심박 구간이 채워진다(§7.1 의 "학습 영상에서도 미학습" 원인 후보 ①에 직접 대응).

## 5. 검증 early-stop 명세 (패치 #31 + 목록·yaml 생성기 확장)

- **검증 집합**: `scripts/vipl_filelist.py valid K` → `vipl_valid{K}.csv`(검증 12명의 전 영상·전 시나리오 청크, 라벨 필터 동일), `train K --xv [POOL]` → `vipl_train{K}_xv_{POOL}.csv`(검증 피험자 제외). 분할 파일 `_workspace/data/physformer/vipl_valid_subjects.json`(fold 별 12명, 시드 0 고정, 생성 후 불변).
- **yaml**: `scripts/vipl_yaml.py train ... --valid_csv CSV` → `VALID.DATA` 를 VIPL uint8 캐시 목록으로, `TEST.USE_LAST_EPOCH: False`. 툴박스는 매 epoch 후 `valid()` 를 돌려 최소 지표 epoch 을 `best_epoch` 로 기록한다(상류 기능).
- **선택 지표(패치 #31)**: `valid()` 의 라벨 HR 을 장치 HR 사이드카(문헌 GT 정의)로 바꾸고(`RPPG_HR_LABEL_FILE=1` 일 때, 없으면 기존 파형 HR), 반환값을 청크 HR **MAE**(`RPPG_VALID_METRIC=mae`, 기본은 상류 RMSE)로. 선택 = epoch 0~9 중 검증 MAE 최소(동률이면 앞 epoch). 조기 종료(patience)는 두지 않고 10 epoch 을 다 돌려 곡선을 남긴다 — "early-stop"의 실질은 체크포인트 선택.
- **읽기 두 벌**: 검증 셀(V)의 자체 테스트 출력(`agg_VF1_*V_L_VIPL.json`)은 툴박스가 검증 최적 epoch 으로 테스트한 결과(= 검증 최적 읽기)이고, 최종 epoch 읽기는 전 셀에 남기는 epoch 곡선의 E9(`agg_EP_{셀}_E9_VIPL.json`)로 얻는다(§3 표의 `_bv` 는 자체 테스트 출력을 뜻함). 선택 효과는 run 내부 비교(학습 데이터·시드 동일)로 분리되고, 검증 피험자 12명 제외 비용은 `VF1_TWgV_L`(최종) vs `VF1_TWg_L` 로 따로 잰다.
- 검증 비용: ≈1,100 청크/epoch ≈ 1~2 분 → run 당 +15 분.

## 6. 판정 규칙과 단계 (사전 등록)

통계: 영상 단위 쌍대 Wilcoxon(n=471), 문헌 GT 주·정본 부. 부분집합 보고: 휴대폰 source 2·v8/v9·v9 움직임, 운동 후 v7, GT 구간(<60, 60–90, 90–100, ≥100), 반감·|오차|>15 편 수. 공동학습 1차 가족 3건(H-T1, H-E2, H-TE 의 `VF1_TWgAV_L_bv` vs TWg)은 Holm 보정, VIPL 단독 가설은 효과가 커(붕괴 유무) 원 p 보고. 문헌형 읽기(30 §7.2 D)는 진단용 병기만(정본 프로토콜 불변).

zero-shot 회귀 게이트(공동학습 셀 채택 조건): DLCN MAE ≤ 2.5, MR-NIRP 움직임 합산이 TWg 대비 유의 악화 아님.

- **Phase 1**(fold 1, 6 셀, ≈15 h): 위 표. 모든 결과를 §7 실행 기록에 적고 판정.
- **Phase 2 (자동 조건부)**: Phase 1 의 공동학습 셀 가운데 TWg 대비 Holm p<.05 개선인 최선 읽기(`VF1_TWgA_L` / `_bv` 읽기 포함)가 있으면 → 시드 200·300(fold 1) + fold 2~5(시드 100) → 5-fold 문헌 GT 표 + 3시드 풀링. **채택 규칙**: 5-fold 합산이 TW 6.96 / HYB 6.70 대비 p<.05 개선 & 게이트 통과 → 해당 수단을 VIPL 학습 프로토콜에 편입(정합 앵커 교체), 30 문서 문헌 표 갱신. 아니면 fold 1 한정 관찰로 기록.
- **Phase 2b (조건부)**: H-T2 지지 시 `VF{k}_BASEA_L` fold 2~5 → 5-fold VIPL 단독 + 증강 표(문헌 프로토콜에 가장 가까운 본 파이프라인 수치). 이 수치가 문헌 4.97 과 1 bpm 이내면 "격차는 증강 부재" 로, 아니면 잔여 차이(β 스케줄·원시 입력·MTCNN)를 명기.
- **Phase 3 (사용자 결정)**: 증강 채택 시 하이브리드 변형(`VF1_HYBgA_L`) 1 셀.
- 중단 규칙: 어떤 셀이든 `HRFILE sidecar hits=0` 또는 `TAUG stats` 미출력이면 체인 실패 처리(라벨 미적용 사고 재발 방지, 31 문서 10-14 사고 참조).

- 구현 순서(승인 후): ①패치 #30·#31(모두 환경변수 기본 off, 상류 동작 불변) + 컴파일 검사 ②`vipl_filelist.py valid/--xv`, `vipl_yaml.py --valid_csv`, 분할 json ③스모크 테스트: 청크 20개 목록·1 epoch·검증 10 청크로 `TAUG stats`·사이드카 적중·배수 라벨·`best_epoch` 출력 확인, 증강 함수 단위 검사(2배속·1/2배속 라벨 변환 정확성, 진폭 보존) ④체인 스크립트. 체인 49 가 도는 동안 코드를 바꾸면 fold 2~5 run 이 새 로더를 import 하므로, 구현은 **체인 49 종료 후** 또는 컴파일 검사·스모크 통과 뒤에만(사용자 선택).

**해석**
1. 시간 배속 증강(문헌 PhysFormer 레시피 요소)은 VIPL 단독 학습을 붕괴에서 구하지만, 이미 정칙화된 공동학습에는 이득이 없고 오히려 해롭다(증강이 학습 난도를 높여 10 epoch 안에 수렴하지 못함). 즉 **증강과 공동학습은 같은 역할(과적합 붕괴 방지)의 대체재**다.
2. 정칙화된 VIPL 단독(증강, 6.92)은 파형 라벨 공동학습(6.96)·실-only 공동학습(6.83)·하이브리드(6.70)와 통계적으로 구분되지 않고, 장치 라벨 공동학습 앵커(6.51)보다만 0.41 나쁘다(p=.01). → VIPL in-domain 에서 공동학습(가상얼굴 포함)의 순기여는 "붕괴 방지"가 아니라 **적절히 정칙화된 단독 학습 대비 ≈0.4 bpm** 로 서술해야 한다(33 §5 VIPL 열·28 원고 §4.8 반영). **10-20 추가(체인 50c)**: 검증 epoch 선택까지 더한 VIPL 단독 셀은 6.21 로 앵커보다 −0.30(p=.017) 우세 → 순기여는 0 이하.
3. 문헌 격차: 증강만으로는 6.92 로 문헌 PhysFormer 4.97 과 1.95 차이 → 사전 등록 기준(1 bpm 이내)에 미달. 남은 격차는 증강 외 요인(읽기 프로토콜 저주파 편향 ≈0.5, 고심박 구간 미학습, 원시 RGB·β 스케줄 등 30 §7)으로 귀속.
4. **사후 확장(체인 50c, 10-20 완료)**: VIPL 단독 + 증강 + 검증 선택 5-fold **문헌 6.21 / 정본 4.94** — 증강만(6.92)보다 −0.71(p<.0001), 그리고 **우리 모든 공동학습 구성(TWg 6.51·HYB 6.70·REAL 6.83·TW 6.96)보다 유의하게 낮다**(앵커 대비 −0.30, p=.017). 즉 문헌 레시피 요소 2개(배속 증강 + 검증 epoch 선택)만으로 외부 데이터 없이 VIPL in-domain 최선이 되며, **공동학습·가상얼굴·분해 손실의 VIPL in-domain 순기여는 0** 으로 결론(단일 시드·사후 확장이므로 원고에는 '사후 확인' 으로 명시). 문헌 PhysFormer 4.97 과의 격차는 1.24 로 줄어듦(남은 격차 = 읽기 프로토콜·고심박 구간).
